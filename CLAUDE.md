# CLAUDE.md

Инструкция для Claude Code и других AI-ассистентов, работающих в этом репозитории.

## О репозитории

**Репозиторий:** `alexnefera-dot/cladue`

Рабочее пространство для проверки архивов по шаблонам. Процесс:

1. Пользователь присылает шаблоны — несколько вариантов, каждый рассчитан на своё количество.
2. Каждый шаблон разбираем и фиксируем его структуру.
3. Под каждый шаблон составляем план проверки (чек-лист).
4. По этим планам проверяем все архивы.

Кода в репозитории нет — только документы. Разделы про сборку, тесты и линтеры добавлять только если появится код.

## Структура

Сейчас в репозитории только этот файл. Предлагаемая раскладка, папки создавать по мере появления материалов:

```
cladue/
├── CLAUDE.md      # эта инструкция
├── templates/     # шаблоны, по файлу на каждый вариант
├── checks/        # планы проверки, по одному на каждый шаблон
└── reports/       # результаты проверки архивов
```

При появлении новых папок обновлять этот раздел.

## Язык

Общение с пользователем, шаблоны, планы проверки и отчёты — на русском. Сообщения коммитов — на английском.

## Git

### Ветки

- `main` — основная ветка.
- `claude/<описание>-<id-сессии>` — ветки, которые создаёт Claude Code.

Работать только в назначенной ветке. Пушить командой `git push -u origin <ветка>`.

### Коммиты

Формат [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<scope>): <краткое описание>`.

Типы: `feat`, `fix`, `docs`, `chore`, `refactor`.

Примеры:

```
docs: add verification plan for template A
chore: add templates directory
```

## Правила для AI-ассистента

- Перед изменением файла прочитать его целиком и следовать его стилю.
- Делать минимальные, сфокусированные изменения; не расширять задачу.
- Не добавлять заглушки и разделы «на будущее» — только то, что нужно сейчас.
- Не коммитить секреты, учётные данные и персональные данные из архивов.
