# План проверки: шаблон 13-стр

Тот же состав, что 12-стр, плюс одна страница, которая пока **не определена**. Всё из `12-str.md` применяется.

## Эталон

| Параметр | Значение |
|---|---|
| Страницы | 12 страниц из 12-стр + `?` (предположительно справка/FAQ: в текстах десятки ссылок «справка», «справку», «в разделе справка» на `/`) |
| Минимум слов | 400 (в примерах страницы короче, чем в 12-стр: 450–2000) |
| Минимум `h2` | 2 |

Пока 13-я страница не названа, скрипт считает 12 файлов ошибкой A3 и предупреждает A4. После уточнения — заменить `?` в `TEMPLATES[13]` в `scripts/check_archive.py` на имя файла и добавить ключевые слова темы в `TOPIC`.

## Что проверять дополнительно

1. **Наличие 13-й страницы** — оба сайта в примере содержат только 12.
2. **Заглушки другого вида**: вместо текста три карточки провайдеров (`h3` NetEnt / NOVOMATIC / Playtech + RTP), ~40 слов, без `h2`. В примере `casinorpb.buzz/app.html` и `zerkalo.html`.
3. **Ссылки «справка» → `/`** (C2): если 13-я страница — справка, все они должны вести на неё.
4. **Повтор `h2`** «Вход в личный кабинет» дважды на `vhod.html` (B8) — в обоих сайтах примера, похоже на дефект шаблона, а не сайта.
5. **FAQ первым блоком** (B9): `casinopioneer.buzz/registracia.html`, `casinorpb.buzz/partnery.html` — проверить порядок блоков в шаблоне.
6. **Тестовые контакты** «+7 123 456 78 90», `support@example.com` в `info.html` — ERROR (B4).

## Примеры из первого архива

|---|---|---|
