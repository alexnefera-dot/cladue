# План проверки: шаблон 1-стр

Одностраничный сайт. Общие проверки — в `00-common.md`, здесь только особенности.

## Эталон

| Параметр | Значение |
|---|---|
| Страницы | `main.html` |
| Минимум слов | 300 |
| Минимум `h2` | 3 (в примере 7) |
| Ссылки | не требуются (C4 не применяется) |
| Плейсхолдеры | `%brand_name_ru%` и `%brand_name_en%` — оба; `%date%` в последнем абзаце |

## Что проверять дополнительно

1. **Структура.** Вводный абзац, 5–8 разделов `h2` + `p`, блок «Частые вопросы» из `<details><summary>`, завершающая строка с `%date%`.
2. **Темы разделов.** Должны быть закрыты: игра/каталог, регистрация и вход, бонус за депозит, касса и вывод, зеркало, FAQ. Отсутствие раздела — WARN.
3. **Единственность цифр.** Процент бонуса упоминается в тексте и в FAQ — значения должны совпадать (в примере 275 % в обоих местах).
4. **Нет чужого бренда** — особенно важно, так как страница одна и бренд повторяется много раз.

## Пример из первого архива

`1-стр/casino389.team/main.html` — 480 слов, 7 `h2`, 3 вопроса в FAQ, замечаний нет.
