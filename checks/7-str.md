# План проверки: шаблон 7-стр

Ядро семейства. Собирается из сайтов 9-стр (см. `9-str.md`); в будущем может приходить и как отдельная группа `7-стр`.

## Эталон

| Параметр | Значение |
|---|---|
| Страницы | `app`, `bonus`, `main`, `registracia`, `slots`, `vhod`, `zerkalo` |
| Минимум слов | 150 |
| Минимум `h2` | 1 |
| Первая строка | абзац с брендом: `<p>%brand_name_ru%.</p>` — только плейсхолдер, не имя |
| Ссылки | только на `/`, `/app`, `/registracia`, `/slots`, `/vhod`, `/zerkalo` |

## Что проверять дополнительно

1. **Все семь страниц на месте** (A3, A4). Сайт без какой-то из семи страниц не дорабатывается, а убирается из выдачи (в отчёте «убран (неполный)»). В примере так убраны `jbp.casino` (нет `registracia`) и `jvv.casino` (нет `vhod`).
2. **Бренд** — только плейсхолдер. Живое название («Daddy», «Motor») и адреса вида `support@…` — ERROR (B4); чинится `scripts/fix_archive.py --brand Daddy`, после чего сайт проверяется заново.
3. **`main` не должна быть другим разделом** (B3): в примере `kky.casino/main.html` — политика конфиденциальности.
4. **Виджет слотов** (`h3` + RTP) не должен быть единственным содержимым `slots.html` (B2).
