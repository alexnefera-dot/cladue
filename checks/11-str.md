# План проверки: группа 11-стр

Отдельного шаблона нет: 11-стр — это набор 12-стр, у которого при выкачке не хватило одной страницы. Какой именно — у каждого сайта своё, поэтому проверяется он по шаблону **12-стр**, недостающую страницу ловит A4, и сайт убирается с пометкой «неполный набор». Дальше — план `12-str.md`.

## Как приходит в архиве

| Параметр | Значение |
|---|---|
| Страницы | 11 файлов из набора 12-стр: `app`, `bonus`, `info`, `main`, `news`, `obzor`, `partnery`, `promo`, `registracia`, `slots`, `vhod`, `zerkalo` |
| Чего не хватает | по одной странице на сайт, у каждого своей |
| Формат | как в 12-стр |

Ссылки на недостающую страницу остаются на всех остальных: в примерах по 29 и 41 ссылке «в бездну» (C1). Это и есть причина убирать такой сайт, а не дорисовывать страницу.
