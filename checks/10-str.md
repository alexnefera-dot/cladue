# План проверки: шаблон 10-стр

## Эталон

| Параметр | Значение |
|---|---|
| Страницы | `about`, `app`, `bonus`, `contacts`, `main`, `privacy`, `registracia`, `slots`, `vhod`, `zerkalo` |
| Минимум слов | 150 |
| Минимум `h2` | 1 |
| Первая строка | абзац с брендом: `<p>%brand_name_ru%.</p>` или `<p>Казино %brand_name_ru%.</p>` — только плейсхолдер, не имя |
| Подпись | на части страниц «Последнее обновление %domain_name%: %date%» (обязательность не определена) |

## Что проверять дополнительно

1. **Первая строка** каждой страницы — плейсхолдер бренда, не живое название (в примере: `<p>Казино Motor.</p>`, `<p>Motor.</p>`). Ловится B4.
2. **Тема страницы по первому `h2`** (B3). Типичные подмены в примере: `registracia` про самоисключение, `main` про поддержку, `app` про обход App Store. Решение — вручную.
3. **Контакты** (`contacts`): e-mail и телефоны допустимы только как плейсхолдеры или общие формулировки («через чат на сайте»). Живые адреса вида `support@Motor.com` — ERROR (B4).
4. **Информационные страницы** (`about`, `contacts`, `privacy`) — обычно без ссылок и короткие (100–250 слов); порог B1 для них может быть ниже, решить после уточнения.
5. **Виджет слотов** (`h3` с названием игры + RTP) допустим, но не должен быть единственным содержимым страницы (`slots.html` без `h2` — WARN B2).

## Пример из первого архива

`10-стр/9t3.casino` — набор полный, но бренд «Motor» зашит на всех 10 страницах, есть `support@Motor.com`, `Motor.com`, `Motormirror.com`; `about` — 103 слова. После `fix_archive.py --brand Motor` — годен.
