# План проверки: шаблон 12-стр

## Эталон

| Параметр | Значение |
|---|---|
| Страницы | `app`, `bonus`, `info`, `main`, `news`, `obzor`, `partnery`, `promo`, `registracia`, `slots`, `vhod`, `zerkalo` |
| Минимум слов | 400 (нормальные страницы 700–3000) |
| Минимум `h2` | 2 (нормальные страницы 5–12) |
| Ссылки | только на `/`, `/slots`, `/app`, `/registracia`, `/vhod`, `/zerkalo` |
| Плейсхолдеры | `%brand_name_ru%` на большинстве страниц; на `app`, `bonus`, `slots` бренда нет — допустимо |

## Обязательные блоки

| Страница | Начало | Конец |
|---|---|---|
| `main` | «2026 Выбор игроков», `h2` с брендом, «Что даёт …», «Игровой каталог …» | «❓ Честные ответы на вопросы», «О портале …», «По этой теме», «Официальный портал и разделы» |
| `slots`, `promo` | виджет «◆ Прогрессивные джекпоты» + «Последние выплаты» | «По этой теме» |
| остальные | `h2` по теме раздела | «По этой теме» + блок раздела |

## Что проверять дополнительно

1. **Заглушки** — главный риск. Сайт из 12 файлов по ~600 байт без `h2` убирается целиком с пометкой «контент из заглушек» (B1). В примере таких четыре из двенадцати сайтов: `05-09casino.buzz`, `casino00065.buzz`, `casino00072.buzz`, `casinosa81.buzz`.
2. **Ссылки по смыслу** (C2, справочно). Системно: «бонусы» → `/app`; «промокоды», «промо акции», «обзор казино», «новости казино», «информацию о казино», «live казино» → `/`. По 150–280 на сайт — так задумано. Дефект только ссылка на несуществующую страницу (C1).
3. **Точные дубли между сайтами** (D1): `05-09casino.buzz/main.html` = `casino00072.buzz/main.html`. Сайт с дублем убирается с пометкой «контент дублированный».
4. **Незаполненные переменные `{NAME}` и `{AMOUNT}`** в тексте и заголовках («{NAME} играет с телефона», `<h2>{NAME} стал партнером`) — ERROR (B5). В примере затронуты 25 файлов на семи из восьми нормальных сайтов; заполняются `scripts/fix_archive.py`, после чего сайты годные.
5. **Разброс цифр** (B11): в одном сайте встречается 13–17 разных процентов бонуса (50 %…750 %). Решить, какой разброс допустим.
6. **Виджет «Последние выплаты»** повторяет список дважды — так устроен шаблон (бегущая строка), не дефект.

## Примеры из первого архива

Нормальные сайты: `0509casino.buzz`, `0509q.casino`, `casino00.top`, `casinosa71/74/75/78/79.buzz` — 20–28 тыс. слов на сайт, из ошибок только незаполненные `{NAME}`/`{AMOUNT}`, но по 140–280 ссылок не на свой раздел.
