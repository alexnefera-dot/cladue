# partnery

**Скелет:** ` | H2×4 | faq-section + layout-block`

Голова и хвост собираются виджетами из библиотеки (`bloki-v5.php`), писать в них
нужно только пары «вопрос-ответ» блока FAQ. Тело — 4 разделов.

## Разделы

### 1. Быстрые выплаты — Раз в неделю

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 6 пунктов, затем финальный абзац
* у доноров раздел встречается 8 раз из 11

### 2. Поддержка партнёров — Поможем с любыми вопросами

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 7 раз из 11

### 3. {NAME} стал партнером — Заработал {AMOUNT}

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 6 пунктов, затем финальный абзац
* у доноров раздел встречается 5 раз из 11

### 4. Высокие проценты — До {ПРОЦ}% от дохода

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 6 раз из 11
