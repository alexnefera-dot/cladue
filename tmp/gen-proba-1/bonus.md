# bonus

**Скелет:** ` | H2×5 | faq-section`

Голова и хвост собираются виджетами из библиотеки (`bloki-v5.php`), писать в них
нужно только пары «вопрос-ответ» блока FAQ. Тело — 5 разделов.

## Разделы

### 1. Реальные истории — Как игроки отыгрывают бонусы

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 8 раз из 11

### 2. Промокоды на сегодня — Без левых схем

* зачин: 3 абзаца(ев) по ~4 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 9 раз из 11

### 3. Условия отыгрыша — Читай внимательно

* зачин: 3 абзаца(ев) по ~4 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 8 раз из 11

### 4. Кэшбэк — Возврат до {ПРОЦ}% реально работает

* зачин: 3 абзаца(ев) по ~3 фразы
* один H3, затем список на 7 пунктов, затем финальный абзац
* у доноров раздел встречается 9 раз из 11

### 5. VIP программа — Для тех, кто играет серьёзно

* зачин: 3 абзаца(ев) по ~4 фразы
* один H3, затем список на 6 пунктов, затем финальный абзац
* у доноров раздел встречается 7 раз из 11
