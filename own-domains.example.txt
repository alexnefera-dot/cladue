# Домены НАШИХ сайтов — список для статистики.
# Скопируйте этот файл в own-domains.txt и впишите свои домены (по одному в строке).
# Строки, начинающиеся с #, — комментарии. Регистр не важен.
#
# Зачем это нужно. «Наш» сайт скрипт узнаёт по меткам в HTML (own-markers.txt), но только когда
# ОТКРЫВАЕТ его. Домен, который уже есть в базе пересечений, повторный сбор не открывает — он
# отсеивается как «уже в базе». Поэтому наши старые сайты в статистике не попадали в «наших»,
# и процент считался по одним свежим.
#
# Всё, что здесь перечислено, подмешивается в список наших доменов (runs/own-domains.txt) при
# каждом запуске — и такие домены считаются нашими, даже если сайт в этот раз не открывался.
#
# Пишите РЕГИСТРИРУЕМЫЙ домен, поддомены учитываются сами:
#   example.com        — и kush.example.com, и max.example.com будут нашими
#   kush.example.net   — тоже можно, запишется как example.net
#
# Список можно не вести руками: скрипт сам добирает наши домены из прошлых сборов —
# из таблицы (sites.json), из убранных сайтов (кнопка «Убрать наши») и из папок pages/наши.
# Этот файл нужен для того, что было собрано ещё раньше и на диске уже не лежит.
#
# example.com
