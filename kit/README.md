# Комплект замера шаблонов

Инструменты, которыми мы разбирали наборы казино-шаблонов. Рассчитаны на **папку с большим
количеством наборов**: каждый набор — это каталог со страницами `.html`/`.htm`.

```
<папка>/
├── site-a/   main.html  slots.html  bonus.html ...
├── site-b/   main.html  ...
└── site-c/   ...
```
Вложенность на уровень глубже тоже распознаётся.

## Быстрый старт (если шаблоны в архиве)

```bash
# 1. распаковать .rar рядом со скриптами
unar OLD25.rar            # macOS:  brew install unar
unrar x OLD25.rar         # Linux:  sudo apt install unrar
7z x OLD25.rar -oOLD25    # Windows / везде, где есть 7-Zip

# 2. зависимости
pip install beautifulsoup4 lxml

# 3. ПЕРВЫМ делом — проверить, что наборы распознались
python3 -I kit/proverka.py OLD25

# 4. если наборы видны — прогнать всё одной командой
bash kit/progon.sh OLD25
```

Отчёты лягут в `otchet/`: `00-proverka.txt`, `01-zamer.md`, `02-brend.md`,
`03-shingly.md`, `04-bloki.md`.

`proverka.py` подскажет готовую строку `--pages` с типами страниц, которые есть
во **всех** наборах — её удобно передать, чтобы сравнивать на одинаковом составе:

```bash
bash kit/progon.sh OLD25 --pages main,slots,bonus,vhod,registracia,zerkalo
```

Если наборов найдено 0 — структура глубже, чем ожидают скрипты. `proverka.py`
покажет, что лежит в папке, и подскажет, какую подпапку передать напрямую.

## Установка

```bash
pip install beautifulsoup4 lxml
```

Запускать с `-I`, если папка с шаблонами — скачанные со стороны файлы:
```bash
python3 -I zamer.py /путь/к/шаблонам
```

## Инструменты

| скрипт | что делает |
|---|---|
| `zamer.py` | Основной замер: ~70 параметров, медиана / полоса / **CV** по наборам |
| `brend.py` | Где живёт бренд: title, meta, JSON-LD, alt, href, aria и т.д. |
| `shingly.py` | Матрица пересечений наборов по 6-словным шинглам |
| `bloki.py` | Состав блоков, матрица `variant`, проверка «рескин или пустой ярлык» |
| `proverka.py` | **Запускать первым**: какие наборы найдены, сколько страниц, какой бренд |
| `progon.sh` | Прогон всех инструментов одной командой, отчёты в `otchet/` |
| `obshee.py` | Общие функции (поиск наборов, опознание бренда) — не запускается отдельно |

### Примеры

```bash
# замер: наши против чужих, на одинаковом составе страниц
python3 -I zamer.py ./наши ./чужие --labels наши чужие \
        --pages main,slots,bonus,app,vhod,registracia,zerkalo > zamer.md

# бренд по всем поверхностям
python3 -I brend.py ./чужие > brend.md

# пересечения текста между наборами
python3 -I shingly.py ./чужие > shingly.md

# блоки и варианты + последовательность
python3 -I bloki.py ./чужие --page main --seq > bloki.md
```

Вывод — готовый markdown, можно сразу вставлять в отчёт.

## Как читать замер (методика)

1. **Единица — набор, не страница.** Показатель считается внутри набора, затем по наборам
   берутся медиана, полоса и CV.
2. **Полоса важнее точки.** Попадание в медиану при выходе за min–max — не попадание.
3. **CV = σ/среднее** показывает, насколько наборы похожи *друг на друга*. Пачка, снятая одной
   машиной, опознаётся по низкому CV каркаса. Нужно **минимум 2 набора** на сторону,
   осмысленно — от 5–6.
4. **Нормировка на 1000 слов** для всего, что зависит от объёма; «на страницу» — для
   остального.
5. **Одинаковый парсер на обе стороны** — поэтому обе стороны гоняйте этими же скриптами,
   не смешивайте с цифрами из другого инструмента.
6. **Отличать приём от чужого сбоя.** Прежде чем копировать расхождение, проверьте, не
   является ли значение конкурента его собственным браком.

## Опознание бренда

Определяется автоматически по `<title>` (1–2 слова, со стоп-листом родовых слов).
Если ошибся — положите в папку набора файл `brand.txt`, по одному написанию на строку:

```
Изи Кэш
EzCash
```

## Важно про CSS

Скрипт `bloki.py` читает **и внешние файлы** (`*_files/*.css`, `styles.php`), **и инлайновые
`<style>` на странице**. Это критично: в разобранных наборах внешний файл был 76 КБ, а
инлайновых стилей — 329 КБ, и большая часть правил жила именно в них. Если смотреть только
внешний CSS, выводы получатся неверными (мы на этом один раз обожглись).
