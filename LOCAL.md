# Локальный запуск для тестирования

Позволяет погонять всю систему на своей машине: без сервера, без MySQL,
без хостинга. База — SQLite в файле, веб-сервер — встроенный в PHP.

## Что нужно

Только PHP 8.2+ с расширениями `pdo_sqlite` и `mbstring`.

- **macOS:** `brew install php`
- **Windows:** скачать с [windows.php.net](https://windows.php.net/download/), в `php.ini`
  раскомментировать `extension=pdo_sqlite` и `extension=mbstring`
- **Linux:** `apt install php-cli php-sqlite3 php-mbstring`

Проверить:

```bash
php -v          # нужна 8.2 или новее
php -m | grep sqlite
```

## Запуск — две команды

```bash
php local.php
```

Создаст `config.php` под SQLite, заведёт 5 демо-кампаний и наполнит базу
статистикой за 30 дней: ~3000 кликов людей, ~1200 ботов (Яндекс и прочие),
источники, гео, регистрации и депозиты, несколько непривязанных постбеков.

```bash
php -S localhost:8000 router.php
```

Дальше открывай **http://localhost:8000/stats.php**, пароль — `test`.

## Что можно потыкать

| Что | Как |
|---|---|
| Панель статистики | http://localhost:8000/stats.php (пароль `test`) |
| Обычный редирект | http://localhost:8000/go/dorgen_engine |
| **Ротация офферов** | http://localhost:8000/go/split_demo — обнови несколько раз, будет попадать то на `offer-a`, то на `offer-b` (примерно 25% / 75%) |
| Несуществующий слаг | http://localhost:8000/go/net_takogo → 404 |
| Приём постбека | `http://localhost:8000/postback.php?key=testsecret&cnv_id=CLICKID&cnv_status=reg` |
| Депозит (FTD) | то же, но `&cnv_status=dep` |
| Импорт из лога в базу | `php import.php` — то, что на бою делает крон раз в час |

`CLICKID` возьми из панели, из таблицы «Последние постбеки» или из `clicks.log`.

## Как проверить полный цикл

1. Открой `http://localhost:8000/go/dorgen_engine` — тебя редиректнет на оффер,
   а в `clicks.log` появится строка.
2. Скопируй `clickid` из адресной строки (он дописан к ссылке оффера).
3. Отправь постбек:
   `http://localhost:8000/postback.php?key=testsecret&cnv_id=ВСТАВЬ_CLICKID&cnv_status=reg`
4. Открой панель → «Последние постбеки». Строка будет с пометкой **«не привязан»**
   — это нормально: клик ещё в `clicks.log` и до базы не доехал.
5. Выполни `php import.php` — увидишь `импортировано: N кликов` и
   `досвязано конверсий: 1`.
6. Обнови панель — постбек привязался к кампании.

Это ровно тот сценарий, из-за которого на бою реги приходили «непривязанными»,
пока не появилось досвязывание.

## Начать заново

```bash
php local.php --reset
```

Удалит базу, лог, кэш и демо-данные, создаст всё с нуля. Существующий
`config.php` сохранится как `config.php.bak`.

## Чем локальная версия отличается от боевой

| | локально | на бою |
|---|---|---|
| База | SQLite (файл `local.sqlite`) | MySQL |
| Веб-сервер | встроенный `php -S` | Apache |
| Правило `/go/СЛАГ` | `router.php` | `.htaccess` |
| Импорт | вручную `php import.php` | крон раз в час |

Логика везде одна и та же — код общий, отличается только конфигурация.

**На боевой сервер `local.php` и `router.php` заливать не нужно** — они там
не используются. `local.php` вообще запускается только из командной строки
и по HTTP отдаёт 403.

## Если что-то не работает

- **`/go/...` даёт 404** — сервер запущен без роутера. Нужно именно
  `php -S localhost:8000 router.php`, последний аргумент обязателен.
- **Ошибка про `pdo_sqlite`** — не включено расширение (см. «Что нужно»).
- **Панель пустая** — не отработал `php local.php`, либо база создалась без
  демо-данных. Помогает `php local.php --reset`.
- **Порт занят** — возьми другой: `php -S localhost:8001 router.php`.
