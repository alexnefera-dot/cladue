# Tracker — копия Pipboy + «Сферы» (второй проект)

Это **полная копия рабочего Pipboy** (`app/`), в которую встроена новая фича
**«Сферы жизни»** — совместно с существующим функционалом. Оригинальные `app/` и
`native/` в корне репозитория не меняются.

## Что добавлено (поверх копии)

- `spheres.js` — `buildSpheres(db)`: строит сферы **из реальных данных**, без
  отдельного хранилища. Сфера = сектор Колеса (`wheel_areas`):
  - `ideal` → «10», к чему идём;
  - последняя оценка из `wheel_scores` → «где сейчас» + история;
  - `step` → следующий шаг (он уже связан с задачей сектора в Pipboy);
  - открытые задачи сектора (`nodes`, по конвенции `note LIKE '%сектор «имя»%'`).
- `server.js` — маршрут `GET /api/spheres`.
- `public/spheres.js` + пункт меню «🧭 Сферы» + экран — рендерит сферы и
  **правит реальные данные**: оценка → `POST /api/psy/wheel`, поля сектора →
  `PATCH /api/psy/areas/:id`, шаг→задача → `POST /api/psy/areas/:id/task`,
  отметка задачи → `POST /api/nodes/:id/toggle`.

Ключ: ничего не дублируется. Экран «Сферы» — это богатый вид над Колесом +
Целями, которые уже есть.

## Запуск

```
cd tracker
node server.js        # http://localhost:7777  (демо-база)
```

### На реальной базе (попробовать на своих данных)

База нативного приложения зашифрована (SQLCipher) — напрямую её не открыть.
Путь: **экспорт из нативного → импорт в трекер**.

1. В приложении: **Настройки → Экспортировать** → создаётся `data.json`
   (на Mac: `~/Downloads/cladue/app/export/<дата>/data.json`).
2. Импорт в plaintext-базу трекера и запуск:
   ```
   cd tracker
   node import-real.js ~/Downloads/cladue/app/export/<дата>/data.json real.db
   PIPBOY_DB=real.db PIPBOY_NOSEED=1 node server.js
   ```
3. Открой http://localhost:7777 → 🧭 Сферы (свяжутся сами по названиям секторов
   Колеса; кнопка «🪄» — пересобрать).

Импорт берёт только таблицы/колонки, которые есть в трекере (лишнее из нативной
схемы игнорирует), целевые таблицы замещает. Стрики/история отметок (`*_log`)
появятся после пере-экспорта из обновлённого нативного приложения (в экспорт
добавлены `routine_log/metric_log/practice_log/contact_log`).

Если есть plaintext data.db от Node-версии — можно сразу:
`PIPBOY_DB=/путь/к/data.db PIPBOY_NOSEED=1 node server.js` (работай на копии).
