# Tracker — копия Pipboy + «Сферы» (второй проект)

Это **полная копия рабочего Pipboy** (`app/`), в которую встроена новая фича
**«Сферы жизни»** — совместно с существующим функционалом. Оригинальные `app/` и
`native/` в корне репозитория не меняются.

## Что добавлено (поверх копии)

- `spheres.js` — `buildSpheres(db)`: строит сферы **из реальных данных**, без
  отдельного хранилища. Сфера = сектор Колеса (`wheel_areas`):
  - `ideal` → «10», к чему идём;
  - последняя оценка из `wheel_scores` → «где сейчас» + история;
  - `step` → следующий шаг (он уже связан с задачей сектора в Pipboy);
  - открытые задачи сектора (`nodes`, по конвенции `note LIKE '%сектор «имя»%'`).
- `server.js` — маршрут `GET /api/spheres`.
- `public/spheres.js` + пункт меню «🧭 Сферы» + экран — рендерит сферы и
  **правит реальные данные**: оценка → `POST /api/psy/wheel`, поля сектора →
  `PATCH /api/psy/areas/:id`, шаг→задача → `POST /api/psy/areas/:id/task`,
  отметка задачи → `POST /api/nodes/:id/toggle`.

Ключ: ничего не дублируется. Экран «Сферы» — это богатый вид над Колесом +
Целями, которые уже есть.

## Запуск

```
cd tracker
node server.js        # http://localhost:7777
```
