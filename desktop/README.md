# Pipboy — Mac-приложение (Electron-оболочка)

Тонкий корпус вокруг ядра `app/`: запускает тот же сервер и открывает окно.
Логика и фронт на 100% общие с веб-версией — доработки приезжают в обе.

## Запуск в разработке
```bash
cd desktop
npm install        # единственный раз: electron + builder (dev-зависимости)
npm start          # окно Pipboy, сервер поднимается сам
```

## Сборка .app (иконка в доке, автозапуск через Login Items)
```bash
npm run dist       # dist/Pipboy.app
```

Уведомления: рутины с фиксированным временем приходят системными
уведомлениями Mac, даже когда окно свёрнуто (пока открыто приложение).
Полный планировщик (платежи, события, звуки по категориям) — следующий шаг.
