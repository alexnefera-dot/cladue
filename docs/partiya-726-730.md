## Сухой пул: транш на 270 записей

Пул вырос с 726 до 996 записей, по 166 на каждый густой короткий тип. Писался
параллельно со сборкой партии, и это безопасно: порог включения — 2000 записей
на тип, то есть пул инертен, движок его не видит, и партия собрана на прежнем
материале.

Спецификация словаря, которой не хватало прошлой партии: в ней записи вертелись
вокруг одних слов (зеркал×43 на 121 запись, прилож×25, устрой×21), отчего
тошнота сухих фраз выходила выше корпусной. Тошнота считается не по одной
записи — у короткой фразы она всегда ноль, — а по двадцати подряд, потому что
столько их ложится на густую страницу:

| тип | новый транш | прежний пул |
|---|---|---|
| registracia | 5.3 | 22.0 |
| zerkalo | 6.7 | 18.5 |
| vhod | 7.7 | 28.8 |
| app | 10.8 | 12.6 |
| main | 14.3 | 10.5 |
| bonus | 21.8 | 22.1 |

Первая редакция транша проверку не прошла: обходя затёртые корни старого пула, я
создал новые — «предло» 8, «услови» 7, «написа» 7, — и четыре типа пришлось
переписать. После правки ни один корень не повторяется больше четырёх раз.
Водность записей 16.7–20.0 против 30.6–33.3 у основного пула прозы.

Проверка вынесена в `engine/instrumenty/proverit-suhoy-pul.php`, чтобы следующие
транши мерились той же меркой.

До порога включения ещё далеко: 996 записей из нужных примерно 12000, то есть
транш закрывает около двадцатой части пути.
