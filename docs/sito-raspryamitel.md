# Правка распрямителя сита и прогон по корпусу

Сито — измерительный прибор, и эта правка меняет цифры во всех прошлых
отчётах. Поэтому мерилась не итогом, а составом: какие находки пропали и
какие появились на всех 887 наборах.

## Что было сломано

`$плоско` заменял блочные теги ПРОБЕЛОМ. Заголовок точкой не кончается, и
при распрямлении слипался со следующей фразой:

```
«…чем бездеп отличается от бонусного пакета «Сделка шерифа»»
+ «Итог: RTP 95% — честно, но не выгодно»
```

Правило «пакет звучит разными числами» ищет число в тридцати знаках после
имени пакета, **не пересекая конца предложения**, — и находило чужой RTP
через одиннадцать знаков.

## Правка

На закрытии блочного тега ставится точка:

```php
'~([^\s.!?:;>])\s*</(?:h[1-6]|p|li|td|th|dt|dd|figcaption|blockquote
   |section|article|div|header|footer)\s*>~i'  →  '$1.'
```

Точка не ставится там, где текст сам кончается знаком конца. `>` исключён
из класса: **первая версия правки этого не учла**, и у вложенных закрытий
(`…сам(а).</p></div>`) перед `</div>` стоял `>` от `</p>` — шаблон считал
его текстом, в тексте появлялись « . . ». Поймал это прогон по корпусу, а
не чтение кода.

## Что изменилось на 887 наборах

```
правило                                 ДО    ПОСЛЕ  разница
джекпот мельче миллиона              11096    11221     +125
джекпот равен выигрышу                1346     1396      +50
пакет звучит разными числами           451      449       −2
остальные девять правил                    без изменений
ВСЕГО                                28511    28684     +173
```

Счёт изменился на 136 наборах из 887: на 134 находок стало больше, на 2
меньше.

### Минус два — ровно те ложные находки

```
857: «Парад-алле»  100 % везде; 95 % (bonus)   ← 95 % это RTP
885: «Сделка шерифа» 106 % везде; 95 % (bonus) ← то же
```

Обе одного узора: RTP, принятый за процент пакета из-за склейки с
заголовком. Страж процентов в обоих случаях сработал ВЕРНО — RTP он не
трогает.

### Плюс 175 — настоящие находки, которые мерка прятала

Прочитаны на наборе 762 (пять новых находок):

```
«Джекпот 440к — кто-то должен сорвать куш. Почему не вы?»
«Потенциальный джекпот — 50к, …»   (и рядом «историю ставок 50к»)
«Он забрал 550 тыс» при джекпоте 550 тыс
```

Джекпот в пятьдесят тысяч — ровно то, что правило и должно ловить. Старая
мерка молчала, потому что склеивала фразу с соседней, где слово «джекпот»
было, и срабатывало исключение «выигрыш, сам названный джекпотом, джекпоту
не противоречит».

### Где эти 175 сидят

```
наборы        джекпот мельче млн       джекпот = выигрышу
1–299      8078 → 8161   (299 наборов)    465 → 472
300–599      10 →   10   (300 наборов)     91 →  96
600–799    3007 → 3049   (200 наборов)    789 → 827
800–867       1 →    1   ( 68 наборов)      1 →   1
868–887       0 →    0   ( 20 наборов)      0 →   0
```

**Весь прирост — в старых поколениях.** Нынешний движок даёт ноль по обоим
правилам на последних двадцати наборах и единицу на предыдущих шестидесяти
восьми. То есть правка не меняет приговор ни одной недавней партии: она
чинит прибор и заодно показывает, что сегодняшняя генерация по джекпотам
чиста.

Попутно видно, какой ценой это далось: в поколении 600–799 мелкий джекпот
встречался пятнадцать раз на набор.
