## Ворота

1.5–1.8 при потолке 2.2, абзацев 19.7–22.7, слов в абзаце 36.3–50.0.

## Что осталось

**«Пакет звучит разными числами» — два случая из четырёх, класс вышел вперёд.**
Процент приветственного пакета один на площадку, а в наборе звучит тремя-четырьмя
числами:

```
811  250% (app); 750% (bonus, info, main, obzor, registracia, slots, zerkalo);
     286% (partnery); 600% (vhod)
812  200% (app, bonus, info, main); 174% (news, obzor, registracia, vhod,
     zerkalo); 15% (news); 106% (partnery, promo, slots)
```

Паспорт держит `процентПакета`, и прорезь `{ПРОЦ_ПАКЕТ}` его читает — значит
лишние числа приходят не из прорези, а из записей пулов с готовой цифрой или из
другой прорези процента (`{ДОЛЯ}`, `{ПРОЦ}`), стоящей рядом со словом «пакет».
Это следующий круг.

**«Одно имя — разные истории»** — один случай, известный открытый класс
(история против истории, а не виджет).
