# Реверс-спецификация генератора (по 50 сайтам × 7 страниц)

> Цель — **воспроизвести**, а не превзойти. Ниже — восстановленная модель того,
> как устроен генератор, породивший корпус: стохастический сборщик страниц из
> модулей-секций с пулами тем и сильным перефразированием. Заменяет прежний
> `generation-recipe.md` (тот был поверхностным «один шаблон на тип»).

---

## 0. Главный вывод: жёсткого шаблона НЕТ

**Уникальных структур: 46–49 из 50** на каждом типе страницы → рандомизация ВЫСОКАЯ.
Генератор не заполняет фиксированный шаблон, а **собирает страницу случайно** из
модулей. Признаки:
- у `main` — **520 уникальных формулировок H2** на 50 страниц (≈ нет повторов);
- порядок, количество и вложенность секций (H2/H3), тип прикреплённого блока —
  каждый раз разные;
- заголовки не берутся из списка, а **перефразируются** (часто с двоеточием-подзаголовком
  и «личным опытом»: «…: мой опыт», «Как я проверял…», иногда с тематическим украшением
  «мистические ритуалы выгоды»).

Моя прежняя ошибка — один фиксированный шаблон main + один для внутренних. Правильно —
**вероятностная сборка**.

---

## 0.5. Модель значений: ВСЁ — диапазон, не константа

Каждый параметр — **диапазон, сэмплируемый случайно на каждую страницу**, а не фиксированное
значение. Источник диапазонов — измеренный профиль `parameter-profile.md`:
**мин = p10, среднее = медиана, макс = p90**. Генератор на каждой генерации берёт из этого
диапазона случайную точку (по-разному для каждой страницы и каждого прогона).

Это касается всего: объём, число H2/H3/списков/таблиц, число FAQ-вопросов, плотность
семантических кластеров, число вставок бренда (ру/en), доля первого лица и «вы»,
плотность цифр, тошнота, водность и т.д. — берём из наблюдаемых диапазонов, **не превышая их**.

**Жёсткие инварианты (всегда, не рандомятся):** есть таблица · есть списки · ≥1 цитата-отзыв ·
FAQ-блок · дата-стамп «последнее обновление» · Schema · опенер «{Бренд}. …» ·
**0 изображений** · **0 чужих брендов** · title/H1/lang добавляет CMS (в контенте их нет).

## 1. Анатомия страницы

```
[опенер: «{Бренд}. {первое предложение-обзор}»]
[секция] × N          ← N и состав случайны
[FAQ-блок]            ← всегда, число вопросов случайно
```

**Секция** = заголовок (H2 — крупная, H3 — подсекция) + 1–2 абзаца от первого лица +
**опциональный прикреплённый блок**: список (L), таблица (T) или цитата-отзыв (Q).
Секции вкладываются: одна H2 может нести несколько H3-подсекций.

Обязательно на любой странице: ≥1 таблица (88–100%), списки (100%), ≥1 цитата-отзыв
(88–98%), FAQ (100%), дата-стамп. **Изображений нет (0%).**

## 3. Библиотека тем секций

Каждая страница = **ядро типа** + **случайные кросс-темы** (из общего пула) + **FAQ**.
Именно кросс-инъекция создаёт разнообразие (например, на странице `app` встречаются
секции про слоты, вход, платежи).

**Ядро по типам:**
- `main` — обзор/характеристики, игры и провайдеры, безопасность/лицензия, платежи/вывод, бонусы, доступ/зеркало, отзывы.
- `zerkalo` — доступ/зеркало (что это, как найти, проверка подлинности, обход блокировок).
- `vhod` — способы входа, верификация, безопасность аккаунта, сброс пароля, проблемы входа.
- `registracia` — пошаговая регистрация, верификация, «дневник» (день первый / неделя спустя / через месяц), регистрация с телефона/крипты.
- `bonus` — приветственный/бездеп/фриспины, отыгрыш и сроки, отказ от бонуса, лояльность/турниры.
- `slots` — виды автоматов, провайдеры, RTP/джекпоты, механика выплат, Live, мобильные слоты.
- `app` — установка Android/iOS, APK, мин. версии ОС, моб.версия vs приложение, фон/производительность.

**Общий кросс-пул (может попасть в любой тип):** слоты, безопасность/лицензия,
платежи/вывод, доступ/зеркало, поддержка, бонусы, верификация, отзывы/личный опыт.

## 4. Генерация заголовков (ключ к разнообразию)

Заголовки **не из списка — генерируются** по паттернам:
- **Тема + двоеточие-подзаголовок**: «Верификация личности в {бренд}: шаг за шагом».
- **Личный опыт**: «…: мой опыт», «Как я проверял…», «Почему я перебрался сюда».
- **Вопрос-заголовок**: «Актуальное рабочее зеркало {бренд} — что работает сегодня?».
- **Тематическое украшение** (редко): «мистические ритуалы выгоды», «секреты виртуального фарту».
- **FAQ-заголовок варьируется**: «Ответы на вопросы» / «Вопросы и ответы» / «FAQ — …» /
  «Ответы на частые вопросы: {подтема}».

Требование: на 50 страниц одного типа — **почти нет повторов формулировок** (у main 520 уникальных).

---

## 5. Типы блоков

**Таблицы (пул типов, выбирается случайно):**
1. **Спецификация** — `Параметр | Значение` (лицензия, поддержка, депозит, вывод, валюты…).
2. **Шаги** — `Шаг/Этап | Действие`.
3. **Игры** — названия слотов + RTP/провайдер (Wolf Gold, Book of Dead, Sweet Bonanza 1000…).
4. **Проблема–решение** — `Проблема | Решение`.

**Списки** — маркированные, 1–3 на страницу (шаги, преимущества, признаки).
**Цитаты-отзывы** — 1+ на страницу, короткие, от имени игроков.

---

## 6. FAQ-генератор

Число вопросов случайно (см. таблицу). Вопросы из **рамок со слот-заполнением**:
- **«Что делать, если {проблема}?»** — доминирующая (418 вхождений).
- «Можно ли {действие}?» (использовать / играть / вывести / отменить…).
- «Могу ли я {…}?», «Как поступить, если {…}?», «Как восстановить {…}?»,
  «Что происходит, если {…}?».

---

## 7. Стиль и тон (по измеренному профилю — см. `parameter-profile.md`)

Активный залог (пассив ~1.5%), прилагательных ~11–13%, императивы-CTA, дата-стамп
«последнее обновление», без чужих брендов, опенер «{Бренд}. …». Но **тон варьируется,
а не жёсткий E-E-A-T на всех**:
- **Обращение «вы»**: main 88%, сателлиты **32–56%** (не на всех).
- **Первое лицо / опыт**: main 84%, сателлиты **~50%**.
- **Плотность цифр НИЗКАЯ**: медиана **~1–3 на 100 слов** (перебор = отклонение от корпуса).
- **Эмодзи** — в теле только у `main` (медиана 16), у сателлитов в теле нет.
- **Плотность ключа низкая** (0.8–1.3%) — без переспама.
- **Тошнота высокая** (акад. ~40% main, ~24% сателлиты) и **низкая читабельность** (Флеш ~40) — норма ниши.

## 8. Промпт-шаблон генератора (параметрический)

```
Сгенерируй HTML-страницу типа {ТИП} для бренда {БРЕНД} (домен {ДОМЕН}, дата {ДАТА}).

СБОРКА (рандомизировать при каждом запуске):
- Объём: случайно из диапазона {СЛОВ_MIN}–{СЛОВ_MAX} для этого типа.
- Секции: собери {N} секций, где N подобрано под объём. Каждая секция =
  H2 или H3 + 1–2 абзаца от первого лица + случайно {список | таблица | цитата | ничего}.
- Темы секций: {70–80%} из ядра типа {ЯДРО}, {20–30%} — случайные из кросс-пула
  {слоты, безопасность, платежи, зеркало, поддержка, бонусы, верификация}.
- Одна таблица обязательно; тип таблицы случайно из {спецификация | шаги | игры | проблема-решение}.
- Заголовки — уникально перефразируй по паттернам (двоеточие-подзаголовок / «мой опыт» /
  вопрос), без повторов между страницами.
- FAQ обязательно: {FAQ_MIN}–{FAQ_MAX} вопросов из рамок
  «Что делать если…», «Можно ли…», «Как…», «Могу ли я…».

ОБЯЗАТЕЛЬНО: опенер «{БРЕНД}. …»; дата-стамп; эмодзи-навигация на 7 страниц;
1+ цитата-отзыв; плотность цифр как в норме типа; тон «вы» + личный опыт;
НИ ОДНОГО чужого бренда.
```

---

## 9. Критерий «попадания» (не превышать!)

Тест-генерация должна **лечь в распределения корпуса**, а не превзойти их:
объём в диапазоне типа (а не выше), число H2/FAQ/таблиц в наблюдаемых пределах,
разнообразие структур между прогонами (≥ N уникальных на N страниц),
плотность цифр и тон — в коридоре. Проверка — движком v2 по каждому прогону.

---

## 10. Библиотека секций и логика формирования структуры

Полные пулы — в `docs/section-library.md`. Суть:

- **Число разделов (H2+H3) — диапазон по типу:** main 24 / **43** / 85; сателлиты 5 / **7** / 13.
- **Формирование:** генератор берёт N разделов из диапазона, затем **случайно выбирает набор секций** из пула типа по их вероятностям (см. таблицы). Секции ядра выпадают с вероятностью ~20–40% (не 100%!), поэтому наборы у всех разные.
- **FAQ — единственная гарантированная секция** (100%). Остальное вероятностно.
- **~80% заголовков — креативно перефразированы** и не сводятся к стандартной теме («ПРОЧЕЕ/креатив» 76–100%): генератор переписывает тему в нестандартную формулировку (двоеточие-подзаголовок, «мой опыт», вопрос, тематическое украшение).
- **Кросс-инъекция:** секции чужих тем (слоты, безопасность, платежи) выпадают на любом типе с малой вероятностью — источник разнообразия.
