# Сквозная сверка фактов

Постраничные меры и согласование смотрят внутрь одной страницы. Дефект,
которого они не видят по устройству, — **факт, согласованный внутри страницы и
разошедшийся между страницами**. Он лезет ровно там, где комплект пишется
страницами-сценами: каждая сцена доказывает своё и подтягивает общий факт под
себя.

Нашлось на `rogozhnaya-masterskaya-1`, всё — чтением семи страниц подряд:

| Что разошлось | Где |
|---|---|
| настольные игры «гостю открыты целиком» при госте в 4 400 машин | `main` против `slots` |
| счёт заведён руками за 90 секунд — и через внешний профиль за 8 | `main` против `registracia` |
| почту правит то оператор за четверо суток, то вы сами за полминуты | `main` против `registracia` |
| перечни шести граф анкеты не совпадают между собой | `main` против `registracia` |
| «семь суток простоя» и «четыре дня» потери | внутри `vhod` |
| «каждые полминуты» при тридцати восьми провалах за полчаса | внутри `app` |

## Что делает приёмка

Раздел «сквозная сверка фактов» в `engine/priyomka-komplekt.php`. Две проверки.

**1. Свод.** Комплект объявляет свои величины в `svod.json` рядом со
страницами. Всякая фраза, где стоит опорное слово величины и число в её
единице, обязана нести объявленное значение. Числа читаются и цифрами, и
прописью, во всех падежах: «до тридцати одного часа», «полторы тысячи»,
«две с половиной тысячи» — `engine/src/Chislitelnye.php`.

Значение засчитывается, где бы во фразе оно ни стояло: «семь суток из
четырнадцати отпущенных» несёт и срок, и остаток, а единица есть только у
первого числа.

**2. Счёт против перечня.** «Пять настроек, которые это чинят» над списком из
четырёх пунктов. Считается без свода. На 66 комплектах срабатывает 13 раз, и
одиннадцать из тринадцати — настоящие промахи.

## Формат свода

```json
{
  "быстрая выплата": {
    "значение": 3, "единица": "час",
    "слова": ["быстрая выплата", "мимо ручной сверки", "с доверенной машины"]
  },
  "настольные игры гостю": {
    "слова": ["настольные игры"],
    "нельзя": ["гостю открыты", "открыты целиком", "доступны гостю"]
  }
}
```

- `слова` — опорные куски, по которым фраза относится к величине. Ищутся
  подстрокой, в нижнем регистре.
- `значение` + `единица` — числовая половина. Единицы канонические, список
  форм в `Skvoznye::EDINICY`: `час`, `сутки`, `минута`, `секунда`, `неделя`,
  `месяц`, `год`, `₽`, `%`, `штука`, `строка`, `графа`, `студия`, `документ`,
  `МБ`, `круг`, `заявка`, `провал`, `кратность`.
- `нельзя` — словесная половина. Не всякий факт выражен числом: настольные
  игры вылезли фразой «гостю открыты целиком» рядом с нулём в таблице соседней
  страницы, и поймать это можно только запретом на слова.

Свод необязателен: без файла работает одна вторая проверка, и приёмка пишет об
этом строкой. У шестидесяти пяти старых комплектов свода нет.

## Чего проверка не ловит

- **Скорость против итога.** «Каждые полминуты» при тридцати восьми провалах за
  полчаса — арифметика частоты, а не сверка величин. Единственный из шести
  случаев, оставшийся за бортом.
- **Полноту свода.** Величина, не объявленная в `svod.json`, не проверяется
  вовсе. Свод пишется руками вместе с комплектом.
- **Правдоподобие.** Номер разрешения, дата, привязка тайтла к студии —
  проверка держит только внутреннюю согласованность, а не соответствие миру.
