Что делаем в коде

Цель в двух единицах

Задаёшь процент или сумму, второе выводится. Признак закрепления — одно поле в схеме, остальное фронт.

Отклонение

Заменяет «До цели»: в евро и в пунктах, сортирует таблицу. Только фронт.

Полосы и один пирог

Полосы «сейчас против цели» вместо аллокации по плану. Пирог состава остаётся. Только фронт.

Форма переноса

Запас у источника, недобор у получателя, живой пересчёт обеих сторон, две кнопки быстрого ввода. Только фронт.

Числа: капитал 476 157 €, цели для примера. Сверх цели 114 306 = ниже цели, сумма отклонений в п.п. — ноль. Перенос 50 000 € даёт +23,0 → +12,5 и −10,5 → ≈ 0 п.п. Макет статический.
