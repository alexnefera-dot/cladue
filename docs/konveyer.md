# Конвейер: от архива до готового комплекта

Основная работа по этому репозиторию. Порядок шагов и чем каждый делается.

## 1. Проверка

```bash
python3 scripts/check_archive.py Archive.zip -o reports/<дата>-<архив>.md --sort /tmp/sorted
```

Принимает zip или папку со структурой `<N>-стр/<домен>/<страница>.html`. Коды проверок — в `checks/00-common.md`. Шаблон выбирается по самому набору страниц, а не по имени папки: группы 9-стр, 10-стр и 11-стр часто оказываются семьёй 12-стр без одной-трёх страниц. `--sort` раскладывает сайты на `годные/`, `на-доработку/`, `убрано/`.

## 2. Сверка со старыми партиями

```bash
python3 scripts/dedup_across.py <старые папки …> <новый архив>
```

Тот же метод, что D2, но против ранее разобранных архивов: ловит контент, который уже приходил. Порог 60 %. Без этого шага повторы между партиями не видны — внутренняя проверка их не находит.

## 3. Починка механики

```bash
python3 scripts/fix_archive.py /tmp/Archive-fixed --auto-brand
python3 scripts/check_archive.py /tmp/Archive-fixed -o reports/<дата>-<архив>-fixed.md --убрать B4,C1
```

Заполняет `{NAME}` и `{AMOUNT}`, снимает скобки шаблонизатора, чинит разметку (потерянный открывающий `<section>`, закрывающие теги без пары, мусорные теги вроде `<spoiler>` и `<title>` в теле), меняет чужие бренды и домены на плейсхолдеры. Заглушки, недостающие страницы и дубли так не чинятся — такие сайты убираются.

## 4. Фильтрация больших архивов

```bash
python3 scripts/filter_archive.py Archive.zip -o /tmp/filter --порог 60
```

Когда код и переменные чистит другой этап: только набор страниц, заглушки, тонкая главная, копии своей же страницы, точные дубли и уникальность. Потоковый, рассчитан на сотни тысяч страниц.

## 5. Оформление

```bash
python3 scripts/oform/повторы.py      <папка>        # снять удвоенные ленты выплат
python3 scripts/oform/razmetka.py     <папка>        # собрать блоки из плоского текста
bash    scripts/oform/oformit7.sh     <вход> <выход> <номер первой темы>
```

Система «витрина». `temy7.php` — 120 тем: палитра, акцент, форма карточек, стиль заголовков, вид постеров, способ вставки картинок, сюжет и раскладка баннера, шрифт; каждому комплекту своя. `stili7.php` — CSS под разметку (герой, колонки, витрина слотов, джекпоты, лента выплат, вопросы, призывы) плюс слой по структуре для комплектов без классов; селекторы заперты в уникальный класс комплекта. `grafika7.php` — рисованная графика: 19 символов автоматов, 12 семей по названию игры, предметные сцены разделов. `kartinki7.php` — расстановка: шапка, фон, врезка, полосы, постеры; плитки автоматов во все карточки страницы.

`razmetka.py` нужен, когда контент приходит плоским (`p`, `h2`, `h3`, `ul`): он узнаёт блоки по тексту и собирает ту же разметку, к которой написаны стили.

Проверка перед отдачей — набор из 12 страниц, имена картинок `{страница}_img_{N}.webp` без дыр, каждая ссылка имеет файл и каждый файл ссылку, по одному блоку стилей и одной обёртке на страницу — делается в конце `oformit7.sh`.

Посмотреть результат:

```bash
NODE_PATH=/opt/node22/lib/node_modules /opt/node22/bin/node scripts/oform/снимок.js <страница.html> <выход.png> 1100 "#ffffff"
NODE_PATH=/opt/node22/lib/node_modules /opt/node22/bin/node scripts/oform/лист.js  <папка выдачи> <выход> "#ffffff" 5
```

## 6. Отдача

Папки комплектов в корне архива, внутри `main.html`, остальные `{url}.html` и `images/`. Путь картинки в HTML — с папкой: `images/main_img_1.webp`. Формат и ограничения — в `templates/README.md`, раздел «Формат импорта комплектов». Разбивка по 40–45 комплектов на архив, если партия большая.

## Отдельная ветка работ: перевод скачанного сайта на шаблонизатор

```bash
python3 scripts/prepare_template.py <папка со страницами> -o <выход>
```

Порядок и что остаётся руками — в `docs/shablon-manual.md`, мануал для разработчика в Word собирает `scripts/manual_docx.js`. Не про контент, а про вёрстку: берёт выкачанный сайт со стилями и готовит его под наш шаблонизатор — подставляет `%domain_name%`, `%brand_name_ru%`, `%brand_name_en%`, `%directory_img%` и `%date%`, удаляет метрику, чинит мусор выкачки в путях и пишет, что осталось от чужого проекта. Контакты (телефон, почта, мессенджеры) не трогаются: это наши же данные.
