# Что фабрика держит через пятьдесят генераций

Пятнадцать проходов по корпусу `new50_3`. Вопрос один: **какой параметр
настроен, а какой просто получился.** На одном эталоне это неразличимо — любое
значение выглядит намеренным. На пятидесяти независимых генерациях намеренное
стоит в узкой полосе, а случайное гуляет втрое.

Инструменты: `engine/razbros-korpusa.php` (разброс 55 полей),
`engine/razbor-zhanra.php` (устройство жанра). Выкладки —
`reports/v4/razbros-*.json`, `reports/v4/zhanr-*.json`.

---

## Оговорка о выборке

Из пятидесяти сайтов в выводы идут **тридцать шесть**.

Четырнадцать «конструкторов» — это не четырнадцать генераций, а один шаблон,
залитый четырнадцать раз: `emoji` у всех ровно 41 при σ = 0, `sections` 37 ± 1,6,
`nausea_acad` 42,7 при CV 2,8 %, `h2_opens_para_pct` 80 ± 1,5. Сорок девять полей
из пятидесяти пяти «держатся» тривиально, потому что держится сама разметка.
Считать по ним настройку фабрики значит мерить один экземпляр пятьдесят раз.

Тридцать шесть «прозаиков» — настоящие независимые генерации: попарное
пересечение по шести словам **0,03 % на 630 парах**.

## Часть 1. Что держится

Полоса та же, по которой идёт приёмка: `|значение − медиана| ≤ max(0,25·медиана; 2)`,
для долей порог 0,8. «Держится %» — сколько сайтов из тридцати шести попало
в полосу. Проверено на всех семи типах страниц, 252 страницы.

«плюсы \| минусы» (5×).

Проверено: у всех тридцати шести первое предложение начинается либо с
«Официальный сайт…», либо с обращения, либо с «Я…».

вдвое шире). То есть это не сквозная настройка текста, а свойство длинной

## Часть 4. Формула заголовка

**54 % заголовков построены как «ключ : хвост».** Левая часть — поисковая фраза,
правая — дописана в маске сайта.

```
Зеркало Б            :  как попасть в красильню без кринжа
Каталог Б Казино     :  Рыбная артель провайдеров 🐠
Как забрать бонус    :  инструкция по‑костёрному раскаливанию 🔥
Оценочная карта      :  аптекарский огород Б (EEAT — по шести грядкам)
```

Левые части повторяются между сайтами — это и есть список ключей:
`таблица` (16 сайтов), `ответы на вопросы` (15), `вопросы и ответы` (14),
`оценочная карта` (12), `оператор Б` (10), `зеркало` (9), `плюсы и минусы Б` (8),
`каталог Б казино` (6).

Иногда хвост не дописан, и остаётся голый ключ — со строчной буквы и в
неестественном падеже. Таких **0,6 %**, и они читаются как строки из Вордстата:

```
промокод на регистрацию
привилегии постоянных игроков
все акции
действующие на сегодня акции
регистрация с мобильного телефона бесплатно
кэшбэк в казино и другие привилегии постоянных игроков
скачать приложение на телефон: основные преимущества
```

Опечатки тиражируются вместе с ключом: **«Летереи»** вместо «Лотереи» —
у пяти сайтов, «турнины» (loft), «по шестим критериям» (ezcash). Это доказывает,
что заголовок берётся из списка, а не сочиняется.

Дословно совпадающих между сайтами заголовков — 32 из 3191 (1 %). Почти все —
служебные: «Ответы на частые вопросы» (28 сайтов), «Вопросы и ответы» (18),
«FAQ» (9), «Оценочная карта: по шести критериям» (6).

Медиана длины заголовка — **7 слов**: ключ около трёх плюс хвост около четырёх.

## Часть 5. Словарь фактов: шесть чисел на весь корпус

На тридцати шести сайтах по семь страниц — **шесть разных значений RTP**:

```
96.5 ×18    96.21 ×3    96.01 ×2    96.1 ×2    96.51 ×1    96.3 ×1
```

Одно значение, **96.5**, покрывает две трети всех упоминаний и встречается у
25 сайтов из 36. Процентов бонуса — семь, из них `100 %` шестнадцать раз.

Константа настолько жёсткая, что протекает в чужие места: у `volna` в
оценочной карте стоит «OS iOS: 96.5», у `kush` — «минимального требования по
пополнению (например от 96.5)». Генератор берёт число из пула, не глядя, куда
его ставит.

Вторая константа — **«бонусный раунд ≈ 1 на 70 спинов»**, у 15 сайтов из 36
дословно, с одним и тем же числом.

Для сравнения: у нас в двадцати девяти версиях **36 разных значений RTP** и
16 процентов бонуса — под каждое упоминание своё число.

## Часть 6. Ключ не в топе частотности

У **34 сайтов из 36** самое частое значимое слово — служебное:
«как» (14 сайтов), «для» (6), «что» (5), «это» (5). Ещё у четырёх — плейсхолдер
бренда. Предметное слово попало на первое место ровно один раз: «клубок» у `eva`,
и то это маска.

Где стоят ключи (медианный ранг по частотности и медианная плотность):

| ключ | ранг | плотность |
|---|---|---|
| `игр*` | 25 | 1,86 % |
| `бонус*` | 16 | 0,95 % |
| `зеркал*` | 22 | 0,59 % |
| `вывод*` | 67 | 0,51 % |
| `регистрац*` | 33 | 0,49 % |
| `слот*` | 82 | 0,46 % |
| `лиценз*` | 154 | 0,33 % |
| `казино` | 33 | 0,28 % |

**«Казино» — 33-е место с плотностью 0,28 %. «Слот» — 82-е. «Лицензия» — 154-е.**
Классическая тошнота 7,28 при плотности главного слова 1,6 %.

Фабрика не гонит плотность ключа. Ключ размазан ниже уровня служебных слов, а
частотную верхушку держит «как» — потому что текст отвечает на «как», а не на
«что такое».

Двадцать одна наша версия из двадцати девяти **начинается сразу с H2**. У
доноров перед первым H2 стоит 169 слов: абзац-паспорт, список-оглавление с
эмодзи, таблица «Атрибут \| Значение». Это самый крупный структурный разрыв.

Второй по величине — FAQ: у них шестьдесят один вопрос на страницу и почти
треть из них про поломку, у нас пять и почти ничего про поломку.

Третий — словарь фактов: у них шесть чисел на весь корпус, у нас тридцать шесть.
Поле `fact_values` это ловит, но мы правили его точечно, а не как правило.

## Что из этого — принцип

1. **Уникальность покупается выдумкой, а не синонимизацией.** 0,03 % на 630
   парах при полном совпадении фактуры. Маска и ракурс разводят тексты, потому
   что придуманы, а не перефразированы.
2. **Плотность ключа не поднимают.** «Казино» на 33-м месте, «слот» на 82-м.
   Верхушку держит «как».
3. **Фактура — крошечный жёсткий пул.** Шесть RTP, семь бонусов, четыре минуса,
   шесть критериев оценки. Повтор числа между страницами — намеренный.
4. **Держат форму, а не объём.** Водность 29–32 % на всех семи типах страниц,
   уникальная шапка у каждой таблицы, 100 % разовых анкоров на внутренних, 2,9
   H3 на H2 — при объёме, гуляющем в пять раз.
5. **Три приёма под запретом:** шаблон обращения, заявка на закрытое знание,
   зачин «а на деле». Ноль на 252 страницах.
6. **Страх дороже обещания.** 7,5 : 1. Треть FAQ — про то, что сломалось.
