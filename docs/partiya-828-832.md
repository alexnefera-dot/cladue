# Партия 828–832

Пять наборов по двенадцать страниц. Первая партия, собранная с мебелью слоя Б:
на каждой странице стоит блок перелинковки `related-sections`.

## Итог замера

```
наборов: 5
сито всего 0 (0.00 на набор)
промахи приёмки: [0, 0, 0, 0, 0] | ср 0.00
пар ср 53.20 мед 54.0 | мельче млн 0.00 | равных 0.00
«джекпот»/1000 ср 3.51 мед 3.47 | «куш»/1000 ср 1.13
наборов с мелким джекпотом: 0 из 5
```

Сито чисто, приёмка без единого промаха — ворота драйвера этого и требуют, но
стоит отметить отдельно: это первая партия, где страницы несут новый блок, и
ни один из восьми классов сита на него не сработал.

## Сколько стоила ошибка в воротах

| набор | сид | попыток |
|---|---|---|
| 828 | 150127 | **128** |
| 829 | 150405 | 8 |
| 830 | 150800 | 4 |
| 831 | 151203 | 4 |
| 832 | 151603 | 4 |

Первые сто попыток 828 ушли впустую: `smysl-v5.php` держит свой список
допустимых адресов, а блок перелинковки ведёт во все разделы сразу — 25 находок
«адрес вне корпуса» на каждой попытке. После починки набор взялся за 28 попыток,
остальные четыре — за 4–8. Разбор в `docs/tz-bloki-plan.md`, правило 19 в
`docs/pochemu-lomaetsya.md`.

Густой набор 830 сошёлся за 4 попытки против «примерно раз в сотню» по старой
оценке драйвера — повезло с жребием, оценку по одному случаю не меняем.

## Рама блока перелинковки

Готовые списки из восьми шапок и шести подводок заменены сборкой по шаблону.
По партии:

```
шапок 60, различных 54
подводок 60, различных 52
```

Было бы 8 и 6 соответственно. Внутри набора шапки не повторяются по построению —
список занятых общий на двенадцать страниц.
