# Тошнота на внутренних: не там чинили

Замер: 288 наших внутренних страниц (`samples/v5-final`) против 228 донорских
(`samples/v5-donors`), по шесть типов с каждой площадки.

## Что было

Тошнота у нас 25,2 % медианой против 21,4 % у донора. Объём страниц при этом
почти совпадает — 528 слов против 511, — то есть дело не в длине.

Пять комплектов подряд она правилась одинаково: находил самое частое слово
(«кошелёк» 7 раз, «разговор» 7, «счётчик» 5) и разводил его синонимами. Каждый
проход снимал по одной-две десятых пункта, и на короткую страницу уходило по
три-четыре прохода.

## Что показал разбор

Разложение массы повторов по частоте слова:

| | доноры | мы |
|---|---|---|
| слова, сказанные 4 раза и чаще | 16,1 % текста | **13,3 %** |
| слова, сказанные 2–3 раза | 24,5 % текста | **30,4 %** |
| самое частое слово | 10 раз | 8 раз |
| доля топ-5 слов | 8,1 % | 7,2 % |

По частому краю мы уже НИЖЕ рынка. Весь перевес — в словах, сказанных дважды.
Отсюда и бесполезность синонимов: я правил тот конец, где запас и без того был.

## Где лежит вторая пара

Пары слов по расстоянию между двумя вхождениями:

| | доноры | мы |
|---|---|---|
| в одном блоке | 3,1 % | 3,4 % |
| в соседних (≤2 блока) | 16,4 % | 14,0 % |
| далеко | 80,6 % | 82,6 % |
| **из них тело ↔ FAQ** | **23,1 %** | **41,9 %** |

На страницу: 9,5 таких пар у донора против 19,2 у нас. Разница в 9,7 пар — это
19 лишних повторных слов на 520, то есть 3,7 пункта тошноты. Наблюдаемый
разрыв — 3,8 пункта. Сходится полностью.

## Причина: устройство вопроса FAQ

| | доноры | мы |
|---|---|---|
| пар «вопрос-ответ» | 8 | 8 |
| длина вопроса | 11,4 слова | **6,7** |
| длина ответа | 14,1 слова | 15,3 |
| слов вопроса, уже бывших в теле | 18 % | **45 %** |
| слов ответа, уже бывших в теле | 11 % | **37 %** |

Донорский вопрос приносит ОБСТОЯТЕЛЬСТВО, которого в теле нет: выходной день,
чужой человек, второй банк, разряженный телефон, повторная попытка. Наш вопрос
собран из существительных тела — «Сколько живёт присланный код?» — и ответ
выходит на тех же словах.

Проверка «эхо тела в ответах» этого не ловит: она ищет пересказ абзаца, а тут
пересказа нет — есть тот же словарь при новом утверждении.

На главной дефект тот же, но разбавлен вчетверо большим объёмом и потому
безобиден: 26,3 % пар против 19,6 % у донора.

## Что записано в задание

Пункт 12 «ТОШНОТА» в `engine/zadanie-v4.php` (нумерация 12–16 сдвинута на
13–17). Он печатает норму и потолок по типу страницы, называет обе доли массы
повторов, говорит прямо, что синонимы к частому слову бесполезны, и даёт
проверку: вычеркните из каждого вопроса слова, уже стоявшие в теле; если
осталось меньше половины — вопрос не добавляет странице ничего, кроме тошноты.

Тошнота внутренних: медиана 22,9 против 23,9–25,5 у трёх предыдущих комплектов.

Главное — цена доводки. Шесть внутренних страниц из шести прошли тошноту с
первого черновика; проходов по синонимам не понадобилось ни одного (одна правка
на `vhod` появилась позже и не от текста, а от добора бренда и выделений).
У трёх предыдущих комплектов таких проходов ушло 2, 7 и 8.

## Что осталось

Вопрос у нас 8,2 слова против донорских 11,4, ответ 10,2 против 14,1. Блок FAQ
по-прежнему вдвое короче донорского — 134 слова против 275. Направление верное,
дистанция пройдена примерно наполовину.
