# Оператор: боевой прогон контента

Как гонять пайплайн генерации без агентов, одной командой. Всё детерминированное — PHP; творческий шаг (текст страницы) — один вызов Claude API на страницу.

---

## 1. Что это за пайплайн

```
Planner ──► PromptBuilder ──► realize.php ──► механическая перелинковка ──► [verify-loop]
(план)      (промпт с целями)  (1 вызов API)   (PHP-инжектор ссылок)          (замер→бриф→фикс)
```

- **Planner / PromptBuilder** (`engine/generate.php`) — детерминированно снимают профиль сайта-донора из корпуса (50 сайтов) и собирают промпт со всеми целями: объём, структура, регистр, фактура, семантика, перелинковка, бренд-переменные. **Токены не тратятся.**
- **realize.php** — берёт один промпт → один вызов Messages API (`claude-opus-4-8`) → сохраняет готовую HTML-страницу. Это единственный платный шаг.
- **Механическая перелинковка** (`inject-links.php`) — донор-осознанно добивает внутренние ссылки, если модель недоставила. Без модели.
- **verify-loop** (опц.) — меряет каждую страницу Analyzer'ом против донора, генерит адресный бриф отклонений и правит их точечным вызовом API. Повторяет до порога.

Замер (`Analyzer`) и все отчёты — тоже чистый PHP, 0 токенов.

---

## 2. Предусловия

Нужен ключ Anthropic в окружении (одно из):

```bash
export ANTHROPIC_API_KEY=sk-ant-...
# или OAuth-токен:
export ANTHROPIC_AUTH_TOKEN=...   # realize.php сам добавит Bearer + oauth beta-header
```

PHP 8.x с расширениями `curl`, `dom`, `mbstring`, `json`. Прокси/CA среды (`HTTPS_PROXY`, `/root/.ccr/ca-bundle.crt`) подхватываются автоматически.

---

## 3. Одна команда — вся связка

```bash
php engine/realize-run.php --donor=monro --out=/tmp/run-monro --verify
```

Что делает: планы+промпты → 7 страниц (по вызову на страницу) → перелинковка → verify-loop до порога. В конце печатает совпадение и стоимость.

### Флаги

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `--donor=<name>` | — | Сайт-донор из корпуса (см. список ниже). Обязателен. |
| `--out=<dir>` | — | Куда сложить `main.html`…`app.html` и промпты. Обязателен. |
| `--seed=<str>` | `prod` | Меняй seed → другой уникальный контент под тем же донором. |
| `--effort=<level>` | `medium` | `low`/`medium`/`high`/`xhigh`/`max` — глубина/стоимость. |
| `--verify` | выкл | Включить verify-loop (замер→бриф→фикс). |
| `--threshold=<N>` | `78` | Порог совпадения %, на котором петля останавливается. |
| `--passes=<N>` | `2` | Максимум проходов правок. |
| `--brand-ru`, `--brand-en`, `--domain`, `--date` | `%brand_%` переменные | Подставить демо-имя вместо переменных (для чтения). По умолчанию бренд остаётся переменной. |

### Список доноров

50 сайтов, по регистрам: **экспертный (24)**, **деловой (13)**, **нейтральный (6)**, **разговорный (4)**, **дерзкий (3)**.

```bash
php engine/generate.php --list-donors   # печатает всех с ключевыми метриками
```

Проверенные ориентиры по регистрам: `monro`/`bitcasino` (экспертный «я»), `bitz`/`vovan` (деловой «вы»), `cosmospin`/`vegasy` (дерзкий «ты»), `almyra` (нейтральный).

## 4. Отдельные шаги (если нужно вручную)

```bash
# Только промпты (без вызовов API):
php engine/generate.php --all --donor=monro --brand-var --seed=prod1 --out-dir=/tmp/run --prompt

# Реалайз одной страницы:
php engine/realize.php --prompt=/tmp/run/prompt-main.md --out=/tmp/run/main.html --effort=medium

# Один корректирующий проход по странице (бриф + текущий HTML → правка):
php engine/realize.php --mode=fix --prompt=/tmp/brief-and-html.md --out=/tmp/run/main.html
```

## 5. Стоимость

Ориентир на связку из 7 страниц (Opus 4.8, $5/$25 за 1M):
- вход ~10k ток. → **$0.05**
- выход ~12k ток. → **$0.30**
- **≈ $0.35 за 7 страниц** (без verify-loop). Каждый проход правок добавляет ~$0.1–0.2.

`realize-run.php` печатает фактические токены и цену в конце.

---

## 6. Как читать результат

- В конце прогона: `совпадение N%` — доля параметров страниц, попавших в коридор донора (объём, структура, ссылки, бренд, семантика, анти-спам, регистр).
- Ориентиры из боевого теста: тюненный движок one-shot даёт **~69–83%**; один проход verify-loop добивает **+10–13 п.п.**, второй — доводка. Сходится к ~83%.
- Остаточные «красные» параметры структурны и объяснимы: `сущности` (доноры-сателлиты аномально узкие), `тошнота` (природа казино-SEO). В ноль их гнать не нужно — это конфликтует с «фактурным, не ИИ-без-данных» текстом.

Полное сравнение по всем параметрам собирается отчётами: `engine/build-battle-report.php <dir> <out.html>` (нужен `runs.txt` в папке для мульти-прогона) и `engine/build-real-texts-viewer.php` (витрина реальных текстов).

---

## 7. Уникальность

Один донор + разный `--seed` = практически полностью уникальный контент при той же форме (в боевом тесте пересечение фактов между двумя прогонами одного донора ~1–2%). Масштабируется на сотни связок из одного шаблона.
