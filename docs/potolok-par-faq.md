# Потолок пар FAQ: уникальность bonus с двух третей до одной десятой

Разбор в `docs/otkuda-peresechenie-nashih-naborov.md` назвал причину провалов
уникальности: у худших пар наших наборов блок «Честные ответы на вопросы»
даёт 21–64 % совпавшего текста, а у верхней пары bonus — 94.2 %. Валит
приёмку не общий уровень похожести, а исход «две-три пары из пяти пришли из
одного прежнего набора»: пара FAQ весит 60–100 слов, то есть десяток фраз
прозы, и двух совпавших пар хватает на 12–16 % пересечения при пороге 17.4.

## Правка

Отбор `$взять` держал потолок на прошлый набор и прежде: не больше пяти
кусков от одного владельца на страницу. Для FAQ он не срабатывал почти
никогда — страница собирается из сотни кусков, и пять от одного набора
набираются редко. Теперь пары FAQ считаются отдельным счётом `$балансFaq`,
а потолок задан таблицей:

```php
const V5_FAQ_POTOLOK = ['bonus' => 1];
```

Потолок мягкий, как и общий: второй проход отбора берёт без разбора, иначе
на истощённом журнале блок остался бы без половины вопросов.

Проверка механики на одном сиде (777001, тот же журнал, отличие одно):

| | владельцы пяти пар FAQ страницы bonus |
|---|---|
| без потолка | 739, **739, 739**, не выдавалась, 740 |
| с потолком | 739, 740, 741, 743, 736 — все пять различны |

## Почему таблица, а не всем типам

Сначала потолок стоял на всех типах. Сквозной замер на 186 парных сидах
(густая манера, тот же журнал, отличие одно) показал, кто платит:

| тип | уникальность провалена | страница ниже 95 % |
|---|---|---|
| bonus | 67.7 → **12.9 %** | 45.2 → 38.7 % |
| app | 3.8 → 0.5 % | 15.1 → 15.6 % |
| main | 3.2 → 1.6 % | 19.9 → 21.5 % |
| registracia | вровень | 43.0 → **50.0 %** |
| zerkalo | 0.5 → 0.0 % | 10.2 → **37.1 %** |

Порог уникальности упирается только у bonus: корпусный потолок у него самый
низкий из всех типов (8.3 против 8.9–11.4), порог выходит 17.4, а наше
пересечение стояло на 17.6. Остальным потолок покупает десятые доли процента
провалов, а платят они полями. У zerkalo подменённые пары оказались влажнее
и беднее прилагательными, а страница стоит на двух краях полос сразу:
`water` 31.9 при верхе густой полосы 32.4, `adj_pct` 11.6 при низе 11.2.
Смены пяти пар хватило, чтобы столкнуть оба.

Попытка оплатить это предпочтением сухих пар FAQ густой странице откачена.
Водность она снимала по-настоящему — промахов `water` по всем страницам
220 → 202, у zerkalo 103 → 80, `adj_pct` вернулся выше низа полосы, — но
`registracia` и `main` теряли больше: промахов всего 1028 против 1002 с
потолком на всех типах и 980 без потолка вовсе.

Сужение до одного типа проверено на 48 парных сидах в трёх состояниях:

| тип | пересечение: без / на всех / только bonus | промахов: без / на всех / только bonus |
|---|---|---|
| bonus | 17.61 / 14.44 / **14.43** | 118 / 110 / 112 |
| zerkalo | 14.88 / 12.38 / 14.87 | 61 / **103** / **61** |
| registracia | 13.91 / 13.21 / 13.97 | 120 / 116 / 119 |
| app | 15.24 / 13.12 / 15.24 | 84 / 86 / 84 |
| main | 23.85 / 23.16 / 23.82 | 86 / 83 / 84 |
| **всего по двенадцати** | | **980 / 1002 / 962** |

Выигрыш на bonus сохранён целиком — 14.43 против 14.44, разница нулевая
(критерий знаков p = 1.0), — а плата снята вся. Промахов по всем страницам
962 против 980 без потолка: сужённый потолок лучше и исходного состояния,
потому что страница bonus тоже перестала падать.

## Сквозной итог

186 парных сидов, густая манера, через ворота, приёмку и смысл. Сторона «до» —
десять разделов без потолка; отличие одно, сам потолок.

| величина | без потолка | потолок bonus | McNemar |
|---|---|---|---|
| **уникальность bonus провалена** | 67.7 % | **10.8 %** | **4e-27** |
| страница bonus ниже 95 % | 45.2 % | **36.0 %** | 0.021 |
| страница zerkalo ниже 95 % | 10.2 % | 10.2 % | 1 |
| страница registracia ниже 95 % | 43.0 % | 41.9 % | 0.75 |
| провалов в среднем | 3.285 | **2.613** | — |
| прошло целиком | 1 из 186 | **3 из 186** | — |

Против исходного состояния этого дня (семь разделов, без потолка) то же:
уникальность bonus 65.1 → 10.8 % (p = 1e-22), провалов 3.199 → 2.613.

Цена набора по прямому счёту прохода:

| | проход | попыток на набор |
|---|---|---|
| без потолка | 1/186 = 0.0054 [0.0009, 0.0298] | 186 [34, 1053] |
| потолок bonus | 3/186 = 0.0161 [0.0055, 0.0463] | **62** [22, 182] |

Интервалы по Уилсону, и они широкие: три успеха из 186 — это оценка порядка
величины, а не цифра. Разницу держит не она, а уникальность bonus: 111 попыток
из 186 перестали падать по ней, и обратно упали пять.

## Что осталось

Единственный незакрытый расход после правки — `vhod` (страница ниже 95 % в
91.4 % попыток) и `registracia` (41.9 %). Водность густой страницы тоже на
месте: у bonus 32.5 при полосе до 29.8, и это по-прежнему требует сухого
пула, а не отбора. Дорогая правка FAQ — писать новые пары, как писался сухой
пул: рабочий пул bonus 97 пар на пять мест и сто наборов, за сто наборов
использовано 68 различных вопросов.
