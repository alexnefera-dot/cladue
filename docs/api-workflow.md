# Рабочий цикл через API: быстрая генерация + проверка

Цикл: **скрипт с твоим ключом** генерит варианты (быстро, ~$1/связка), а проверку
делает `compare-vs-donor.php` / `check-batch.php` (0 токенов) — и, когда нужен
разбор/докрутка генератора, подключается ассистент.

---

## 1. Куда положить API-ключ (важно!)

Ключ Anthropic — **СЕКРЕТ**. Он НЕ хранится в GitHub. Файл `engine/.anthropic-key`
внесён в `.gitignore`, поэтому в репозитории его НЕТ — если открыть его на гитхабе,
будет **404, и это правильно**. Ключ живёт ТОЛЬКО на машине, где ты запускаешь скрипт.

Три способа (выбери один, по тому, ГДЕ гоняешь скрипт):

**A. Своя машина/сервер** (склонировал репо и запускаешь локально):
```bash
printf 'sk-ant-ТВОЙ_КЛЮЧ\n' > engine/.anthropic-key   # создаётся локально, в git не попадёт
# либо переменной окружения:
export ANTHROPIC_API_KEY=sk-ant-...
```

**B. Переменная окружения** (CI, сервер, docker):
```bash
export ANTHROPIC_API_KEY=sk-ant-...
```
`realize.php` берёт ключ в порядке: `ANTHROPIC_API_KEY` → `ANTHROPIC_AUTH_TOKEN` →
файл `engine/.anthropic-key` (или путь из `ANTHROPIC_KEY_FILE`).

**C. Claude Code web (это окружение)** — задать `ANTHROPIC_API_KEY` в настройках
окружения (Environment variables), чтобы он был во всех сессиях. Файл в контейнере
тоже работает, но контейнер эфемерный — переменная окружения надёжнее.

> НИКОГДА: не коммить ключ, не вставляй его в чат/PR/промпт. Только файл-гитигнор
> или переменная окружения на машине запуска.

## 2. Один вариант — одна команда

```bash
# v1 (наш корпус):
php engine/realize-run.php --donor=monro --seed=A --out=runs/A --verify

# v2 (референс конкурента dorgen):
php engine/realize-run.php --corpus=dorgen --donor=set199 --seed=A --out=runs/199A --verify
```
Делает: планы → реалайз (1 вызов API/страницу) → перелинковка → verify-loop до
порога. Пишет совпадение и стоимость, плюс `meta.json` (для check-batch).

Флаги: `--seed` (уникальность), `--effort=low|medium|high`, `--threshold=85`,
`--passes=2`, `--no-opener` / `--opener`.

## 3. Пачка вариантов

```bash
for s in A B C D E; do
  php engine/realize-run.php --corpus=dorgen --donor=set199 --seed=$s --out=runs/199-$s --verify
done
```

## 4. Проверка всей пачки — одна команда

```bash
php engine/check-batch.php runs --corpus=dorgen
```
Печатает ранжир: связка · донор · совпадение % · топ-красные параметры. Пример:
```
set199-A   set199   88%   императивы×5, «вы»×2
set256-B   set256   82%   тошнота×6, прилаг×6
```
Отдельная связка детально: `php engine/compare-vs-donor.php runs/199-A set199 report.html --corpus=dorgen`.

---

## 5. Где подключается ассистент

- **Поток** — пушишь `runs/` в ветку/PR → ассистент гоняет `check-batch`, ранжирует,
  диагностирует систематические промахи, правит генератор.
- **Точечно** — скинул STATUS/архив → разбор + правка.
- **Руки** — «сделай N вариантов и отранжируй» → оркестрация под ключ.

Рутинные варианты гонишь сам (скрипт всё меряет); ассистент — для докрутки
генератора и качественных суждений, что метрики не ловят.

## 6. Стоимость

~$1 за связку из 7 страниц (Opus, medium). Дешевле на `--effort=low` или Haiku.
Генерация планов, замер, отчёты, check-batch, verify-loop-брифы — 0 токенов (PHP).
