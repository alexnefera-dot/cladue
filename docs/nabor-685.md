разделы без цифр (12.6 → 16.0 %), ты-формы (8.74 → 7.80), глагольные анкоры
(17.5 → 16.0 %). Все три внутри корпусной полосы, но разброс у нас шире
корпусного — при одном наборе на партию это будет прыгать и дальше.
