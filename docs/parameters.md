# Реестр параметров анализа контента под Яндекс

> **Фаза 1 проекта.** Полный список параметров, которые локальный скрипт может
> посчитать сам (офлайн, без обращения к API Яндекса), для анализа 7-страничного
> контента с перелинковкой.
>
> **Легенда колонок:**
> - **ID** — код параметра (используется в HTML-шаблоне и PHP-скрипте).
> - **Норма** — рекомендованный диапазон/значение под Яндекс.
> - **Авто** — можно ли посчитать локальным PHP-скриптом без внешних API:
>   `✅` да · `🟡` частично (нужен словарь/эвристика) · `🔴` нужен внешний источник.
> - **Тип** — `SEO` · `Текст` · `UX` · `Тех` · `Линки` · `Антиспам`.

## 0. Как считается «под Яндекс» (контекст)

Яндекс ранжирует иначе, чем Google. Ключевые алгоритмы, под которые заточен этот анализ:

| Алгоритм | Что оценивает | Наши параметры |
|----------|---------------|----------------|
| **Баден-Баден** | Переоптимизация текста, переспам ключами | тошнота, плотность, % точных вхождений |
| **YATI / Королёв / Палех** | Смысловое соответствие запросу (нейросети) | LSI, семантика, естественность, Ципф |
| **Проксима / ИКС** | Качество сайта, поведенческие | объём, структура, мультимедиа, перелинковка |
| **Спам-фильтр** | Неестественные конструкции | водность, повторы, спам-анкоры |

Главная особенность Яндекса против Google: **переоптимизация наказывается сильнее, чем недооптимизация**. Поэтому пороги «сверху» (тошнота, плотность, % вхождений) для нас важнее, чем «снизу».

## Итог по фазе 1

- **Всего параметров:** ~110.
- **Считаются офлайн локальным PHP (`✅`):** ~75.
- **Считаются с оговоркой / нужен словарь (`🟡`):** ~30 (стоп-слова, лемматизация, LSI, орфография).
- **Требуют внешних API (`🔴`, вне офлайн-скрипта):** внешняя уникальность/плагиат, реальные поведенческие факторы Яндекса, ИКС.

### Что понадобится скрипту как справочники (готовим в фазе 3)
1. Словарь **стоп-слов** русского языка (для водности и тошноты).
2. Таблица **слогов/эвристика слогов** (для индексов читабельности).
3. Опциональный **словарь лемм** или стеммер Портера для русского (морфоформы ключей).
4. Пользовательский ввод: **список ключевых слов** и **семантическое ядро/LSI** на проект.
