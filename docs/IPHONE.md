# iPhone-приложение: план и что нужно

## Архитектура (решено)
Capacitor-оболочка: тот же фронт (app/public/), SQLite на устройстве,
локальные уведомления со звуками по категориям (лента notify.js),
синк с Mac по Wi-Fi (журнал операций, last-write-wins).

## Что нужно от пользователя (один раз)
1. Установить Xcode из App Store (бесплатно).
2. Apple Developer Program — $99/год (https://developer.apple.com),
   чтобы приложение жило на своём iPhone дольше 7 дней. В стор не выкладываем.
3. Сказать в чате «Xcode готов» — дальше собираем по шагам вместе.

## Порядок работ (после готовности Xcode)
1. mobile/: Capacitor-проект, адаптер БД (node:sqlite → @capacitor-community/sqlite —
   API совместим: prepare/get/all/run, логика ядра не меняется).
2. Локальные уведомления: notify.js лента → LocalNotifications.schedule
   со звуком категории (рутины/деньги/события/люди).
3. Синк: таблица ops(journal) в обеих базах; телефон дома находит Mac
   (адрес из Настроек), обменивается журналами по ключу замка.
4. Тест на твоём iPhone → правки → ежедневное использование.

Ядро и фронт уже общие — iPhone-версия получит все будущие доработки автоматически.
