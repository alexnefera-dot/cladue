## Два дефекта, найденные уже на собранной партии

**Глагол в строке доверия был зашит в мужском роде**, а имя берётся любое, и
в наборы уехало «Милана вывел 50 000 ₽ — проверено». Теперь отглагольное
существительное, согласования не требует: «Милана — вывод 50 000 ₽,
проверено». В выдаче исправлено 268 строк — ровно тот текст, что теперь даёт
движок. Блок мебельный, из ворот вычитается: перемер исправленной выдачи дал
те же числа до цифры.

**Вставка молча теряла блоки без ориентира.** На `registracia` набора 842 нет
`faq-section`, и зазывалки туда не попали — без ошибки, без следа в логе,
round-trip при этом идеальный. Одна страница из 48. Теперь при отсутствии
ориентира блоки идут в конец содержимого.

Это второй случай того же класса за день: часом раньше вставка промахивалась
по тегу (`<section>` против нашего `<div class="faq-section glass-card">`) и
тоже молча. Общее у обоих — **отказ без признаков**: функция возвращает
правдоподобный результат, и ни одна проверка не срабатывает. Ловится только
счётом: «блоков должно быть 48, а их 47».
