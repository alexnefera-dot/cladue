# Бэклог отложенного функционала

> Что осознанно отложено и **когда возвращаемся**. Проверять этот файл при старте каждого этапа.

| Функция | Куда относится | Вернуться когда | Заметка |
|---|---|---|---|
| Вкладки «План» и «Лог» у задачи (рассуждения + датированные записи хода) | Задачи | **Этап 3 (Инфо)** — план = страница редактора; лог можно раньше, если попросит | Сейчас частично закрыто полем «заметка» |
| Pre-flight перед стартом важной задачи | Задачи × Финансы | **Этап 2 (Финансы)** — как только появятся обязательства/платежи, радару будет что показывать | Обязательный чеклист блокеров |
| Повторяющиеся задачи (RRULE) | Задачи × Календарь | **Этап 2 (Календарь)** | «назначать даты заранее», ТО, счётчики |
| Двусторонняя связка задача ↔ календарь | Календарь | **Этап 2** | выполнение события дополняет цель |
| Undo (отмена последнего действия) | Все разделы | **Перед началом боевого разбора 500 строк** — спросить пользователя | Сейчас удаление необратимо (есть confirm) |
| Окно времени ±60 дней в предложениях связей | Разбор | **Этап 2** — станет полезным с финансовыми датами | Частично есть: «дата рядом», если у обоих стоят сроки |
| Метрики/прогресс у целей, горизонты (год/квартал) | Цели | **Этап 4** вместе с колесом | Категория «Глобальные цели» уже есть |
| Типизация при добавлении («?» в конце → вопрос автоматом) | Разбор | Спросить после обкатки ＋-ввода | |
| Журнал принятых решений (история всех answer) | Психология/Журнал | **Этап 4** — отдельный экран «Принятые» | Поле answer уже копится с этапа 1 |

## Перенести в другие разделы при их создании

- **Финансы (этап 2):** pre-flight; окно времени; «Принятые» решения по сделкам; категории Финансы→* уже готовы как место раскладки.
- **Календарь (этап 2):** повторы; связка с задачами; сроки из вида «Сроки» должны стать лентой.
- **Инфо (этап 3):** «План» задачи = страница; заметка узла мигрирует в полноценный блок.
- **Психология (этап 4):** тревоги (тип worry уже есть — собрать их экран «Тревоги» из категорий Страхи/Вопросы); журнал решений.
