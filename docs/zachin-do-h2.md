# Зачин до первого h2

Вводный абзац перед первым заголовком — манера густых наборов, найденная
вычиткой, а не замером. Ни один из девяноста восьми измеряемых параметров её не
ловил: все они считают количества, а порядок блоков не смотрит никто.

## Что у корпуса

Зачин есть на 225 густых страницах из 252 — по 19 наборов из 21 на каждом типе,
на main 16 из 21. У 79 обычных наборов его нет ни на одной из 360 страниц. То
есть это признак именно густой манеры.

Их зачин — описание страницы, вынесенное в текст: предмет, перечисление того,
что внутри, возрастная метка. Слов 33 по медиане, нижний дециль 12.

> Регистрация %brand_name_ru% Казино онлайн: создай профиль, проверь правила
> бонусов и выбери удобный способ входа. 18+

## Что сделано

`v5ZachinStranicy` собирает зачин из собственных h2 страницы, а не из нового
текста: так он остаётся в её словаре и не требует материала, которого у нас нет.

Четыре правки по итогам вычитки собственного вывода:

- срезано нетекстовое начало заголовка — иначе в перечисление попадал эмодзи из
  заголовка FAQ;
- заголовок FAQ исключён: он одинаков на всех страницах набора и лез в зачин
  пяти страниц из семи, перечисление переставало описывать конкретную страницу;
- у main предмет пустой — иначе выходило «Онлайн-казино %brand% Казино онлайн»,
  три казино в одной строке;
- отбор слабых пунктов (корень предмета, заголовок-история с глаголом) сделан
  **предпочтением, а не фильтром**: жёсткий фильтр на registracia выбрасывал три
  пункта из четырёх, отключался по своему же условию «оставь хотя бы два» и
  оставлял ровно то, что должен был убрать.

## Замер

Доля страниц с зачином: **0 % → 100 %** при корпусной полосе 100–100.

Сдвиг остальных полей, 24 парных сида, медиана по двенадцати типам: абзацев
+1.00, слов +15.00, бренд-ru +1.00, терминов +1.00, тошнота +0.50, слов в абзаце
−0.90, водность −0.10; короткие абзацы, прилагательные, разделы и h2 не
шевельнулись. Водность чуть упала — зачин сухой, в нём перечисление и возрастная
метка.

Приёмка, 48 парных сидов:

| тип | до | после |
|---|---|---|
| registracia | 70.8 % | **60.4 %** |
| main | 10.4 % | 8.3 % |
| bonus | 33.3 % | 41.7 % |
| news | 4.2 % | 12.5 % |
| vhod | 75.0 % | 79.2 % |

Провалов в среднем 4.52 → 4.33, прошло всё 0 → 1. Критерий Макнемара по парам:
единственное заметное движение — registracia, 5 пар ушло, 0 появилось,
p-значение 0.0625. Остальные расхождения не значимы (bonus 1 против 5,
p = 0.22).

Правка оставлена: цель достигнута целиком, приёмка в сумме не пострадала, а
единственное значимое движение — в плюс.

## Две ошибки в самом замере

**Первый прогон «до» мерил то же, что «после».** Я закоммитил правку, а потом
сделал `git stash push` — stash сравнивает с HEAD, правка уже была в HEAD, и
ничего не спряталось. Поймано тем, что 48 записей из 48 совпали полностью: такое
точное совпадение само по себе означает одинаковые условия, а не безвредность
правки. Переделано выгрузкой файлов из родительского коммита; во втором прогоне
совпало 21 из 48.

**Оценка p произведением по источникам на 48 сидах врёт.** Она дала 0.0009
против 0.0118 на прежних 186 сидах, но прямой счёт прошедших наборов — 0 и 1 из
48 — укладывается в прежнюю оценку. При двух десятках источников и полусотне
наблюдений доли источников шумят вверх, и произведение уезжает вниз. На таком
объёме надо смотреть прямой счёт.
