# Реестр v2 — стилистика, тон, фактура (расширение)

> Цель этого расширения — не «оценить SEO», а **понять, как устроен и как
> сгенерирован контент**: стиль, тон, акценты, набор фактов. Источник —
> ручной разбор конкурентов (Ramenbet, 3 сайта × 7 страниц), где помимо
> объёма/тошноты/структуры анализировались части речи, обращение, E-E-A-T,
> извлечение сущностей, чужие бренды и «тема-угол» страницы.
>
> Легенда «Авто»: `✅` считается офлайн-скриптом · `🟡` нужен словарь/эвристика ·
> `🔴` нужен внешний источник/ручная разметка.

---

## Что уже есть в системе (v1) — не дублируем

Объём, тошнота (класс./академ.), водность, Ципф, читабельность (Флеш/Ганнинг),
плотность ключа, покрытие по базе запросов + упущенные запросы, заголовки H1–H6
(счёт), метатеги, изображения/alt, микроразметка, форматирование, типографика,
перелинковка 7×7, внутренняя уникальность, ориентация по интентам.

## A. Стилистика и тон (POS-анализ) — НОВОЕ · ядро «как написано»

|----|----------|----------------|------|

## G. Кросс-документный слой (для калибровки на 50 контентах)

Считается по набору, а не по одной странице — именно это даёт «рецепт генерации»:

| ID | Параметр | Что показывает |
|----|----------|----------------|
| `common_h2_tails` | Общие «хвосты» H2 (напр. «🎮 Категории игр») | шаблон структуры |
| `volume_band` | Типичный диапазон объёма (148–230 слов) | норма объёма генерации |
| `common_spec_fields` | Общий набор полей факт-таблицы | обязательные блоки |
| `shared_phrases` | Повторяющиеся фразы/конструкции между сайтами | «рыба» шаблона |
| `intent_per_page_pattern` | Какая страница = какой интент/угол (main/reg/bonus/…) | карта покрытия |
| `style_signature` | Усреднённый POS/тон-профиль набора | стиль автора/генератора |

## Приоритет для задачи «понять генерацию»

1. **F + D** (ИИ-почерк, чужие бренды, шаблонные повторы) — прямые улики автогенерации.
2. **A** (POS/стиль/обращение) — «как пишут».
3. **B** (фактура/E-E-A-T) — «что утверждают», справочность vs вода.
4. **C + E** (ключи, тема-угол, каркас H1/H2, факт-таблица) — «о чём и в каком формате».
5. **G** — рецепт по набору (нужно ≥ несколько десятков контентов, отсюда калибровка на 50).

## Реализуемость офлайн (PHP)

- **✅ сразу**: числа/%, эмодзи, бренд-варианты, чужие бренды (по базе 157 брендов),
  даты, топ-слова/биграммы, повторяющиеся конструкции, однообразие предложений,
  тексты H1/H2, строки таблиц, баден-баден зона.
- **🟡 через словари/эвристики**: POS-профиль (по окончаниям + список служебных слов),
  обращение/залог глаголов, канцелярит/клише/паразиты (словари), извлечение сущностей
  (доменные словари: провайдеры, платёжки, лицензии), тема-угол, FAQ, поля факт-таблицы.
- **🔴 вне офлайна**: точный синтаксический разбор, реальные поведенческие Яндекса.

> POS для русского без библиотеки делаем эвристикой (окончания + функциональные
> слова) — для распределения частей речи и тона этого достаточно; для полной
> морфологии позже можно подключить mystem/pymorphy.
