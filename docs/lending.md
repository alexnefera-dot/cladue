# Лендинг оферов из выкачанной страницы

Сохранённая браузером страница («страница.html» + папка «страница_files») превращается
в обычную статику:

```
index.html
css/styles.css
img/…
js/…          # только если на странице были свои скрипты
```

```bash
python3 scripts/lending.py <папка с выкачкой> -o <папка выдачи> \
        [--обрезать-с '<div class="…"'] [--заголовок "…"] [--описание "…"]
```

## Что делает

**Режет лишнее.** `--обрезать-с` удаляет разметку начиная с первого вхождения строки и до
конца тела. Так из главной страницы сайта остаётся только лендинг оферов: меткой берётся
первый элемент, который идёт сразу за лендингом.

**Отбирает CSS.** У выкачки в голове бывает под полмегабайта чужих стилей. Селекторы
проверяются в браузере по живому документу, текст правил берётся из исходника. Через CSSOM
их читать нельзя: сокращение с переменной внутри (`background: linear-gradient(…, var(--gold))`)
возвращается пустым, и текст с `background-clip: text` становится невидимым. Классы, которые
навешивают скрипты (активная вкладка, показанная липкая кнопка), в документе не видны, поэтому
правило остаётся и тогда, когда все его классы просто встречаются в исходнике страницы.

**Чинит пути.** Выкачка оставляет три вида: `./страница_files/x.png`, абсолютный путь живого
сайта (`/img/splash/stage-hero.webp`) и путь, который скрипт достраивает на ходу
(`` `/img/partners/${partner.image}` ``). Все три ведут в никуда, из-за них не грузятся фон и
логотипы. Переписываются и в HTML, и в CSS, и в перенесённых скриптах.

**Чистит голову.** Остаются charset, viewport, title, description и ссылка на стили. Счётчики
(Метрика, GA, GTM), prefetch чужих доменов, десятки блоков `ld+json` от удалённых страниц
удаляются. Скрипт-счётчик из папки выкачки не переносится вовсе.

**Прибирает имена.** `brand(1).png` → `brand-1.png`: в `img/` только строчная латиница, цифры
и дефис. Картинки, на которые после всех правок никто не ссылается, удаляются.

## Чем проверять

Открыть `index.html` и посмотреть, что все картинки живы:

```bash
NODE_PATH=/opt/node22/lib/node_modules /opt/node22/bin/node scripts/oform/снимок.js \
        <папка>/index.html снимок.png 1400 "#0d1016"
```

Разобранные шаблоны: `offer1` (ЛакиБир, из главной страницы сайта — с `--обрезать-с`),
`offer2` (Vegasy) и `offer3` (Mellstroy) — оба уже были отдельными лендингами.

## Что осталось от исходника

В шаблонах 2 и 3 заголовок первого экрана налезает сам на себя: у строк жёсткие размеры и
`margin: 0 !important`. Это в самой выкачке — в исходной странице ровно то же самое, —
и правкой путей не лечится.
