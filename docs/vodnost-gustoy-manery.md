# Водность густой манеры: семь замеров

Задача: у наших густых страниц водность 31–35 %, у их густых — 25–32 по
полосе p10–p90. Разрыв 2–4 пункта.

## Где сидит вода

Замер по частям страницы, наш густой набор против 17 густых наборов NEW100:

| часть | наше | корпус |
|---|---|---|
| проза | 34.3 % | 30.0 % |
| пункты списка | 30.8 % | 27.4 % |
| заголовки | 27.8 % | 28.1 % |

Заголовки в полосе. Разрыв — проза и пункты.

## Чьи это слова

На 1000 слов прозы, наше против их:

| гуще у нас | | гуще у них | |
|---|---|---|---|
| не | 29.96 / 15.67 | для | 2.12 / 10.45 |
| а | 15.64 / 5.92 | да | 0.27 / 5.79 |
| с | 21.21 / 14.00 | или | 3.71 / 9.03 |
| и | 44.01 / 39.76 | через | 3.71 / 6.17 |
| он | 4.24 / 1.11 | чтобы | 0.00 / 1.69 |
| его | 3.18 / 0.95 | от | 1.86 / 4.76 |

Первые три слова дают 3.1 пункта из 4.3. Это не наполнитель, а регистр:
наша манера отрицания и противопоставления против их номинального строя.

## Почему нельзя сушить пул целиком

Полоса водности обычной манеры **выше** густой:

| тип | обычная | густая |
|---|---|---|
| main | 26.0–33.0 | 20.3–28.9 |
| bonus | 31.0–37.4 | 23.6–29.8 |
| app | 31.1–37.8 | 20.2–30.9 |
| vhod | 30.8–35.7 | 27.6–31.1 |

Наши пулы настроены под обычную полосу и стоят в ней. Срез пула на 2.6
пункта увёл бы обычную манеру под нижнюю границу на восьми типах из
двенадцати. Значит правка обязана быть по манере.

## Семь замеров, одни и те же 16 сидов

| механизм | провалов приёмки |
|---|---|
| полосы по децилям, без правок воды | **6.62** |
| потолок водности в очереди выбора | 6.50 |
| потолок с разводом по цифрам | 7.25 |
| сухая половина пула, все слоты | 7.38 |
| сухая половина пула, только проза | 7.38 |
| сухая проза 132 записи, расход «сколько есть» | 7.50 |
| сухая проза 132 записи, расход в шестую часть | 6.94 |
| сухая проза 726 записей, расход в шестую часть | 7.06 |

Воду снимает каждый механизм: проза с 34.3 до 31.9 % на полном ходу,
страница с 32.4 до 31.1. Не окупается ни один.

| registracia | 13.3 | 45.2 | 14.1 | 10.3 / 30.7 / 26.2 |

Прилагательные в полосе. Тошнота 38.5–53.3 при корпусных 24.3–33.0:
записи одного типа вертятся вокруг одних слов — «приложение», «кабинет»,
«настройки», «код», «домен». Это и есть цена, которую платит страница.

## Что стоит в движке

`engine/data-v5/suhaya-proza-v5.json` — 726 записей, по 121 на каждый из
шести коротких типов густой манеры, вода 15.9 %. Ставится хвостом абзаца
добавкой, как фраза легенды. Порог включения — две тысячи записей на тип:
столько нужно, чтобы двадцать фраз на страницу стали шестьюдесятью (все
четыре пункта воды) и не повторялись между наборами. Пул лежит до этого
размера.

## Что делать дальше

1. Спецификация следующих партий разводит словарь: не больше двух записей
   на одно ключевое слово внутри типа, иначе тошнота записей остаётся 45+.
2. Объём — порядка двух тысяч на тип, то есть примерно двенадцать тысяч
   записей. Написано 726.
3. Проверка после каждой партии — та же гонка на 16 сидах против 6.62.
