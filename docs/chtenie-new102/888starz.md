## Формула написания, которую я вижу

**1. Скелет страницы.** Для типа страницы берётся список тем h2 (для info — верификация/ответственная игра/платежи/лицензия/поддержка/правила; для vhod — проблемы/пароль/соцсети/кабинет/безопасность; для partnery — выплаты/инструменты/стать партнёром/как работает/поддержка). Число текстовых разделов зависит от типа: main, obzor, info, partnery, slots, vhod — 6; news, promo, registracia — 4; bonus, zerkalo — 3; app — 2. Заголовок h2 строится из пары «Тема — Подзаголовок» через тире; в 1–2 заголовках на страницу подзаголовок содержит число из пула («До 500% на первый депозит», «RTP 96.4%», «Вывод за 15 минут», «Возврат до 30%», «За 2 минуты») или имя героя с суммой («Дмитрий Заработал 410 000 рублей», «Владислав сорвал 620к здесь», «Юрий играет уже год», «{NAME} входит каждый день»). Один h2 на страницу может быть «расширенным» зимней добавкой через двоеточие.

**2. Виджеты.** Вставляются по типу страницы, а не по содержанию текста: main — hero + навигация + «столпы» + каталог + джекпоты + лента; promo и slots — джекпоты + лента; vhod — «Ежедневные бонусы за вход»; obzor — блок отзывов вместо карточек; bonus — ничего. Числа в виджетах генерируются отдельно (джекпот МЕГА 16.2–16.8 млн, RTP каталога 96.09–96.71, hero «до 151 %», «от 8 мин») и никогда не совпадают с числами текста. Лента выплат — 6 строк, продублированных для бесконечной прокрутки.

**3. Раздел.** Базовый порядок: **абзац героя → абзац фактов → h3 → список 5–7 пунктов → финальный абзац-призыв.** Вариации, которые я вижу как случайный выбор из 3–4 компоновок: (а) герой и факты слиты в один длинный абзац (bonus р.2–3, promo р.1, slots р.5, vhod р.4); (б) три абзаца до h3 — герой, факты, «почему мы» (main р.4, info р.1/5/6, registracia р.2, obzor р.6); (в) факты первым абзацем, герой вторым (obzor р.5, slots р.1, partnery р.5); (г) под h3 сначала вводный абзац, потом список (12 разделов по набору). Финальный абзац всегда содержит 1–2 ссылки-CTA и минимум одну из формул «не заходи / гарантии — не сюда / добро пожаловать».

**4. Абзац героя.** Шаблон: [приём ввода] + [имя (+ «из <город>» с вероятностью ~20 %)] + [ситуация: «после работы», «просто посмотреть», «от нечего делать», «скептически»] + [действие со ссылкой на [слоты]/[регистрацию]/[Морозный Бонус]] + [время: «через полчаса», «через час», «спустя пару часов», «за несколько минут»] + [сумма из пула, часто с парой старт→финиш] + [оговорка «это не сказка, а реальный кейс / гарантий нет»]. Приёмы ввода — «Вот, например, X», «Помните X?», «Знакомьтесь, X», «Слышали истории…? Вот X». Герой, стартовая и финальная суммы берутся из пулов независимо от страницы, поэтому пары «3 тыс → 470 тыс», «2 тыс → 290 тыс», «500 → 83 тыс» гуляют по набору с разными именами, а одно имя (Юрий, Леонид, Илья) получает разные суммы.

**5. Абзац фактов.** Шаблон: [«можно выиграть, можно и проиграть» / «не обещаем золотых гор»] + [RTP из пула, с формулой «это не гарантия, а математика»] + [джекпот из пула «до N миллионов»] + [бонус «до N%» со ссылкой] + [время вывода из пула] + [«если нужны гарантии — это не сюда, это движ для смелых»]. Все четыре числа выбираются заново для каждого раздела — отсюда 5–6 разных RTP на странице. Число, вошедшее в раздел, почти всегда переписывается ещё раз в списке под h3 (RTP → «Честные шансы: RTP 95.2%», джекпот → «Крупный джекпот: 67.3 миллиона ждут», вывод → «Быстрый вывод средств (3 минуты)», бонус → «Стартовый пакет: до 400% бонусов»), реже — в h2 и в FAQ. Между разделами числа не согласуются: генератор не помнит предыдущий выбор.

**6. Список.** 5–7 пунктов вида «*Жирный ярлык:* пояснение» или просто «пояснение». Пул ярлыков один на весь набор: прозрачность / быстрый вывод / поддержка 24/7 / щедрые бонусы / мобильность (ссылка на [мобильное приложение]) / доступность (ссылка на [рабочее зеркало]) / «нет гарантий» / «реальные истории». Один пункт обязан содержать 1–2 ссылки на [промо акции], [информацию о …], [новости о …], [играть бесплатно]. Иногда герой возвращается в пункте («как у Даниила», «Борис смог вывести свои 310 000», «Денис – лишь один из многих»). В трёх местах (promo р.3, slots р.5, vhod р.4) список не сконвертирован из markdown и остался строкой с «* … * …» внутри абзаца.

**7. Ссылки.** В каждом разделе 3–6 анкоров из словаря типа страницы (для promo — «новости о промо акциях», «информацию о промокодах», «войдите и активируйте», «Морозный Бонус»; для vhod — «информацию о входе», «бонусы после входа», «рабочее зеркало»; для partnery — «партнерский кабинет», «новости для партнеров»). Анкор подставляется в готовой грамматической форме, поэтому регулярно не согласуется с предложением: «Полная [информацию о казино]», «зашел к нам в [регистрацию]», «полученный при [регистрацию]», «пора [регистрация] и [войти и играть]», «Наше казино — это [обзор] честности». Целевой URL берётся из шести значений; «промо/бонусы/промокоды» всегда → `/app`, «информация/новости/обзор/партнёрка/live» → `/`.

**8. FAQ.** Ровно 5 вопросов под h2 «❓ Честные ответы на вопросы». Состав: 3–4 «тематических» вопроса (по типу страницы), 1 «геройский» с именем и суммой в самом вопросе или в ответе («Реально ли Руслан выиграл(а) 2к → 290к?», «Как Роман отыграл(а) бонус?», «В каких слотах Олег выигрывает?», «Если ты Максим, который недавно выиграл 1.6 млн»), иногда 1 метавопрос («Почему пишете „не заходи, если боишься“?»). Ответ — 1 или 2 абзаца (двухабзацный на main, promo, bonus, app, registracia, vhod, zerkalo; одноабзацный на obzor, news, info, partnery, slots), 1–2 ссылки, обращение на «ты» с «(а)», и кикер из пула: «Решать всё равно тебе.», «Если готов(а) — заходи и проверяй сам(а).», «Хочешь попробовать — начни с бонуса.», «Если боишься риска — проходи мимо.» Значения в FAQ берутся из пулов заново и спорят с телом (бонус 750 % на news, 1000 % на registracia, 600 % на promo и zerkalo, 175 % на app).

**9. Финальный блок.** Класс `page-thematic-block … variant-v1`, позиция `layout-block-pos-3`. Название по типу страницы («О портале», «Типы акций и промо», «О чём пишем в новостях», «Разделы информации», «Условия для партнёров», «Преимущества приложения», «Шаги регистрации», «Полезно знать о слотах», «Вход в личный кабинет», «Как пользоваться зеркалом»; на obzor — «Что пишут игроки»). Четыре карточки «заголовок + 2–3 предложения», без темы, без цифр из пула, без формул — это единственный слой, написанный «нормально» и, судя по стилю, из отдельного статичного шаблона. На bonus блок отсутствует; на vhod он стоит после виджета «Ежедневные бонусы».

**10. Общее и специфичное.** Общее для всех страниц: тон «честного циника», формульный финал раздела, 5 FAQ с кикерами, 6-адресная карта ссылок, независимая рандомизация RTP/бонуса/джекпота/вывода в каждом разделе, пул имён и сумм. Специфичное для типа: набор h2-тем, словарь анкоров, состав виджетов, название финального блока, а также «включённость» зимней темы (на main и news выключена). На vhod дополнительно перемешан порядок (FAQ после первого раздела), а в h2 остался `{NAME}`.

## Сбои и швы генератора

1. **Незаполненный плейсхолдер в заголовке** — vhod, h2: «{NAME} входит каждый день — Как это делает он», в теле герой — Пётр.
2. **Противоречие h2 и тела** — main: «Быстрые выплаты — Вывод за 15 минут (проверено игроками)» → «среднее время вывода средств у нас – 3 минуты!» → «Фёдор свои 1.3 миллиона получил в течение 10 минут». Partnery: «Быстрые выплаты — Раз в неделю» → «вывод займёт до 30 минут». Bonus: «Кэшбэк — Возврат до 30%» → герой «вернул 15% от проигранного».
3. **Один герой — разные суммы на одной странице** — main: Юрий «25 000 рублей» (раздел 1) и «рискнул своими 500₽ и сорвал куш в 83к» (FAQ). Info: Илья «3 тысяч → 470 тысячами» (раздел 3) и «как у Ильи, 270к» (FAQ). Vhod: Павел без суммы в истории и «Павлу подобный куш в 500к» в финале того же раздела.
4. **Одна пара сумм — разные герои рядом** — info: Илья «со скромных 3 тысяч, а вышел… с 470 тысячами» и через два раздела Андрей «его скромные 3 тысячи превратились в ослепительные 470 тысяч». Zerkalo: Кирилл «2 тысячи рублей превратились в… 290 тысяч», Николай «из скромных 2 тысяч рублей за вечер вытащил 380 тысяч». Registracia: «Кирилл, обычный парень из Твери» и «Эдуард, обычный парень из Твери».
5. **Три размера одного бонуса на одной странице** — app: «Морозный Бонус – 100% на первый депозит», «целых 400% к первому депозиту», «Морозный Бонус в целых 175%». Vhod: 600 / 1000 / 100 / 150 / 400 / 200 %. Registracia: «до 200%» ×4 и в FAQ «до 1000%».
6. **Совет против собственных цифр** — slots: «Всегда проверяйте RTP слота: ниже 96% — уже сомнительная снежинка» на странице с «RTP 94.8% и чистая удача сошлись в одной точке».
7. **Списки, не сконвертированные из markdown** — promo, раздел «Фриспины»: «мы приготовили: * Возможность активировать до 125% бонусов на первое пополнение. * Ежедневные фриспины за активность…». То же в slots «Джекпот слоты» («* Наш Морозный Бонус в 450%… * Реальный шанс сорвать джекпот…») и vhod «Вход через соцсети» («* Мгновенный старт: … * Безопасность: …»).
8. **Ссылка-анкор в чужом падеже** — main: «Полная [информацию о казино]»; obzor: «Он зашел к нам в [регистрацию] без особых ожиданий», «вся [информацию о казино] можно найти легко»; promo: «Морозный Бонус, полученный при [регистрацию]»; partnery: «Морозный Бонус до 600% при [регистрацию]», «наша [информацию о партнерской программе] самая честная»; slots: «то пора [регистрация] и [войти и играть]»; zerkalo: «Наше [информацию о зеркалах] всегда актуальна»; registracia: «Наше казино — это [обзор] честности и прозрачности».
9. **Бессмысленные предложения от подстановки ссылки** — info: «Ты всегда можешь приостановить свою [регистрацию] или установить лимиты»; «Мы поддерживаем [партнерскую программу], но никогда не принуждаем к игре»; vhod: «а может, и крупнее – до [промокодов] до джекпота в 89.5 миллионов?»; slots: «Возможность сорвать Джекпот до 4.1 млн: да, даже на демо вы можете увидеть потенциальный масштаб выигрыша»; partnery: «Мы честны на все 97.2% RTP».
10. **Пропущенный пробел после жирного ярлыка** — promo: «*Вход в систему:*[Войдите и активируйте] свой код».
11. **Ссылки на несуществующие цели** — все «[новости о …]», «[информацию о …]», «[обзор казино]», «[партнерская программа]», «[live казино]» ведут на `/`; «[промо акции]», «[бонусы]», «[промокоды]», «[Морозный Бонус]» — на `/app`. Страницы bonus, promo, news, info, obzor, partnery не имеют входящих ссылок.
12. **Прямая речь с гиперссылками** — obzor: «„Сначала я просто хотел [играть бесплатно], изучить [слоты]…“ — Анна, игрок с двухлетним стажем»; «„Почитав [новости казино], решил попробовать…“ — Михаил, новичок».
13. **Зимняя тема включена/выключена по странице** — main и news: 0 упоминаний «северного сияния», «Морозного Бонуса», «Ледяного Королевства»; obzor/promo/vhod — по 7–11 на страницу. При этом главная ссылается на «[бонусы]», которые на других страницах называются «Морозный Бонус».
14. **Виджеты спорят с текстом** — main hero: «Бонус до 151%», «Вывод от 8 мин», «столпы»: «От 15 минут до суток», ниже текст: «до 500%», «3 минуты». Полоса джекпотов: 16 773 538 ₽ (main), 16 328 360 ₽ (promo), 16 232 592 ₽ (slots) при текстовых «67.3 миллиона», «120.0 миллионов». Лента выплат — те же шесть строк дважды («🎰 Роман — 1 646 ₽ 👸 Starlight Princess 18 минут назад» ×2).
15. **Смена обращения внутри раздела** — main, раздел 2: три абзаца на «вы» («Вы можете выиграть…»), финал — «Не заходи, если боишься проиграть. Но если ты готов к настоящему азарту…». Info, «Ответственная игра»: «если вам нужны гарантии» → список на «ты» («помни, это не подарок»).
16. **Гендерная скобка в вопросах про мужчин** — «Реально ли Юрий выиграл(а) 500₽ → 83к?», «Как Роман отыграл(а) бонус?», «Реально ли Руслан выиграл(а) 2к → 290к?»; на zerkalo кикер, наоборот, без скобки: «Если готов — заходи и проверяй сам.»
17. **Формула, не адаптированная к типу страницы** — partnery: «Не заходи, если боишься проиграть. Но если ты готов к азарту, этот мир ждёт тебя» (партнёр ничего не проигрывает); герои партнёрской страницы — игроки с выигрышами (Илья 2.0 млн, Андрей 1.1 млн). Info, «Ответственная игра»: рядом с инструментами самоограничения — «Морозный Бонус до 400%… инструмент для тех, кто готов рисковать».
18. **Дублирующиеся заголовки** — vhod: h2 «Вход в личный кабинет — Быстро и просто» и финальный блок h2 «Вход в личный кабинет»; news: h3 «Ваш Шанс на Большой Куш или Горький Урок?» и «Ваш Шанс на Большую Игру или Где Искать Свои Приключения»; obzor: h3 «Отзывы, которые не тают на солнце» и «Ледяные Ранги: Отзывы, Которые Не Тают».
19. **Выигрыш героя = «джекпот» из пула** — info: Тимур выиграл «3.2 миллиона», и на той же странице «снежный джекпот в 3.2 миллиона» дважды как потолок; app: Владимир «сорвал джекпот, принесший ему… 2.5 миллиона», а джекпот раздела — 6.9.
20. **Дословные повторы между страницами** — «Не заходи, если боишься проиграть.» — 14 раз на 9 страницах; «Если готов(а) — заходи и проверяй сам(а).» — 7 раз; «Если нужны гарантии — это не сюда.» — 4 (плюс варианты с «–»); «Хочешь попробовать — начни с бонуса.» — 4; «Это не сказка, а реальный кейс.» — дважды на одной main.
21. **Пустые обещания вместо контента типа** — news без дат и названий («Призовой фонд пока держим в секрете»), slots «Провайдеры» без единого провайдера и «Новинки 2026» без названий, zerkalo без ссылки на зеркало, promo без промокода, app «Пошагово» без шагов установки, partnery без ставки комиссии — весь предметный контент отдан четырём карточкам финального блока.
22. **Мелкие опечатки и артефакты** — info: «настoящий» (латинская o); zerkalo: «морозному сиянию .» (пробел перед точкой), «движ для смелых ,»; obzor: «[оценить %brand_name_ru%]» — плейсхолдер бренда внутри анкора, бренд среднего рода («наше %brand_name_ru%», «любое %brand_name_ru%», «в нашем %brand_name_ru%»).
