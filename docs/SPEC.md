# ТЗ: «Pipboy» — личная платформа роста

> Рабочее название — **Pipboy** (как Pip-Boy из Fallout: единое устройство со всей информацией о владельце). Название можно поменять в любой момент.

**Версия документа:** 0.2 · **Дата:** 2026-06-10 · **Статус:** черновик на обсуждении

---

## 1. Видение

Единая локальная платформа, которая заменяет Notion, заметки iPhone, Snowball (учёт портфеля), Monefy (расходы), таск-менеджер и трекеры привычек. Все сущности живут в одной зашифрованной базе и связываются между собой: заметка ↔ задача ↔ цель ↔ актив ↔ событие ↔ практика.

### Принципы

1. **Local-first.** Все данные на устройстве. Синхронизация (фаза 2, iPhone) — только end-to-end шифрованная.
2. **Всё зашифровано + приватные зоны.** База — зашифрованный файл (SQLCipher). Отдельные зоны (Финансы, Психология, Интим) требуют **повторного ввода пароля** и автоблокируются.
3. **Всё связано.** Связи — первоклассный объект: блокировки, зависимости, «до/после», вложенность.
4. **Никакого вендор-лока на самих себя.** Полный экспорт в Markdown + JSON.
5. **Дашборд не выдаёт секретов.** Главный экран показывает только публичный (для случайного взгляда) слой.

## 2. Платформа и стек

| Слой | Выбор | Почему |
|------|-------|--------|
| Язык/UI | Swift + SwiftUI | Одна кодовая база macOS → iOS; EventKit, Shortcuts, позже HealthKit |
| Хранилище | SQLite через GRDB + SQLCipher | Зашифрованная БД-файл; FTS5 для поиска |
| Ключи | Keychain + Secure Enclave | Touch ID; отдельные ключи для приватных зон |
| Вложения | ChaCha20-Poly1305 (CryptoKit) | Сканы, PDF, картинки |
| Котировки | Опциональный API по явному согласию (ETF/BTC/золото/валюты) + ручной ввод как fallback | Пользователь хочет автотрекинг цен; приватность — через явный opt-in, наружу уходят только тикеры |
| Синк (фаза 2) | CloudKit private DB с клиентским шифрованием или зашифрованный бандл в iCloud Drive | E2E |
| Импорт | Notion export (zip), Apple Notes (AppleScript), **Monefy CSV**, банковские CSV, **список целей 500+ строк** | Разовая миграция + регулярные импорты |

Минимальная цель: **macOS 14+**, позже iOS 17+ (включая «микро-апку» ввода расходов на телефоне — замена Monefy).

## 3. Приватные зоны (ключевая механика)

| Зона | Что внутри | Доступ |
|------|-----------|--------|
| **Публичная** | Задачи, цели (без сумм), Инфо, календарь, рутины, месяц активности | Основной пароль / Touch ID |
| **Финансы 🔒** | Портфель, счета, расходы/доходы, пассивы, FIRE, макро | Повторный ввод пароля |
| **Психология 🔒** | Майндсет, практики, колесо, рабочий лог, журнал | Повторный ввод пароля |
| **Интим 🔒** | Личный дневник, что угодно сверхприватное | Повторный ввод пароля |

- Автоблокировка зоны по таймауту (настраивается, по умолчанию 5 минут) и при сворачивании приложения.
- Дашборд и поиск **не показывают содержимое заблокированных зон** — только заглушки («🔒 Финансы: 3 напоминания»). Суммы нигде не «протекают» в уведомления.
- Сущности из приватных зон могут ссылаться на публичные задачи (например, шаг портфеля создаёт задачу «Купить облигации» — без суммы в публичном слое, сумма видна по разблокировке).

## 4. Модель данных

Все сущности: `id`, `createdAt`, `updatedAt`, `archivedAt?`, теги, `privacyZone` (public/finance/psychology/intimate).

### Ядро

| Сущность | Ключевые поля |
|----------|---------------|
| **Note** (страница «Инфо») | title, блоки, parentNoteId, icon, isPinned |
| **Task** | title, описание, status, priority (P0–P3), dueDate?, scheduledDate?, parentTaskId, recurrenceRule?, контекст-пометка «как стоило бы поступить» |
| **TaskDependency / GoalDependency** | predecessor → successor, type (**блокирует / дополняет / зависит от решения**) |
| **Event** | title, даты, type (событие/дедлайн/платёж/напоминание/практика), source; **обратная связь: выполнение события дополняет цель/задачу** |
| **Goal** | title, horizon (жизнь/год/квартал/месяц/неделя), parentGoalId, kind (**глобальная / направление / энергия**), wheelAreaId?, метрика |
| **Decision** (узел решения) | вопрос («Резидентство SK?», «Город Б или В?»), варианты, status (открыто/принято/пересмотр), принятое решение + дата; **задачи и другие решения могут зависеть от него** |
| **Link** | универсальная связь между любыми сущностями |

| Сущность | Ключевые поля |
|----------|---------------|
| **Account** (счёт) | name, type (брокер/банк/кэш/ячейка/крипто-кошелёк), currency, balance, balanceUpdatedAt — **обновление в один клик инлайн** |
| **Instrument** | ticker, type (ETF/акция/облигация/крипто/золото/валюта), источник цены (API/вручную), lastPrice, priceUpdatedAt |

| **TargetAllocation** | class/instrument → целевая доля %; прогресс к целевому портфелю |
| **PortfolioStep** (план шагов) | type (купить/продать/перевести), instrument, сумма/кол-во, plannedDate?, условие («когда X < Y»), status; → может создавать задачу и событие |
| **Liability / Obligation** | кредиты, **аренда ячеек, оплата квартир** — любые регулярные обязательства: сумма, расписание, remindDaysBefore |

| **MacroNote** | моя оценка фазы цикла, тезисы, дата; история тезисов |
| **Snapshot** | дата + нетворс + стоимость портфеля — для графиков |

## 5. Функциональные модули

### 5.1 Дашборд «Сегодня»

- Задачи дня + просроченные, события, рутины со стриками.
- **Месяц активности** («июнь — падл») и ближайший «классный план» из «Энергии жизни».
- Прогресс недельных целей.
- **«Движение недели»** — где есть прогресс, включая мелкие шаги (§5.14).
- **Люди:** ближайшие ДР и просроченные контакт-ритмы.
- Заглушки приватных зон: «🔒 Финансы — 3 напоминания на неделе», без сумм и названий.
- Быстрый ввод ⌘N → Inbox.
- **Никаких секретных данных** — экран можно показать кому угодно.

### 5.2 Задачи

Как в v0.1 (виды список/дерево/доска, P0–P3, подзадачи, повторы, вкладки «План» и «Лог») плюс:

- **Двусторонняя связка с календарём:** задачу можно отправить в календарь (с уточнением времени или без); выполнение события в календаре отмечает шаг и **дополняет список целей** записью «сделано».
- Поле-пометка «как стоило бы поступить» — переносится из текущего 500-строчного листа.

### 5.3 Цели (отдельный модуль)

- **Глобальные цели и направление жизни** — верхний уровень; под ними год → квартал → неделя.
- **Граф зависимостей между целями и задачами:** «блокирует», «дополняет», «зависит от решения» (решение выше по списку меняет смысл задач ниже — это явный тип связи).
- **Импорт текущего списка (500+ строк) и «режим разбора»** — см. §5.3.1: типизация строк, радар блокеров, дубли, временные коллизии.
#### 5.3.1 Режим разбора (импорт жизненного списка)

Исходный формат: вложенный список по категориям жизни (P1…P5 по убыванию важности), внутри каждой — вперемешку переживания, планы, микрозадачи, решения, идеи, вопросы, принципы («НЕ СПЕШИМ до 2028»).

**Шаг 1 — импорт «как есть».** Список сохраняется целиком как **«Источник»** (read-only оригинал с нумерацией). Ничего не теряется; каждая созданная сущность хранит ссылку на исходную строку.

**Шаг 2 — типизация строк.** Каждая строка при разборе получает тип (автоподсказка по эвристикам, подтверждение в один клик):

| Тип | Эвристика | Куда превращается |
|------|-----------|-------------------|
| **Вопрос** | заканчивается на «?» | вопрос при Decision или задаче («Как мы покупаем в SK? Бюджет?») |
| **Решение** | вопрос с вариантами, развилка | **Decision** — узел, от которого зависят задачи ниже и в других ветках |
| **Задача** | начинается с глагола | Task с датой/приоритетом («Август продать x5» → срок авг) |
| **Тревога** | эмоциональная формулировка | → дневник тревог в Психологии + опционально задача |
| **Идея** | «стоит ли…», сослагательное | бэклог идей при цели |
| **Принцип/ограничение** | CAPS, императив без действия | ограничение на ветке («НЕ СПЕШИМ до 2028» подсвечивается на всех задачах MX5) |
| **Категория** | верхний уровень | Goal/группа, наследует приоритет P1…P5 |

**Шаг 3 — «радар блокеров»** (главный механизм против «смотрю на продажу авто, а забыл про налоги»). При разборе или открытии любой задачи система автоматически показывает панель:

1. **Цепочка вверх** — родительские категории и их принципы/ограничения.
2. **Упоминания в других ветках** — полнотекстовый поиск по всему источнику и базе: «x5» найдено также в «Семья → Сделать до росписи → Продать x5» → предлагается **объединить дубли** в одну задачу с двумя контекстами (и взять более ранний дедлайн).
3. **Временно́е окно** — все обязательства/дедлайны/события ±2 месяца от даты задачи: «авг 2026: налоги за 2025 не закрыты ⚠, транш за квартиру в сентябре».
4. **Денежное окно** — крупные притоки/оттоки из Финансов рядом по времени (продажа авто = приток → предложить связать с планом шагов портфеля).
5. **Открытые решения рядом** — незакрытые Decision, влияющие на ветку («Резидентство SK?» влияет на MX5 и легализацию).

**Шаг 4 — pre-flight перед исполнением.** Крупная задача (флаг «важная») перед стартом показывает чеклист: открытые блокеры, ограничения ветки, коллизии окна времени/денег. Нельзя «случайно» продать авто, не увидев налоги.

**Процесс:** разбор инкрементальный — по ветке за раз, прогресс виден (N из M строк). Неразобранные строки продолжают искаться поиском и попадать в радар упоминаний, поэтому даже неразобранный хвост списка не теряется.

**Подготовка источника (опционально, до импорта):** разметка ускоряет автотипизацию — `?` вопросы уже есть, добавить `!` для тревог, `#x5`-теги для сквозных тем, даты в строках («август», «до 2028», «январь») парсятся автоматически.

- **«Энергия жизни»** — раздел внутри Целей: списки желаний (в т.ч. перенесённые «желания внутреннего ребёнка» из психологии), классные планы покупок, путешествий, развлечений, идеи наполнить жизнь эмоциями. **Месяц активности**: выбираем тему месяца, она видна на дашборде.
- Крупные покупки из «Энергии» связываются с PlannedExpense в Финансах (сумма — в приватной зоне, название плана — в публичной).
- **Эксперименты против шаблона** (включаются по желанию): **рулетка спонтанности** — случайная идея из твоего же бэклога под свободный слот («ты сохранил „картинг“ 8 месяцев назад — суббота свободна»); **банк впечатлений** — копилка идей отовсюду (места, рестораны, активности); **энергоаудит** — пометка «дало/забрало энергию» у событий → квартальный отчёт источников и стоков.

### 5.4 Инфо (заметки) — наш аналог Notion

Без изменений к v0.1: блочный редактор, `/`-меню, вложенные страницы, `[[вики-ссылки]]`, бэклинки, шаблоны, импорт Notion (разово) и Apple Notes. Страницы могут принадлежать приватной зоне (майндсет-страницы живут в Психологии тем же редактором).

### 5.5 Календарь

Как в v0.1 (единая лента: события + дедлайны + деньги + ревью + **практики по расписанию**). Финансовые события в заблокированном состоянии зоны показываются без сумм («платёж 🔒»).

### 5.6 Финансы 🔒 (замена Snowball)

Вкладки: **Обзор · Портфель · Счета · Расходы · Доходы · Пассивы · FIRE · Макро**.

**Портфель:**
- Позиции по счетам и классам; автотрекинг цен **ETF, BTC, золота, валют** (opt-in API, обновление по кнопке/расписанию; ручной ввод всегда доступен).
- **Текущий vs целевой vs планируемый:** целевая аллокация, прогресс к целевому (общий % и по классам), отклонения.
- **План шагов:** очередь покупок/продаж/переводов с датами или условиями; шаг → задача + событие в календаре; после исполнения — фиксируется транзакцией. История шагов = журнал сделок с причиной («почему купил»).
- XIRR, история нетворса, мультивалютность (базовая валюта + курсы из трекинга валют).

**Счета:** все балансы на одном экране, **инлайн-обновление в один клик**, дата последнего обновления, сигнал «баланс не обновлялся X недель».

**Расходы:**
- Текущие — **импорт из Monefy (CSV)** с маппингом категорий; позже ввод в своей микро-апке на iPhone.
- Категории, месяц/год, тренды.
- **Планируемые крупные траты** (PlannedExpense) с горизонтом — попадают в прогноз кэшфлоу.

**Доходы:** факт / план / потенциал (с вероятностью) + **дебиторка** (невыплаченные доходы: кто, сколько, когда ждём, напоминание при просрочке).

**Пассивы и обязательства:** кредиты, **аренда ячеек, оплата квартир** — расписания платежей и напоминания за N дней.

**FIRE:** целевой капитал, ставка изъятия, прогноз даты финансовой независимости от доходности и нормы сбережений; прогресс-бар.

**Макро:** моя текущая оценка фазы цикла (экспансия/пик/сжатие/дно), тезисы и ожидания с датами, история тезисов («что я думал в марте»), ручные индикаторы-заметки. Связь с планом шагов («шаг активен, пока тезис в силе»).

**Прогноз кэшфлоу:** факт + планы + подписки + пассивы + крупные траты + потенциалы (взвешенные) → график 3–12 мес, предупреждение о минусе.

### 5.7 Психология 🔒

- **Майндсет:** страницы из Notion переезжают сюда (тот же редактор Инфо, зона psychology).
- **Колесо развития** живёт здесь: сектора, замеры 1–10, радар, динамика, привязанные цели/задачи/практики.
- **Конструктор практик** — лёгкое создание и ведение:
  - по расписанию: «тревоги по расписанию» (вт/чт 19:00), «подъём утром», «в рабочие дни»;
  - пошаговые техники: «позитивное намерение — 7 шагов» (мастер ведёт по шагам, лог ответов);
  - чеклисты-фильтры: «выбор инвестиций» (пройти перед сделкой), «авто»;
  - регулярные активности: спорт, падл, психолог.
  - У каждой практики: расписание → события в календаре, трекинг выполнения, стрики, заметки к сессии.
- **Рабочий лог:** быстрые датированные записи «что делал по работе» — для ревью и самонаблюдения.
- Списки желаний внутреннего ребёнка **создаются здесь, но живут в Целях → Энергия жизни** (вынос из психологии в общие планы — по решению пользователя).

### 5.8 Рутины — первоклассный модуль, отдельно от задач

Микро-действия (таблетка, миноксидил, отжимания, витамины…) **никогда не попадают в списки задач** — у них свой экран и свой виджет на дашборде:

- слоты утро/день/вечер + дни недели; чек в один тап; количественные рутины («отжимания 3×15»);
- стрики и тепловая карта по каждой рутине;
- **антидолг-принцип:** пропущенная рутина не «висит» и не переносится — день закрылся, статистика учла, без чувства вины;
- привязка к практике или сектору колеса — опциональна.

### 5.9 Журнал и ревью

Как в v0.1: дневник (mood/energy), журнал решений с отложенной проверкой, авто-ревью недели/месяца/года. Зона intimate — для сверхличного.

### 5.10 Поиск, граф, импорт/экспорт

- ⌘K-поиск (приватные зоны ищутся только когда разблокированы).
- Граф связей (v2).
- Импорты: Notion, Apple Notes, Monefy CSV, банковские CSV, список целей.
- Экспорт всего одной командой.

### 5.11 Люди

- Карточка человека: ДР (напоминание за N дней), заметки (что любит, семья), лог идей подарков, история контактов.
- **Контакт-ритм:** желаемая частота общения («мама — раз в неделю», «Дима — раз в месяц») → подсветка «давно не общались» + постановка созвона в календарь одной кнопкой.
- Связи с задачами и событиями («спросить у Игоря про рынок авто»).
- ДР и просроченные созвоны — публичный слой (видны на дашборде); заметки о людях можно убрать в приватную зону.

### 5.12 Имущество и регламенты

- Карточки объектов **по категориям** (авто / недвижимость / техника …): регламент обслуживания (ТО, страховка, резина, счётчики, продления) → повторяющиеся задачи и напоминания о датах истечения.
- Наглядный обзор: категория → объекты → ближайшие регламентные события; просроченное подсвечено.
- Чеклист «Авто» из практик становится регламентом карточки авто.

### 5.13 Трекинг — кастомный, без фанатизма

- **Чек-ин дня (опционально, 10 секунд):** день «плохой / нормальный / хороший» + одна строка заметки.
- **Конструктор метрик:** трекается только то, что пользователь сам создал (кофе, падл-часы, страницы…). Тип: число / да-нет / шкала. График и тепловая карта по каждой.
- Никаких обязательных полей и браслетов; пропуски — норма, не ошибка.
- Раз в месяц — простые корреляции по накопленному (детерминированная статистика, без ИИ).

### 5.14 Динамика и похвала (кросс-модульная механика)

- В каждом модуле — блок **«Движение»**: дельта за неделю/месяц (закрытые шаги, % прогресса целей, выполнения практик, приближение к целевому портфелю).
- На дашборде — **«Движение недели»**: направления, где есть прогресс, **включая мелкие шаги**, и серии («3-я неделя подряд с движением по Переезду 🔥»).
- Похвала сдержанная и честная: считаются реальные действия, без очков, уровней и геймификации. Цель — видеть «я двигаюсь», особенно когда шаги мелкие.
- Механика закладывается с M1: каждая сущность с прогрессом умеет отдавать дельту за период.

### 5.15 Журнал прогнозов (внутри Финансов)

- Запись: «думаю, X случится — уверенность 70%» с привязкой к сделке или макро-тезису.
- По сроку система спрашивает «случилось?» и считает **калибровку**: насколько твои «70%» — настоящие 70%. Показывается во вкладке Макро.

### 5.16 Годовой отчёт и память (зона Интим)

- **Годовой отчёт** — автособранные итоги года из всех данных; живёт в зоне Интим, не в Финансах.
- **«Этот день год назад»** — виджет из журнала; тоже Интим, на публичный дашборд не выводится.

## 6. Безопасность

Как в v0.1 (SQLCipher AES-256, Secure Enclave, Touch ID, шифрованные вложения и бэкапы, нулевая телеметрия) **плюс**:

- **Без ИИ и облаков.** Типизация, радар блокеров, поиск дублей, парсинг дат — детерминированные алгоритмы (эвристики, FTS5, SQL) внутри локальной зашифрованной базы. Никаких внешних AI-сервисов, аккаунтов и передачи данных; платформа полностью работает с выключенным интернетом. Единственные сетевые функции — котировки (opt-in, наружу только тикеры) и E2E-синк (opt-in, фаза 2).
- Приватные зоны с повторным паролем и раздельными ключами (см. §3).
- «Режим кафе» 👁: одним нажатием все суммы → `•••` даже в разблокированной зоне.
- Сетевые запросы только явные: котировки — отдельный тумблер, наружу уходят только тикеры.
