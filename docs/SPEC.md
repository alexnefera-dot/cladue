# ТЗ: «Pipboy» — личная платформа роста

> Рабочее название — **Pipboy** (как Pip-Boy из Fallout: единое устройство со всей информацией о владельце). Название можно поменять в любой момент.

**Версия документа:** 0.1 · **Дата:** 2026-06-10 · **Статус:** черновик на обсуждении

---

## 1. Видение

Единая локальная платформа, которая заменяет Notion, заметки iPhone, таск-менеджер, финансовые таблицы и трекеры привычек. Все сущности живут в одной зашифрованной базе и связываются между собой: заметка ↔ задача ↔ цель ↔ актив ↔ событие.

### Принципы

1. **Local-first.** Все данные лежат на устройстве пользователя. Никаких сторонних серверов. Синхронизация (в будущем, для iPhone) — только end-to-end шифрованная.
2. **Всё зашифровано.** База — один зашифрованный файл (SQLCipher). Ключ — в Keychain / Secure Enclave, разблокировка по Touch ID или паролю.
3. **Всё связано.** Любая сущность может ссылаться на любую другую. Связи — первоклассный объект системы, а не послесловие.
4. **Никакого вендор-лока на самих себя.** Полный экспорт в Markdown + JSON в один клик.
5. **Один экран правды.** Дашборд «Сегодня» отвечает на вопрос «что мне делать и что меня ждёт» без переключения между модулями.

## 2. Платформа и стек

| Слой | Выбор | Почему |
|------|-------|--------|
| Язык/UI | Swift + SwiftUI | Одна кодовая база macOS → iOS; нативный доступ к EventKit, Shortcuts, позже HealthKit |
| Хранилище | SQLite через GRDB + SQLCipher | Одна зашифрованная БД-файл; быстрые запросы; FTS5 для поиска |
| Ключи | Keychain + Secure Enclave | Разблокировка Touch ID; ключ не покидает устройство |
| Вложения | Файлы, шифрованные ChaCha20-Poly1305 (CryptoKit), ключи в БД | Сканы документов, PDF, картинки |
| Синк (фаза 2) | CloudKit private DB с клиентским шифрованием **или** зашифрованный бандл в iCloud Drive | Данные уходят с устройства только зашифрованными |
| Импорт | Notion export (zip/markdown+csv), Apple Notes через AppleScript, банковские CSV | Разовая миграция + регулярный импорт транзакций |

Минимальная цель: **macOS 14+**, позже iOS 17+.

## 3. Модель данных

Все сущности имеют: `id (UUID)`, `createdAt`, `updatedAt`, `archivedAt?`, произвольные теги.

### Ядро

| Сущность | Ключевые поля |
|----------|---------------|
| **Note** (страница) | title, иерархия блоков (см. 4.2), parentNoteId (вложенные страницы), icon, isPinned |
| **Task** | title, описание (rich), status (inbox/todo/doing/done/cancelled), priority (P0–P3), dueDate?, scheduledDate?, parentTaskId (подзадачи), recurrenceRule?, estimate?, energyLevel? |
| **TaskDependency** | predecessorId → successorId (отношения «до/после»; запрет циклов) |
| **Event** | title, dateStart, dateEnd?, type (событие/дедлайн/платёж/напоминание), recurrenceRule?, source (свой/EventKit/финансы) |
| **Goal** | title, horizon (год/квартал/месяц/неделя), parentGoalId, wheelAreaId?, targetMetric?, status |
| **Link** | fromEntity(type,id) → toEntity(type,id), linkType (relates/blocks/follows/child/mentions), note? — **универсальная связь между любыми двумя сущностями** |

### Финансы

| Сущность | Ключевые поля |
|----------|---------------|
| **Asset** | name, class (акции/облигации/крипто/кэш/недвижимость/бизнес/прочее), currency, quantity, costBasis, currentPrice (ручной ввод или импорт), notes |
| **Liability** (пассив) | name, principal, rate?, paymentAmount, paymentDay/schedule, endDate?, remindDaysBefore |
| **Subscription** | name, price, currency, period (мес/год), nextChargeDate, category, lastUsedAt?, status |
| **Transaction** | amount, currency, date, direction (доход/расход), kind (**факт / план / потенциал**), category, recurrenceRule?, probability? (для потенциальных), linkedAssetId? |
| **Snapshot** | дата + стоимость портфеля/нетворс — для графиков истории |

### Рост

| Сущность | Ключевые поля |
|----------|---------------|
| **WheelArea** | name (здоровье, финансы, карьера, отношения, …), order, color |
| **WheelAssessment** | date, оценки 1–10 по каждой области — история замеров колеса |
| **Routine** | name, slot (утро/день/вечер/неделя), items[] (чеклист), активные дни |
| **RoutineLog / HabitLog** | date, completed items — для стриков и статистики |
| **JournalEntry** | date, type (дневник/решение/ревью), content, mood?, energy? |
| **Review** | period (неделя/месяц/год), автособранные метрики + ответы на вопросы |

## 4. Функциональные модули

### 4.1 Дашборд «Сегодня» (главный экран)

- Задачи на сегодня + просроченные (топ по приоритету).
- События календаря на сегодня/завтра.
- **Платежи на 7 дней вперёд**: подписки, пассивы — с суммой.
- Рутины дня с чекбоксами и текущим стриком.
- Виджет нетворса: число + спарклайн за 30 дней.
- Быстрый ввод (⌘N): «закинуть в Inbox» — текст превращается в задачу/заметку/трату без ухода с экрана.
- Строка статуса в духе Pip-Boy: дата, дней до конца квартала, прогресс недельных целей.

### 4.2 Инфо (заметки) — наш аналог Notion

> Модуль в интерфейсе называется **«Инфо»**; внутренняя сущность — Note (страница).

Редактор — **блочный**:

- Типы блоков: текст, заголовки H1–H3, чеклист, маркированный/нумерованный список, цитата, код, разделитель, тоггл (сворачиваемый), callout, изображение/вложение, таблица (простая), embed-ссылка на любую сущность платформы.
- Markdown-ввод на лету (`#`, `-`, `[]`, `>` …), `/` — меню вставки блока.
- **Вложенные страницы** — дерево любой глубины (замена структуры Notion).
- **Вики-ссылки** `[[...]]` на заметки, задачи, цели, активы. Автодополнение.
- **Бэклинки**: панель «кто ссылается на эту страницу».
- Шаблоны страниц (ревью недели, план задачи, разбор актива…).
- Пин, архив, корзина (30 дней).
- Вложения шифруются на диске; превью PDF/картинок внутри приложения.

**Импорт из Notion:** разбор официального экспорта (zip: markdown + csv), сохранение иерархии страниц и базовых блоков. Однократная миграция — после неё Notion больше не нужен.
**Импорт Apple Notes:** скрипт на AppleScript/Shortcuts, экспортирующий заметки в наш формат; запуск вручную или по расписанию.

### 4.3 Задачи

- Представления: **список** (по приоритету/дате), **доска** (по статусу), **дерево** (вложенность), «Сегодня», «Неделя», Inbox.
- Приоритеты P0–P3 + отдельно флаг «важно для цели» (наследуется от привязанной цели).
- Даты: дедлайн (`dueDate`) и план (`scheduledDate`) — разделены осознанно.
- **Подзадачи** любой глубины; прогресс родителя = % детей.
- **Зависимости «до/после»**: задача может блокировать другие; заблокированные визуально приглушены; готовность открывается автоматически. Мини-граф зависимостей на карточке.
- Повторяющиеся задачи (RRULE-подобные правила).
- У каждой задачи — вкладка **«План»**: полноценная страница-заметка (тот же редактор), где раскладываем подход, варианты, рассуждения. И вкладка **«Лог»**: датированные записи хода работы.
- Связь с колесом развития и целями: у задачи видно, какой сектор и какую цель она двигает.

### 4.4 Календарь

- Месяц / неделя / повестка (agenda).
- Единая лента: свои события + дедлайны задач + **финансовые даты** (списания подписок, платежи по пассивам) + дни ревью.
- Чтение системного календаря через EventKit (опционально, read-only в v1).
- Напоминания — локальные уведомления macOS.

### 4.5 Финансы

**Портфель:**
- Активы по классам; стоимость, доля, P&L, доходность (XIRR по транзакциям).
- Целевая аллокация и отклонение («ребаланс: продать X, купить Y»).
- Цены — ручное обновление в v1 (без внешних API: приватность), импорт котировок CSV опционально.
- История нетворса (Snapshot — автоматически раз в день при открытии).

**Подписки:**
- Список с датами списания, суммой в месяц/год итого.
- Напоминание за N дней до списания; сигнал «не использовалась X недель — отменить?» (lastUsedAt вручную или из журнала).

**Доходы/расходы:**
- Транзакции трёх видов: **факт**, **план** (регулярные: зарплата, аренда), **потенциал** (с вероятностью: «может выгорит проект на X»).
- Категории, повторяемость, импорт банковских CSV с маппингом колонок.

**Пассивы:**
- Кредиты/обязательства: график платежей, остаток, напоминания за N дней.

**Прогноз кэшфлоу (ключевая фича):**
- График на 3–12 месяцев: факт + планы + подписки + платежи по пассивам + потенциалы (взвешенные на вероятность, отдельной пунктирной линией).
- Предупреждение «в месяце X прогноз уходит в минус».

### 4.6 Рутины и привычки

- Рутины-чеклисты по слотам (утро/день/вечер/неделя) с активными днями.
- Отметки выполнения с дашборда; стрики, % за месяц, тепловая карта в стиле GitHub.
- Привязка привычки к сектору колеса.

### 4.7 Колесо развития

- Настраиваемые сектора (по умолчанию 8: здоровье, финансы, карьера, отношения, окружение, развитие, отдых, смысл).
- Периодическая самооценка 1–10 → радар-диаграмма; история замеров и динамика.
- У каждого сектора: текущая оценка, целевая, привязанные цели и задачи, привычки.
- «Самый проседающий сектор» подсвечивается на дашборде.

### 4.8 Цели и горизонты

- Иерархия: год → квартал → месяц/неделя. Цель без привязки к родителю — сигнал.
- У цели: метрика (если измерима), привязанные задачи, прогресс = из метрики или из % задач.
- Задача без цели — мягкое предупреждение в ревью.

### 4.9 Ревью

- Еженедельное / месячное / годовое. Платформа **сама собирает**: закрытые задачи, траты vs план, движение нетворса, стрики, динамику колеса — и подставляет в шаблон с вопросами для рефлексии.
- Ревью — это JournalEntry, остаётся в журнале и ищется поиском.

### 4.10 Журнал и журнал решений

- Дневник с настроением/энергией (1–5).
- Записи типа «решение»: контекст → варианты → выбор → ожидание. Через N месяцев платформа напоминает: «проверь, как сработало решение от …».

### 4.11 Глобальный поиск и граф

- ⌘K: поиск по всему (FTS5) — заметки, задачи, транзакции, цели, люди.
- Командная палитра там же: «создать задачу», «перейти в финансы»…
- Граф связей (v2): визуализация Link-сети вокруг выбранной сущности.

### 4.12 Безопасность

- БД зашифрована SQLCipher (AES-256); ключ шифруется master-ключом из Secure Enclave.
- Разблокировка: Touch ID / пароль. Автоблокировка по таймауту и при закрытии крышки.
- Вложения шифруются отдельно (ChaCha20-Poly1305).
- Скрытие сумм одной кнопкой («режим кафе»: все деньги → `•••`).
- Зашифрованный бэкап в файл по расписанию (можно класть в любой облачный диск — он бесполезен без ключа).
- Никакой телеметрии. Сетевые запросы — только явные (импорт котировок, синк), по умолчанию выключены.

## 5. UI десктопной версии

> Интерактивный макет: `docs/mockups/desktop.html` — открыть в браузере, переключать экраны в сайдбаре.

**Эстетика:** **светлая тема — основная**: белые панели, мягкий серый фон, зелёный акцент (оммаж Pip-Boy в сдержанном виде), моноширинные цифры и заголовки секций, обычный шрифт для текста. Тёмная тема — позже, опционально.

**Каркас:** трёхзонный.
1. **Сайдбар** (слева): Сегодня · Задачи · Инфо · Календарь · Финансы · Колесо · Цели · Журнал; внизу — поиск (⌘K) и замок (заблокировать).
2. **Основная зона** — контент модуля.
3. **Инспектор** (справа, сворачиваемый) — свойства выбранной сущности: связи, теги, даты, бэклинки.

Описание ключевых экранов — см. макет; он является частью этого ТЗ.

## 6. Нефункциональные требования

- Запуск до интерактивности < 2 с; поиск по 50k записей < 100 мс.
- Полная работа офлайн; ни одной обязательной сетевой зависимости.
- Экспорт всего (Markdown + JSON + вложения) одной командой.
- Все деструктивные действия обратимы (корзина/архив) минимум 30 дней.
- Управление с клавиатуры: глобальные хоткеи на быстрый ввод и навигацию.
