# Формат архива для импорта

Требования принимающей стороны — по ним собираются архивы, которые уходят в работу.

## Файлы

| что | правило |
|---|---|
| `main.html` | обязателен, текст главной страницы (первый таб) |
| `{url}.html` | страница контента, имя файла = url страницы-родителя (`bonus.html`, `registracia.html`) |
| `images/` | папка с картинками, необязательная |

Наши наборы этому уже соответствуют: страницы называются по типу (`main`, `vhod`,
`zerkalo`, `registracia`, `bonus`, `slots`, `app`), и эти же имена стоят в путях
перелинковки.

## Картинки

* Имя файла: `{страница}_img_{N}.{ext}` — расширение любое (`webp`, `jpg`, `png`).
  Примеры: `images/bonus_img_1.webp`, `images/main_img_1.jpg`, `images/registracia_img_2.png`.
* В HTML пишется **только имя файла**, без папки: `<img src="bonus_img_1.webp">`.
* При импорте путь подменяется на `/uploads/content/{id}/bonus_img_1.webp`.
* Если картинку не удаётся привязать к странице-родителю — **импорт отменяется с
  ошибкой**. То есть префикс в имени файла обязан совпадать с именем страницы:
  картинка `bonus_img_1.webp` может стоять только в `bonus.html`.

## Пример структуры

```
main.html
bonus.html
registracia.html
images/
  main_img_1.webp
  bonus_img_1.jpg
  bonus_img_2.png
  registracia_img_1.webp
```

## Что это меняет для генерации

Разметка `<img>` до сих пор была под запретом: у всех референсов картинки — часть
шаблона сайта, а не текста, и в замер они не входят.

Для варианта с картинкой договорённость такая:

* **одна картинка на набор, только в `main.html`** → имя файла `main_img_1.{ext}`,
  в разметке `<img src="main_img_1.webp" alt="…">`, файл лежит в `images/`;
* стоит в первой части текста — после первого-второго абзаца первого раздела,
  до второго заголовка;
* внутри файла — генерируемая заглушка (GD в окружении есть), её можно заменить
  на настоящую иллюстрацию, не трогая разметку: имя и путь останутся прежними.

**`alt` на замеры не влияет.** Все счётчики работают по `strip_tags`, а он
выбрасывает тег вместе с атрибутами — текст `alt` в подсчёт слов, терминов и
маркеров не попадает. Значит, `alt` можно писать осмысленно и с ключом, не
оглядываясь на коридоры.
