## 4. Принцип их генерации

Реконструирую по 294 страницам. Три уровня: **архив → сайт → страница**.

### Уровень архива

Общие для всех 42 сайтов пулы, из которых потом берут:

- **словарь слоганов** — короткие фразы («Взрыв кэш», «Модуль мечты»,
  «Пасс фортуны»), склеиваемые по 2–4 в шапку и подвал;
- **каталог слотов** — 208 тайтлов с провайдером, RTP и годом;
- **48 категорий виджета** с эмодзи;
- **3 шаблона описания карточки**, ротируемые по кругу:
  `Играйте в X от P на %brand_name_ru%. RTP R, жанр: G.` (572 раза) ·
  `X — популярный слот от P (Y) с RTP R.` (317) ·

- **банк подтем** по семи типам страниц: для `/slots` — волатильность,
  джекпоты, кластерные выплаты, провайдеры, достижения, совместимость…;
- **банк вопросов FAQ** по типам.

### Уровень сайта

десятке слов внутри; у нас — в ракурсе рассказчика, рефрене и словаре по всему
тексту.

### Уровень страницы

Сборка: `тема = подтема из банка + суффикс маски сайта`, затем семь слоёв.

1. Взять 3–4 слогана, склеить в шапку, один продублировать в H2.
2. Поставить голый плейсхолдер абзацем.
3. Написать уникальный блок: H2-тема, 5–8 H3, внутри — проза, 1–2 списка,
   таблица на 3 столбца, `<details>` со свёрнутым чек-листом, одна цитата в
   кавычках с подписью, врезка «Совет от кореша».
4. Вшить в прозу 5–7 ссылок падежными анкорами; всё бонусное увести на `/app`.
5. Подставить виджет: категория с эмодзи + 4 карточки из каталога.
6. Приклеить FAQ: 8 вопросов из банка по типу страницы.
7. Подвал: дата, H3-слоган, три слогана.
