# Два поколения одной фабрики

Продолжение разбора. Первые пятнадцать проходов —
`docs/v4-zhanr-new50_3.md`, здесь проходы с шестнадцатого по двадцать третий.

Ключевая мысль: **узкая полоса внутри одного корпуса ещё не значит настройку.**
Если промпт про поле молчит, модель всё равно выдаёт похожие значения — это
привычка модели, а не решение фабрики. Отличить одно от другого можно только
вторым выпуском: настройка переживает смену поколения, привычку правят.

В аплоадах лежал `new50.zip` от 12–13 июля — **другие пятьдесят брендов, за три
недели до августовского корпуса**. Итого 86 независимых генераций, 700 страниц.

Инструмент: `engine/sravnit-pokoleniya.php`, выкладка
`reports/v4/pokoleniya-main.json`.

## Что правили — сюда фабрика прикладывала руки

| поле | июль | август | сдвиг |
|---|---|---|---|
| `opener_name` «Бренд — это…» | 1 | 0 | **−100 %** |
| `first_person` «я» | 23,5 | 3,5 | **−85 %** |
| `ty` «ты» | 4,5 | 23,5 | **+81 %** |
| `compare` бытовых сравнений | 1 | 3 | +67 % |
| `cta` прямых призывов | 0 | 2 | +100 % |
| `emoji` | 16 | 30 | +47 % |
| `emoji_inline` внутри фразы | 0 | 1 | +100 % |
| `faq` вопросительных знаков | 4 | 7 | +43 % |
| `games_named` / `names_uniq` | 0 / 0 | 0,5 / 2 | +100 % |

Читается это как одно решение, разложенное на девять полей: **фабрика сменила
голос.** В июле писали от первого лица («я проверял», медиана 23,5 упоминания)
и открывали страницу формулой «Бренд — это…». В августе первое лицо срезали
почти в семь раз, «ты» подняли впятеро, добавили прямые призывы и вдвое больше
эмодзи.

Здесь же поправка к предыдущему отчёту: я писал, что зачин **никогда** не
начинается «Бренд — это…». Это верно для августа; в июле так открывались
большинство страниц (`opener_name` = 1 при 90 % попаданий).

`compare` втрое — прямое следствие масок. Метафора «рыбацкая артель»,
«костёр», «сталактитовый грот» — это и есть механизм производства бытовых
сравнений. Маски появились вместе с ростом этого поля.

### Эмодзи: где именно их прибавилось

| место | июль | август | во сколько |
|---|---|---|---|
| в заголовке | 0,4 | 10,6 | **×26** |
| внутри фразы | 0,5 | 9,5 | **×19** |
| в начале пункта | 3,9 | 12,3 | ×3,2 |
| в ячейке таблицы | 10,1 | 15,4 | ×1,5 |

В июле эмодзи жили почти исключительно в ячейках таблиц. В августе их рассыпали
везде. **Наши шесть эталонов v3 принадлежат июльской школе** — карточка эталона
прямо говорит «в заголовках эмодзи нет ни одного». Августовская школа это
правило отменила.

## Самый жёсткий инвариант корпуса

Внутренняя страница (не главная) устроена одинаково у всех:

| | июль (300 стр.) | август (216 стр.) |
|---|---|---|
| ровно два H2 | 97 % | **99 %** |
| последний H2 — это FAQ | 98 % | **100 %** |
| H3 медиана | 5 | 5 |
| есть H3-инструкция | 60 % | 68 % |

**216 из 216 августовских страниц заканчиваются блоком «Ответы на вопросы».**
Ни одного исключения на 516 страницах двух поколений.

Схема страницы:

```
H2  <узкий срез темы, в маске сайта>
    H3 что это такое
    H3 как найти / как сделать — пошагово
    H3 таблица или чек-лист
    H3 риски и безопасность
    H3 итог
H2  Ответы на вопросы   ← аккордеон <details>
```

Первый H2 — **не сама тема, а срез темы**. Страница `zerkalo` называется не
«Зеркало», а:

```
Вывод средств через зеркало: как быстро и без заморочек   888starz
Частые ошибки при использовании зеркал: как всё началось  arkada
Причины блокировки и роль зеркал казино                   baboss
Актуальное зеркало: как через зеркало ловить бонусы       cat
Доступность бонусов и акций через зеркало на сегодня      clubnika
как я проверяю подлинность зеркала — мой опыт             cactus
```

Так семь страниц одного сайта и пятьдесят сайтов одной темы не наступают друг
другу на ноги.

## Каннибализации нет вообще

Все семь страниц пишут об одном казино, и главная содержит разделы «зеркало»,
«регистрация», «бонусы» — при том что для каждой из этих тем есть отдельная
страница. Пересечение:

| | среднее | макс |
|---|---|---|
| главная ↔ внутренние (август) | **0,18 %** | 2,29 % |
| внутренние между собой (август) | 0,06 % | 1,29 % |
| главная ↔ внутренние (июль) | 0,31 % | 3,65 % |

**Ни одной переиспользованной формулировки даже внутри одного сайта.** Каждая
из семисот страниц написана заново. Это подтверждает принцип из первого отчёта
на новом материале: уникальность здесь не результат правки, а результат того,
что переиспользовать просто нечего.

## Морфология: язык инструкции, а не объяснения

На 100 слов, оба поколения почти совпадают:

| форма | июль | август |
|---|---|---|
| инфинитив (`-ть/-ти`) | 4,13 | **4,15** |
| прошедшее время | 3,02 | 2,63 |
| условие «если» | 0,92 | 0,98 |
| повелительное | 1,12 | 0,83 |
| страдательный залог | 0,65 | 0,63 |
| модальное «можно/нужно» | 0,42 | **0,42** |
| уступка «но/однако» | 0,49 | **0,47** |
| причина «потому что / так как» | 0,05 | **0,06** |
| вводное «например» | 0,07 | **0,05** |

Три вещи:

1. **Инфинитив — самая частая глагольная форма**, вдвое чаще прошедшего.
   Текст живёт в форме «как сделать»: проверить, вывести, зарегистрироваться.
2. **Условие есть, причины нет.** «Если» — почти одно на сто слов, «потому что»
   — 0,06. Текст описывает не почему устроено так, а что делать, когда.
3. **Примеров вводными словами не приводят.** «Например» — 0,05 на сто слов.
   Конкретика встроена прямо в предложение, а не подвешена оборотом.

Страдательный залог 0,63 % — очень низкий, залог активный.

## Таблица — это мини-инструкция, а не справка

586 таблиц, 6441 ячейка, медиана — 3 колонки, 5 строк, **4 слова в ячейке**,
20 % ячеек с цифрой.

| колонка | что в ней | частые подписи |
|---|---|---|
| 1 | субъект | параметр (37), шаг (31), критерий (17), провайдер (15), ситуация (12), этап (10), проблема (9) |
| 2 | что делать | описание (43), действие (25), что сделать (6), что проверить (5) |
| 3 | **зачем** | почему важно (9), результат (7), что делать (7), зачем это важно (4), как исправить (4) |

Разных подписей: 289 / 386 / 321. Третья колонка — не оценка и не сравнение, а
**оправдание действия**. Это уточняет карточку `table_cols` в движке.

## Анкор — одно слово внутри фразы

| | |
|---|---|
| внутренних ссылок | 2853 |
| стоят внутри `<p>` или `<li>` | **91 %** |
| слов в анкоре, медиана | **1** |
| разных анкоров | 577 |
| встречаются ровно один раз | 78 % |
| в косвенном падеже | 30 % |

Как это выглядит в живом предложении:

```
Пройди регистрацию в 2 минуты…
Смотри зеркало, если приложение «зависло»…
Каждый новый игрок получает промокод от постоянных участников…
следите за всеми фишками на зеркале! 🍀
хотите узнать про бонусы и промокоды…
выбрать регистрацию и проверять скиллы в слотах
учти всё по регистрации тут, чтобы лишний раз не дёргаться
```

Анкор — **обычное слово предложения в нужном падеже**. Уберите разметку —
предложение не изменится ни на букву. Это ровно то, что заложено в поле
`anchor_once_pct`, и держится оно в обоих поколениях (71,4 → 74,45 при 90–92 %).

## Итог по двум поколениям

**Настройка** (пережила смену выпуска, 86 генераций):
уникальная шапка у каждой таблицы · три запрещённых приёма · ключ в зачине ·
список в зачине · один-два значения с процентом на страницу · 31 слово в абзаце ·

анкоров · водность 28–29 % · тошнота 37–39 на главной · 84–90 % разделов,
открытых абзацем · ровно два H2 на внутренней странице · последний H2 = FAQ ·
инфинитив как несущая форма · условие вместо причины · анкор в одно слово внутри
фразы · нулевая каннибализация.

**Правили** между выпусками: голос (я → ты), зачин («Бренд — это…» убрали),

оценочная карта (новая).

бренда и их расположение, императивы, «вы», короткие абзацы, `strong`,
