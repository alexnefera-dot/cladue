# Инструкция: уникальные стили и картинки для комплекта из 12 страниц

Самодостаточное описание того, как в этом репозитории каждому набору (12 HTML-страниц казино-контента) даётся своё оформление и свои картинки. Написано так, чтобы по нему можно было воспроизвести конвейер в другом проекте после чистки кода. Файлы движка, на которые опирается конвейер: `engine/temy-v5.php`, `engine/kartinki-v5.php`, `engine/verstka-v5.php`, `engine/verstka-tablichnaya-v5.php`, `engine/stili-v5.php`.

---

## 1. Что на входе и что на выходе

**Вход:** папка набора `nabor-NNN/` с 12 страницами `main, obzor, promo, news, info, partnery, app, bonus, registracia, slots, vhod, zerkalo` (`*.html`). Страницы — голая семантическая разметка: секции, заголовки, абзацы, списки, карточки слотов с классами (`hero-value`, `slot-name`, `faq-question` …) или, для чужих текстов, вообще без классов (section / table / aside / details).

**Выход:** та же папка, где:
- у каждого элемента появился инлайновый `style="…"` (или, для половины тем, один тег `<style>` в начале страницы с классами `v5s-N`);
- в `images/` лежат webp-картинки: по одной ведущей на страницу (`<страница>_img_1.webp`) плюс обложки карточек слотов на главной (`main_img_2…N.webp`), всего 24 файла;
- картинки вшиты в HTML тем способом, который задаёт тема набора;
- ни одной внешней зависимости: без CSS-файлов, CDN, шрифтов из сети. Всё переносится в любой шаблон копированием.

**Неизменные ограничения:** структура HTML не меняется (не добавляем `<table>` и новые `<ul>`, не режем текст), тексты не правятся, палитра полупрозрачная (`rgba`), чтобы блоки одинаково ложились на светлую и тёмную тему сайта-хозяина.

---

## 2. Тема — единица уникальности

Тема — это набор из ~14 параметров в таблице `v5Tema(int $n)` (`engine/temy-v5.php`). Одна тема = один сайт. Сейчас в таблице 41 тема (1–20 первая волна, 21–31 вторая, 32–41 третья); тема 0 — базовое оформление без темы.

| Поле | Значения | На что влияет |
|---|---|---|
| `имя` | слово-цвет («янтарь», «мох», «уголь») | только для журнала |
| `тон` | `[r,g,b]` | цвет подложки блоков и кантов (полупрозрачный) |
| `а1`, `а2` | 0.08–0.14 / 0.14–0.24 | прозрачность подложки и подложки-2 (шапки таблиц, чипы) |
| `кант` | `solid 1px` / `solid 2px` / `dashed 1px` / `none` | рамка блоков; при `none` заливка гуще |
| `акцент`, `акцентТекст` | hex | кнопки, суммы, метки, полосы заголовков; цвет текста на акценте |
| `радиус` | 0 … 1.6 | множитель ко всем `border-radius` вёрстки (0 — прямые углы) |
| `пилюля` | bool | чипы и кнопки остаются пилюлями (999px) или становятся 8px |
| `тень` | `box-shadow:…` или `''` | тень карточек |
| `кнопка` | `сплошная` / `контур` / `градиент` | стиль кнопок |
| `заголовок` | `чистый` / `капс` / `подчерк` / `полоса` / `тонкий` / `рамка` | стиль H2/H3 |
| `список` | `точка` / `стрелка` / `квадрат` / `тире` / `ромб` / `галка` / `звезда` | маркер списков |
| `строка` | 1.55–1.75 | line-height абзацев |
| `картинка` | 12 способов, см. §4 | как вшивается ведущая картинка |
| `высота` | 260–360 px | max-height ведущей картинки |
| `сдвигТона` | 0–359 | сдвиг оттенка рисованных картинок относительно сюжета страницы |
| `интеграция` | `инлайн` / `style` | стили атрибутами или одним `<style>` на страницу |

Из полей темы функция достраивает производные: `подложка`, `подложка2` (rgba из `тон` и `а1/а2`), `кантCSS`, `маркер` (CSS-строка для `list-style-type`), `тревога`, `успех`, `плюс`, `минус`.

**Правило уникальности.** Новая тема не должна повторять ни одну существующую по сочетанию «акцент + кант + радиус + кнопка + заголовок + маркер + картинка». Внутри волны тем ещё и чередуется `интеграция` (нечётные — `style`, чётные — `инлайн`), чтобы у половины сайтов был `<style>`, у половины — чистый инлайн. Проверка перед добавлением: выписать эти семь полей у всех тем и убедиться, что строка новой темы не совпадает ни с одной (достаточно `sort | uniq -d` по конкатенации полей).

**Выбор темы для набора детерминированный:** `тема = номер набора − смещение волны` (400–410 → 21–31, 411–420 → 32–41), сид картинок `9000 + номер × 13`. Так один и тот же набор всегда собирается одинаково, а соседние наборы никогда не делят тему.

## 3. Конвейер оформления одного набора

Скелет драйвера (bash), по одному набору за итерацию:

```bash
src=samples/v5-final/nabor-$n; dst=$OUT/nabor-$n
cp -r "$src" "$dst"; rm -f "$dst"/nabor.json; rm -rf "$dst"/images     # 1. чистая копия без служебных файлов
tema=$((n-379)); seed=$((9000+n*13))                                     # 2. тема и сид

php engine/kartinki-v5.php "$dst" --сид=$seed --не-резать --тема=$tema   # 3. картинки + вшивание по теме

if grep -q 'class="hero-value\|class="slot-name' "$dst"/*.html; then     # 4. вёрстка
  php engine/verstka-v5.php "$dst" --тема=$tema                         #    страницы с классами v5
else
  php engine/verstka-tablichnaya-v5.php "$dst" --тема=$tema             #    голые табличные страницы (по тегам)
fi

# 5. половине тем — стили в один <style> (по полю «интеграция» темы)
php -r 'require "engine/temy-v5.php"; exit(v5Tema('$tema')["интеграция"]==="style"?0:1);' \
  && php engine/stili-v5.php "$dst"

# 6. убрать картинки, на которые никто не ссылается
for f in "$dst"/images/*.webp; do b=$(basename "$f"); grep -q "$b" "$dst"/*.html || rm -f "$f"; done

# 7. пути к картинкам — относительные в images/
sed -i -E 's#src="(main_img_[0-9]+\.webp)"#src="images/\1"#g; s#src="([a-z]+_img_1\.webp)"#src="images/\1"#g' "$dst"/*.html

# 8. самопроверка
bity=$(grep -oh 'src="[^"]*"' "$dst"/*.html | sed 's/.*src="//; s/"$//' | while read p; do [ -f "$dst/$p" ] || echo x; done | wc -l)
echo "nabor-$n тема $tema: картинок $(ls "$dst/images" | wc -l) img-тегов $(grep -o '<img ' "$dst"/*.html | wc -l) style-тегов $(grep -o '<style' "$dst"/*.html | wc -l) битых $bity"
```

Ожидаемая строка проверки: `картинок 24 img-тегов 24 style-тегов 12|0 битых 0`. Порядок шагов важен: картинки вшиваются до вёрстки (вёрстка дорисовывает им стили темы), `stili-v5.php` идёт последним (он переносит в `<style>` всё, что к этому моменту лежит в атрибутах).

Флаги `kartinki-v5.php`:
- `--сид=N` — детерминированный розыгрыш сюжетов, вариантов подписей, искр;
- `--тема=N` — способ вшивания, сдвиг тона, высота;
- `--не-резать` — не сокращать список карточек слотов до восьми (обязательно для чужих текстов: снятая карточка уносит абзац, а это уже правка содержания);
- `--только-урезать` — комплект без картинок, только привести список слотов к восьми (до приёмки);
- `--без-стилей` — картинка ставится голой, только `max-width:100%;height:auto`;
- `--обложки=<dir>` / `--без-фото` — откуда брать фото-обложки слотов (по умолчанию `engine/data-v5/oblozhki`, 12 webp по слагам игр).

## 4. Как делаются картинки (`kartinki-v5.php`)

Всё рисуется на месте библиотекой GD (PHP ≥ 8, расширения gd + webp; шрифты DejaVu Sans / DejaVu Sans Bold из системы). Никаких внешних генераторов и сети. Холст 1200×630, рисуется вдвое крупнее (константа `S = 2`) и ужимается — так сглаживаются края.

**Сюжет по странице.** Таблица `$ТЕМЫ[страница] = [тон, сюжет, [варианты подписей], [варианты alt]]`: у каждой из 12 страниц свой базовый оттенок и свой предмет-персонаж, например `main → сундук`, `obzor → кубок`, `promo → подарок`, `news → рупор`, `info → щит`, `partnery → монетопад`, `app → телефон`, `bonus → монеты`, `registracia → карта`, `slots → барабаны`, `vhod → сейф`, `zerkalo → портал`; есть ещё `корона`, `джокер`, `тигр`, `лампа`, `семёрка`. Сюжеты — предметы казино, не схемы.

**Слои одной картинки** (функция `нарисовать`): градиентный фон из двух тонов → свечение за предметом → лучи → сам предмет (объём: затенение, блики, отброшенная тень) → искры по сиду → виньетка → две строки подписи (заголовок и подзаголовок из трёх вариантов, вариант по сиду) → сохранение в webp. Тон = тон страницы + `сдвигТона` темы, поэтому одна и та же страница в разных темах выглядит по-разному даже при одном сюжете.

**Обложки слотов** (`обложкаФото`): для карточек слотов на главной берётся фото-обложка игры из `data-v5/oblozhki/<слаг>.webp`, кадрируется и тонируется под тему; если обложки нет — рисуется вариант `барабаны`. Alt берётся из жанра слота.

**Вшивание** (`вшитьПоТеме`): ведущая картинка ставится в начало страницы одним из 12 способов, значение поля темы `картинка`:

| Способ | Что делает |
|---|---|
| `полоса` | картинка полосой во всю ширину над первым H2 (базовый способ) |
| `шапка` | картинка на всю ширину как шапка с уменьшенной высотой |
| `широкая` | широкая полоса с большим радиусом и тенью |
| `постер` | высокий постер с подписью снизу |
| `карточка` | картинка в карточке с подложкой темы и кантом |
| `слева` | картинка в левой колонке, текст справа (grid) |
| `обтекание` | float влево с обтеканием первого абзаца |
| `сплит` | две колонки: картинка и первый блок текста |
| `фигура` | скруглённая фигура (сильный радиус) с полем |
| `подзаголовком` | картинка после первого H2, под ним |
| `рамка` | двойная рамка: акцентный кант + внешний контур с отступом |
| `лента` | подпись лентой поверх нижнего края картинки с чипом раздела |

Каждый способ — законченный кусок инлайн-CSS без внешних правил. Добавляя способ, добавляешь `case` в `вшитьПоТеме` и значение в комментарий-словарь `temy-v5.php`.

## 5. Как работает вёрстка (`verstka-v5.php`)

Таблица `$ПРАВИЛА['класс'] = 'инлайновый стиль'` для всех классов разметки v5 (`hero-value`, `btn`, `btn-apple`, `quicklink-item`, `slot-card`, `faq-question` …). Проход по HTML: у каждого элемента берётся **первый** класс, по нему подставляется `style`. Тема правит правила до прохода:

- цвета: `ПОДЛОЖКА`, `ПОДЛОЖКА2`, `КАНТ`, `ЗОЛОТО` (акцент), `ТРЕВОГА`, `УСПЕХ` — из темы;
- `v5TemaRadius` умножает все `Npx` радиусов на `радиус` темы (999px пилюль остаётся или становится 8px по `пилюля`);
- `v5TemaKnopka` перестраивает `btn` под `сплошная / контур / градиент`;
- `v5TemaZagolovok` даёт стиль H2 и H3 по полю `заголовок`;
- `ul` получает `list-style-type` по маркеру темы, `p` — `line-height` по `строка`;
- при `кант = none` все `border:1px solid transparent` → `border:0`, а кнопкам `btn-apple` кант заменяется на `2px solid <акцент>` (иначе в темах без канта кнопки шапки «Играть/Акции» становятся голым текстом — это была реальная ошибка первых волн);
- `тень` дописывается карточкам.

`verstka-tablichnaya-v5.php` делает то же для страниц без классов v5 — по тегам (`table, th, td, aside, blockquote, details, summary, nav, time, figure, h2, h3, ul, ol, p`), идемпотентно: элемент, у которого уже есть `style`, не трогается.

`stili-v5.php`: собирает все `style="…"` страницы, нормализует (`; ` → `;`), одинаковые правила склеивает в один класс `v5s-N`, пишет `<style>` в начало файла и заменяет атрибуты классами. Вид не меняется ни на пиксель, разметка вдвое легче. Идемпотентно: страницу с `<style>` пропускает.

## 6. Как добавить новую волну тем

1. Открыть `engine/temy-v5.php`, дописать строки после последней темы — существующие не менять и не перенумеровывать (старые наборы должны пересобираться в том же виде).
2. Для каждой темы выбрать сочетание, которого ещё нет (§2). Удобно идти по кругу: кант (4 значения) × кнопка (3) × заголовок (6) × маркер (7) × картинка (12) — комбинаций тысячи, повторов не будет, если следить за семёркой полей.
3. Акцент подбирать контрастный к тёмному и светлому фону (насыщенный цвет средней светлоты); `акцентТекст` — тёмный на светлых акцентах, белый на тёмных.
4. Чередовать `интеграция`.
5. Проверить `php -l engine/temy-v5.php` и `php -r 'require "engine/temy-v5.php"; print_r(v5Tema(NN));'`.
6. Прогнать драйвер §3 на нужных наборах и посмотреть контактный лист (§7).

## 7. Проверка глазами

Скриншоты через Playwright (Chromium из `/opt/pw-browsers/chromium`): каждая главная страница набора рендерится дважды — на тёмном и на светлом фоне (`prefers-color-scheme`), обрезается по верхним ~900 px и склеивается в контактный лист 5×2 (`лист-main-dark.png`, `лист-main-light.png`). Смотрим: кнопки шапки видны, картинка вшита по способу темы, карточки слотов с обложками, заголовки в стиле темы, ни одного «голого» блока без подложки. Это единственный шаг, который не автоматизирован: цифры проверки из §3 не ловят визуально невидимую кнопку.

## 8. Требования к среде и грабли

- PHP ≥ 8.1 с `gd` (с поддержкой webp и freetype), шрифты `DejaVuSans.ttf` и `DejaVuSans-Bold.ttf`; для скриншотов — Python + Playwright + Chromium.
- Правило берётся по **первому** классу элемента: если нужный класс не первый, стиль не применится. Не переставлять классы в разметке.
- Не запускать `stili-v5.php` до вёрстки и картинок — он заберёт в `<style>` только то, что уже есть.
- После вшивания обязательно чистить неиспользуемые webp и переписывать `src` на `images/…`, иначе в архиве будут лишние файлы или битые ссылки.
- Никаких внешних ресурсов (CSS, шрифты, CDN): комплект должен открываться из папки офлайн.
- Один набор — одна тема; одна тема — не больше одного набора в волне. Тема и сид выводятся из номера набора, а не разыгрываются случайно, чтобы результат воспроизводился.
