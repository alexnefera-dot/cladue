# terms_total: четыре рычага, ни один не окупился

## Что мерили

Профильных терминов (24 семейства `NicheLexicon::TERMS`) у нас на странице
больше корпусного. Медиана нашего значения стоит на 73-м процентиле NEW100 и
выше корпусной медианы на всех двенадцати типах; за набор выходит 883 термина
против корпусных 730.

Это плотность, а не объём: слов у нас ровно корпусных, медиана процентиля 50 %.

## Где перебор лежит

Разбор по месту в разметке оказался решающим:

| | абзацы | пункты списков | доля слов в пунктах |
|---|---|---|---|
| наши 20 наборов | **47.0** | 57.4 | 28 % |
| NEW100 обычные | **34.9** | 61.4 | 25 % |

В перечислении мы корпуса даже реже. Весь перебор — в прозе, и он там на 35 %.

Пул при этом не виноват. Проза пула несёт 38.3 термина на 1000 слов против
корпусных абзацев 34.9, и 63 % её записей не несут термина вовсе: в пуле
43 013 записей прозы, из них 26 957 чистых. Очередь выбирает плотные записи, а
не пул их такими пишет.

(Первый счёт пула давал 51.3 и 16 % внутренних повторов — это был артефакт
прорезей: `{RTP}` содержит «RTP», и «RTP {RTP}%» считалось за два термина,
хотя на странице это «RTP 96.4%», то есть один. С подставленными значениями
выходит 44.4 по всему пулу и 2.4 % внутренних повторов.)

Тянет плотные записи предпочтение «по теме». Слова темы — пятибуквенные основы
слов из H2 раздела, а заголовки у нас терминные: «Вывод средств», «Джекпот
слоты», «Бонус за регистрацию», «Фриспины — Крути бесплатно». Предпочтение
срабатывает на каждом выборе и по построению тянет записи с терминами.

## Четыре рычага и их замеры

Все четыре — 48 парных сидов, одни сиды, один журнал, один перекрут.

| рычаг | terms_total промахи | цена |
|---|---|---|
| 1. Потолок семи семейств, все слоты | **1.33 → 0.71** (p = 0.0008) | fact_values 0.71 → 2.60 (p = 1.7e-08), on_topic_pct 0.23 → 0.77 (p = 2.6e-06), страниц с провалом 8.75 → 9.79 (p = 0.0026) |
| 2. Два семейства без чисел | 1.33 → 1.00 (p = 0.015) | on_topic_pct 0.23 → 0.44 (p = 0.013), paragraphs 0.79 → 1.04 (p = 0.031), страниц с провалом 8.75 → 9.21 (p = 0.024) |
| 3. То же, давление только на пункты | 1.33 → 1.38 (p = 1) | промахов полей 15.46 → 15.88 (p = 0.0046), страниц с провалом 8.75 → 8.85 (p = 0.049) |
| 4. Квота предпочтению «по теме» | 1.33 → 1.17 (p = 0.52) | on_topic_pct 0.23 → 0.54 (p = 0.0059), words_per_para 0.85 → 1.29 (p = 0.052) |

Рычаг 1 показал, что метрику сдвинуть можно — и дорого. Рычаг 2 снял урон по
фактам, сузившись до семейств, которые чисел при себе не держат, но темность и
абзацы всё равно просели. Рычаг 3 давил в пункты — то есть ровно не туда, где
перебор, — и не дал ничего, заплатив при этом приёмкой. Рычаг 4 снимал не
противодавлением, а самим перекосом: квота предпочтению «по теме». Он дал
наибольший сдвиг по значениям (zerkalo −6.5, news −6.0, slots −5.0), но по
промахам поля это незначимо, а темность просела значимо.

## Почему все четыре упираются в одно

Термин и тема — одни и те же слова. 27 % слов темы в `PageMetrics::TOPICS`
совпадают с основами терминов («бонус», «промокод», «фриспин», «кэшбэк»,
«отыгрыш», «вейджер», «зеркал», «домен», «верификац», «провайдер», «отдач»,
«волатильн», «ставк»), а слова темы, которые строит генератор из H2, совпадают
с ними ещё чаще. Любое давление на термины — это давление на тему.

Корпус держит абзацы на 34.9 термина и при этом остаётся по теме. Значит их
проза бывает тематичной без терминов, а наша — редко: у нас запись либо несёт
термин, либо не читается как «по теме».

## Что это значит

Чинится это письмом, а не весом. Нужны записи прозы, которые держат тему
раздела, не называя профильного термина: не «вывод средств идёт быстро», а «в
понедельник деньги пришли раньше, чем я успел закрыть ноутбук». Таких записей в
пуле 63 %, но очередь их не берёт, потому что по её мерке они не по теме — а
правильная мерка темы должна бы считать не термин, а предмет разговора.

До тех пор поле остаётся как есть: промахов 1.33 за набор из примерно
пятнадцати, значения на всех двенадцати типах внутри корпусной полосы 10–90 на
75–100 % страниц. Это не провал приёмки, это разница в почерке.

## Партия прозы: что написано и сколько осталось

Раз рычагом поле не берётся, пишем. Запись обязана пройти два встречных
условия сразу: содержать пятибуквенную основу из H2 своего раздела — иначе
очередь сочтёт её не по теме и не возьмёт, — и не содержать ни одного из
двадцати четырёх профильных терминов, иначе она ничем не отличается от того,
что уже лежит. Проверка автоматическая (`scratchpad/proza/sobrat.py`), она же
ловит левые части таблицы `PK_TERMY`: перекрут превращает «проверку данных» в
«верификацию», и такую фразу писать нельзя.

Написано 927 фраз по девяти типам: zerkalo 125, info 112, main 112, slots 98,
news 96, obzor 96, app 96, partnery 96, vhod 96.

Доля чистых среди тематических записей прозы:

| тип | было | стало |
|---|---|---|
| zerkalo | 20 % | 25 % |
| info | 33 % | 40 % |
| news | 38 % | 43 % |
| slots | 40 % | 45 % |
| main | 47 % | 51 % |
| obzor | 50 % | 55 % |
| vhod | 61 % | 64 % |
| app | 63 % | 66 % |
| partnery | 65 % | 68 % |
| **всего** | **42 %** | **46 %** |

bonus, promo и registracia не тронуты: по значениям они уже на корпусной
медиане или ниже неё.

### Чему научила проверка

Двадцать шесть промахов в первой партии и семнадцать во второй, и почти все —
на стыке мерки и языка:

* «платёж» через «ё» не совпадает с основой «плате» из заголовка «Платежи и
  вывод», «помогает» — с «помощ», «Стать» — со «стань», «Скачивание» — со
  «скача», «Новое» — с «новог», «Шансы» — с «шанса». Основа режется от формы в
  заголовке, и записи приходится писать под эту форму, а не под словарную.
* «за спиной» ловится шаблоном ставок `\bспин\w*` и считается термином.
* «домен», «лицензия», «выплата», «лимит», «турнир», «провайдер», «джекпот»,
  «верификация» — всё это термины; писать о зеркале, не называя зеркала, и о
  лицензии, не называя лицензии, оказалось главным упражнением партии.

### Сколько осталось

Чтобы плотность прозы упала с 47.0 до корпусных 34.9, доля чистых среди
тематических должна дойти до ~57 %. Сейчас 46 %, записей 16 089. Остаток —
около 4 300 фраз.

Замер первой партии (349 фраз, 48 парных сидов) это подтвердил: `terms_total`
промахи 1.50 → 1.62 (p = 0.7), медианы в пределах шума, цена нулевая, кроме
`nausea_acad` 0.94 → 1.15 (p = 0.049) — малую партию сорок восемь наборов
перебирают часто. Партия в тысячу фраз сдвига не даст; поле двинется ближе к
концу работы, и мерить имеет смысл не каждую партию, а накопленное.
