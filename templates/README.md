# Разбор шаблонов

Архивы содержат не готовые сайты, а **HTML-фрагменты текста** для страниц. Структура архива:

```
<N>-стр/<домен>/<страница>.html
```

- `N-стр` — группа: количество страниц в шаблоне. `<домен>` — папка одного сайта. `<страница>` — имя раздела (`main`, `vhod`, `slots`, …).
- Файл — фрагмент тела страницы: без `<html>`, `<head>`, `<body>`, без меню, шапки и подвала. Заголовка `h1` нет — его, как и обвязку, даёт сборщик сайта.
- Используемые теги: `p`, `h2`, `h3`, `ul`, `ol`, `li`, `strong`, `a`, `table/tr/th/td`, `details/summary`, `blockquote`.
- Плейсхолдеры, которые подставляет сборщик: `%brand_name_ru%`, `%brand_name_en%`, `%domain_name%`, `%date%`.
- Внутренние ссылки относительные: `/`, `/slots`, `/app`, `/registracia`, `/vhod`, `/zerkalo`. Внешних ссылок нет.
- Кодировка UTF-8 без BOM, переводы строк LF.

## Варианты шаблонов

Семейство вложенное: 7-стр — ядро, остальные добавляют к нему страницы.

| Шаблон | Страницы | Особенности |
|---|---|---|
| **1-стр** | `main` | 300–500 слов, 5–8 `h2`, FAQ в `<details>`, в конце строка «… проверена %date%». Ссылок нет. Бренд и в русском, и в английском варианте. |
| **7-стр** | `app`, `bonus`, `main`, `registracia`, `slots`, `vhod`, `zerkalo` | Ядро. Собирается из сайтов 9-стр: служебные страницы `privacy`, `contacts`, `about` выбрасываются. Формат страниц как в 10-стр. |
| **9-стр** | 7-стр + `contacts`, `privacy` | Как приходит в архиве. При проверке автоматически превращается в 7-стр (см. выше). В примерах наборы сайтов расходились: у каждого не хватало своей страницы (`registracia`, `vhod` или `privacy`). |
| **10-стр** | 7-стр + `about`, `contacts`, `privacy` | Первая строка каждой страницы — абзац с названием бренда: `<p>%brand_name_ru%.</p>`. На части страниц в конце «Последнее обновление %domain_name%: %date%». 150–1000 слов на страницу, обычно 1–3 `h2`. На многих страницах виджет «популярные слоты» (`h3` + RTP). Информационные страницы без ссылок. |
| **12-стр** | 7-стр + `info`, `news`, `obzor`, `partnery`, `promo` | 700–3000 слов на страницу, 5–12 `h2`. `main` начинается блоком «2026 Выбор игроков», далее «Что даёт …», «Игровой каталог …». `slots` и `promo` начинаются виджетом «Прогрессивные джекпоты» + «Последние выплаты». В конце страниц блоки «❓ Честные ответы на вопросы», «О портале …», «По этой теме». Страницы `app`, `bonus`, `slots` без плейсхолдера бренда — это допустимо. |
| **13-стр** | те же 12, что в 12-стр | 13-я страница при выкачке отсутствует, поэтому шаблон без неё. Отличается от 12-стр только стилем текста: страницы короче (450–2000 слов), в текстах ссылки «справка» ведут на `/`. |

## Заглушка

Отдельный тип брака — «заглушка»: файл ~600 байт, ~40 слов, без `h2`. Содержит один абзац, две кнопки (`/registracia`, `/vhod`), строку статистики («Кэшбэк 15%Карта за 83 минут…») и пять ссылок «… →» на `/`. Так выглядит страница, для которой генератор не сделал текст. В первом архиве целиком из заглушек состоят четыре сайта 12-стр, ещё у одного сайта 13-стр заглушками оказались `app` и `zerkalo` (там вместо текста три карточки провайдеров).

## Типовые дефекты (по первому архиву)

1. Страницы-заглушки и сайты целиком из заглушек.
2. Меньше страниц, чем заявлено в группе (13-стр с 12 файлами).
3. Чужой бренд в тексте вместо плейсхолдера: «Motor», «Daddy», адреса `support@Motor.com`, `support@Daddy-casino.com`, `support@example.com`, телефон `+7 123 456 78 90`.
4. Незаполненные переменные `{NAME}` и `{AMOUNT}` в тексте и заголовках.
5. Ссылки на страницу, которой в сайте нет (9-стр: ссылки на `/registracia` при отсутствии файла).
6. Ссылки «не на свой раздел»: «бонусы» ведут на `/app`, «промокоды», «обзор», «новости», «информация», «справка» — на `/`. В 12-стр по 150–280 таких ссылок на сайт. По решению — не дефект, только справочно.
7. Содержимое не соответствует разделу: в `main` лежит политика конфиденциальности, в `registracia` — текст про самоисключение, в `vhod` — про VPN.
8. Точные дубли файлов между сайтами и дубли внутри сайта (`main` включает весь текст `privacy`).
9. Повтор одного `h2` на странице, FAQ первым блоком.
10. Мусор в архиве: `__MACOSX`, `.DS_Store`.

## Принятые решения

1. **13-стр** — 13-й страницы при выкачке нет, шаблон без неё: те же 12 страниц.
2. **9-стр → 7-стр** — из сайтов 9-стр убираем `privacy` и `contacts`, получаем шаблон на 7 страниц. Страницу `about` тоже убираем: без этого выходит 8, а не 7. Если `about` нужна — вернуть её в `TEMPLATES[7]` и убрать из `CONVERT` в скрипте.
3. **Ссылки «не на свой раздел»** («бонусы» → `/app`, «промокоды» → `/`) — так задумано, не дефект (C2 справочно). Дефект только ссылка на страницу, которой нет (C1).
4. **Бренд** на странице может отсутствовать (B5 справочно).
5. **Маркировка 18+** не требуется, не проверяется.
