# Письмо пунктов с тематическим ярлыком

Запас помеченных пунктов в пулах — вход рычага мечения (`v5PorogMecheniya()`),
поэтому транш меняет не только уровень, но и всю кривую рычага. Порядок работы:

```
python3 spravka.py <тип>            # разделы, анкеры, прорези, полосы плотностей
<пишем руками>  <тип>.py            # ПУНКТЫ = {номер раздела: [(ярлык, тело, выделять), …]}
python3 dover.py <тип>              # доводчик плотностей по словарю вставок
python3 sobrat.py <тип> [<тип>…]    # девять проверок и семь полос, без записи
python3 sobrat.py <тип>… --писать   # вкручивание в пулы
```

Дальше — замер, и он обязателен:

```
python3 osest4.py                                   # модель осевшего журнала
python3 ../krivaya-metok.py --журнал=…              # кривая «порог → доля» заново
<пересчёт порогов по кривой>                        # разбор в docs/tematicheskie-metki.md
python3 ../zamer-metok.py … && ../raspred-metok.py  # парный замер и распределение
```

Что здесь легко сделать неправильно:

* **Транш без пересчёта порогов ломает распределение.** +1.5 пункта запаса
  подняли кривую на 8–12 пунктов в середине, и медиана набора ушла с 18.4 на
  22.5 % при корпусных 17.0.
* **Сборка не сверяет транши друг с другом** — только с пулами. Когда в одном
  прогоне идут несколько типов, повторы между ними надо проверять отдельно.
* **Полосы плотностей обязательны.** Новая запись вытесняет старую со всем, что
  та несла: первая партия bonus несла honest 0.01 против 0.16 у существующих, и
  приёмка это увидела.
* **Вёдра распределения шумят.** На двадцати четырёх наборах сумма квадратов по
  девяти вёдрам имеет шумовой порог 19.2 — решают медиана, децили и среднее.
* **«Уникальность» в приёмке — худшее совпадение с соседним набором.** Меньше
  значит лучше.

Словарь вставок `slovari.json` — язык, а не механика: хвосты со ссылками,
прорезями, цифрами, honest и терминами написаны под каждый тип отдельно.
