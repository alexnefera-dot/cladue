# Движок анализа контента под Яндекс (Фаза 3)

Локальный PHP-движок: парсит контент 7 страниц (HTML / DOCX / текст),
считает параметры из [`docs/parameters.md`](../docs/parameters.md), строит
матрицы перелинковки и схожести, отдаёт JSON для шаблона
[`template/index.html`](../template/index.html).

Работает **офлайн** — без обращения к API Яндекса.

## Требования

- PHP ≥ 8.1 с расширениями `dom`, `mbstring`, `zip` (для DOCX).

## Быстрый старт (веб-интерфейс)

```bash
# из корня репозитория
php -S localhost:8000
# открыть в браузере:
#   http://localhost:8000/template/index.html
```

На вкладке «Загрузка контента» заполните до 7 страниц (файл или вставка текста,
ключ + LSI) и нажмите «Проанализировать». Форма отправит POST в `engine/analyze.php`,
результат отрисуется на вкладке «Результаты».

Кнопка «Показать демо-данные» рисует пример без сервера.

## Быстрый старт (командная строка)

```bash
# анализ папки с файлами (берутся первые 7)
php engine/cli.php ./pages --domain=example.ru --out=report.json

# с ключами и LSI по каждому файлу
php engine/cli.php ./pages --keywords=keywords.json --out=report.json
```

`keywords.json`:

```json
{
  "index.html": { "keyword": "купить окна", "lsi": ["пластиковые", "монтаж"] }
}
```

## Проверка на тестовых данных

```bash
php engine/tests/make-fixtures.php          # создаст 7 связанных страниц
php engine/cli.php engine/tests/fixtures \
    --keywords=engine/tests/keywords.json --out=/tmp/report.json
```

## Формат результата (JSON)

```jsonc
{
  "pages": [
    {
      "name": "index.html",
      "url": "index.html",
      "keyword": ["купить окна"],
      "metrics": { "words_total": 145, "nausea_classic": 5.6, ... },
      "wordFreq": [["окна", 12], ...]
    }
  ],
  "link":    [[0,1,1,...], ...],   // матрица перелинковки 7×7
  "shingle": [[100,8,...], ...],   // матрица схожести 7×7 (%)
  "project": {                     // метрики уровня проекта
    "orphan_pages": 0, "dead_end_pages": 1,
    "internal_uniqueness": 85, "max_link_depth": 2, ...
  }
}
```

Ключи в `metrics` совпадают с id из `docs/parameters.md` и реестра
`template/assets/schema.js`, поэтому фронтенд рисует любой ответ без изменений.

## Архитектура

```
engine/
├── analyze.php          # HTTP-эндпоинт (POST формы -> JSON)
├── cli.php              # запуск по папке из терминала
└── src/
    ├── Parser.php       # извлечение текста из HTML / DOCX / plain
    ├── Morphology.php   # стеммер Портера-Снежка (RU) для сопоставления ключей
    ├── StopWords.php    # словарь стоп-слов (водность, «значимая» тошнота)
    ├── TextMetrics.php  # объём, тошнота, водность, Ципф, читабельность, типографика
    ├── SeoMetrics.php   # метатеги, заголовки, изображения, ссылки, разметка
    ├── Similarity.php   # шинглы -> матрица внутренней уникальности
    ├── LinkGraph.php    # граф перелинковки: сироты, тупики, глубина
    └── Analyzer.php     # оркестратор -> итоговый JSON
```

## Границы офлайн-анализа

Считается локально: объём, тошнота, водность, Ципф, читабельность, вхождения
ключей (по морфологии), метатеги, заголовки, изображения, микроразметка,
перелинковка 7×7, внутренняя уникальность, типографика.

**Не** считается офлайн (нужны внешние источники, см. `docs/parameters.md`):
внешняя уникальность/плагиат, реальные поведенческие факторы Яндекса, ИКС.
