# Своя проза для obzor — калибровка, не подключена

224 записи в восьми разделах `obzor`, написанные не из донорских фраз.
Совпадение с корпусом по пятисловным шинглам — 2,2 % против ~100 % у
остального пула, где каждая запись чья-то.

**В пулы они НЕ вставлены.** Замер показал, что вставка делает хуже:

| | против доноров | против конкурентов |
|---|---|---|
| старые пулы, 6 наборов | 4,2 % | 8,1 % |
| со свежими записями, 4 набора | 6,2 % | 7,7 % |

Причина в механике выдачи. Свежие записи — единственные невыданные в своих
слотах, поэтому каждый набор забирает их первыми и разом. Они вытесняют
разнообразный донорский материал, остаток тянется из меньшего числа доноров,
и доля самого частого донора растёт. Попытка обойти это, пометив записи
выданными, сделала ещё хуже (10,7 %): журнал перестал отличать своё от чужого.

Чтобы такая проза работала, нужно не 224 записи, а объём, сопоставимый со
слотом целиком, — тогда она не вытесняет, а заменяет. Это тысячи записей на
тип страницы.

Записи лежат здесь как заготовка на случай, если решим писать пулы всерьёз.
Формат совпадает с `pools.json`: `т` — текст, `п` — позиция в абзаце,
донор пустой.
