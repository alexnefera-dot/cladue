## Разметка карточки витрины

```html
<h2>{эмодзи} {категория}</h2>
<p>{подзаголовок}</p>
<!-- карточка ×4 -->
<p>HIGH RTP</p>          <!-- только при RTP ≥ 96,5 % -->
<p>{студия}</p>
<h3>{тайтл}</h3>
<p>RTP: {rtp}% {год}</p>
<p>{описание по шаблону A, B или C}</p>
```

**Порог метки `HIGH RTP` — ровно 96,5 %.** Граница чистая: последний тайтл без
метки идёт с 96,47 %, первый с меткой — с 96,5 %. Правило вытащено из 1 180
карточек, не назначено.

## Что вычищено при добыче

Словари собраны из чужого материала и несут его дефекты. Снято при добыче:

- **17 вхождений чужого бренда** «Lucky Bird» в шапках, H2-слоганах и одной
  подтеме — заменены на `%brand_name_en%`;
- **2 тайтла-призрака**: `%brand_name_en%` и `%brand_name_en% Spin` — их
  генератор подставил бренд прямо в название игры;
- **съеденные апострофы**: `Dracula 8217s Castle` → `Dracula's Castle`,
  и то же у `Gonzo's Gold`, `Warlock's Book`;
- `Playn GO` → `Play'n GO`;
- запятые и точки в начале жанра.

Не вычищено и требует решения при сборке: у трёх тайтлов из 206 нет жанра —
шаблоны A и C без него не собираются, для таких карточек берётся шаблон B.

## Чего в этих словарях нет намеренно

Номера лицензий, домены и адреса почты не добывались. У них на 50 страницах
стоит один номер `8048/JAZ`, а в тексте живут `github.com`, `mailinator.com` и
`etherscan.io`. Для нас это плейсхолдеры, которые подставляет заказчик.

## Прозаические разделы

Числа профиля собирает `build-profil-v5.php`, прозу подмешивает
`--текст=profil-v6-tekst.json`, поэтому пересборка профиля не стирает выводы.
Разделы наследованы от `profil-v5-B.json`; по разбору образца переписаны три:

- **`FAQ.образец_разметки`** — голые `<details>`. Микроразметки schema.org нет
  ни на одной из 294 страниц образца, а поле `faq_pairs` разделяло корпуса
  надёжнее всех остальных — 99,1 %. Задание берёт разметку отсюда; у профилей
  без этого ключа остаётся августовская схема, иначе правка молча переписала бы
  и задания по v5, под которые написан весь нынешний корпус.
- **`структура.слои`** — семь слоёв и указание, что писать надо только слой 4
  (тема) и слой 6 (FAQ), остальное кладёт `engine/sloi-v6.php`.
- **`структура.тема_h2`** — тема-H2 открывается абзацем ровно в половине
  случаев: 143 страницы образца из 294, остальные 137 идут сразу `<h3>`.
- **`регистр.вода`, `регистр.повелительное`, `регистр.числа`, `регистр.вы`** —
  три нормы, которые не закрываются сборщиком, с целями по каждому типу
  страницы.
