# Бекап: генератор доменов + разбор чеков Spaceship

Python 3, только стандартная библиотека. Ничего ставить не нужно.

## Файлы

- `USED.txt` — реестр всех ранее выданных имён (без TLD, по одному в строке).
  Главный файл: именно он гарантирует, что новые имена не повторятся.
- `gen.py` — генератор новых имён.
- `extract_pdf.py` — извлекает текст из PDF-чека Spaceship (свои шрифты
  с subset-кодировкой, поэтому обычные парсеры текст не видят).
- `reconcile.py` — чистый список доменов из чека + сверка с выданной партией.
- `batches/` — выданные партии, по файлу на партию (`имя.tld` в строке).

## Генерация

```bash
python3 gen.py 150 lol     # 150 имён .lol
python3 gen.py 100 team    # 100 имён .team
python3 gen.py 50 buzz
```

Правила, под которые настроен генератор:
- длина имени ровно **4 символа** (3-символьные почти всегда заняты);
- **без слова `casino`** в имени;
- состав: ~60% четыре цифры, ~25% четыре буквы, ~15% чередование буква/цифра;
- каждое имя проверяется против `USED.txt` и против текущей партии,
  после генерации новые имена дописываются в `USED.txt`.

Партия сохраняется в `batches/<tld>-<N>-<дата>`.

## Разбор чека

```bash
python3 reconcile.py ~/Downloads/spaceship-xxxx.pdf batches/lol-150-2026-11-18
```

Выведет список доменов из чека в исходном порядке и затем те имена партии,
которые в чек не попали (не зарегистрировались). Второй аргумент можно
не указывать — тогда просто печатается список из чека.

Если домен в PDF вышел обрезанным или с прилипшей ценой, скрипт пробует
восстановить его по `USED.txt` и по ещё не найденным именам партии; если
не получилось — строка помечается `<-- не распознано` с вариантами.

## Важно про `USED.txt`

Это единственное, что нельзя терять: без него генератор начнёт выдавать
повторы. Храните его в git / синхронизируемой папке и переносите вместе
со скриптами.

Текущий реестр восстановлен из истории переписки и содержит не все самые
ранние партии (август–сентябрь), поэтому редкие совпадения со старыми
именами возможны. Дальше реестр пополняется автоматически и этой проблемы
больше не будет.
