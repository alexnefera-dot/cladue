# CLAUDE.md — домены: генерация и разбор чеков

Инструкция для Claude. Если ты читаешь это в новой сессии — здесь весь
контекст задачи, продолжай без лишних вопросов.

## Что это за задача

Пользователь массово регистрирует короткие «одноразовые» домены у регистратора
Spaceship. Claude в этом цикле делает две вещи:

1. **Генерирует партии имён** по короткому запросу: «150 lol», «20 team»,
   «100 lol и 100 team но с разными именами», «дай 70 team 30 lol отдельными
   списками». Ответ — просто список `имя.tld`, по одному в строке, в блоке кода.
   Никаких пояснений и таблиц, пользователь копирует список целиком.
2. **Разбирает чеки.** Пользователь прикладывает PDF-чек Spaceship — часто
   вообще без текста запроса. Приложенный PDF сам по себе означает: «дай список
   доменов из этого чека». Ответ — чистый список доменов в исходном порядке,
   количество, и отдельно какие имена из выданной партии в чек не попали.

## Правила генерации (установлены пользователем, не меняй без его просьбы)

- **Ровно 4 символа** в имени. Раньше генерировались и 3-символьные — у них
  почти все имена заняты, доля отказов регистратора была ~16% на партию.
  После перехода на 4 символа — 0–7%.
- **Без слова `casino`** в имени. (В ранних партиях ~30% имён намеренно
  содержали `casino` — это отменено.)
- Состав: ~60% четыре цифры, ~25% четыре буквы, ~15% чередование буква/цифра.
- **Каждая партия уникальна** против всех ранее выданных имён и внутри себя.
  Когда просят несколько зон за раз «с разными именами» — имена не должны
  повторяться и между зонами.
- Зоны в работе: `.lol`, `.team`, раньше также `.casino`, `.buzz`.

## Как работать

Всё лежит в `domains-backup/`, только стандартная библиотека Python 3:

```bash
python3 gen.py 150 lol          # сгенерировать партию, допишет USED.txt
python3 reconcile.py чек.pdf batches/lol-150-2026-11-18
```

`reconcile.py` печатает список из чека и затем непрошедшие имена партии.
Партии сохраняются в `batches/<tld>-<N>-<дата>` — файл партии нужен при
разборе чека, чтобы понять, что не зарегистрировалось.

**Чеки Spaceship нельзя читать обычными средствами.** Инструмент Read
возвращает для них только «PDF file read», без текста; `pdftotext` в
окружении нет; `pypdf`/`PyPDF2` ставятся, но падают на импорте
(`_cffi_backend`, panic в rust-биндингах `cryptography`). Поэтому есть
`extract_pdf.py` — он сам распаковывает потоки через `zlib` и собирает текст
по `/ToUnicode` CMap каждого subset-шрифта. Не трать время на библиотеки,
используй его.

Две известные особенности разбора, обе уже обработаны в `reconcile.py`:
- к имени домена иногда приклеивается колонка с ценой (`08dvgc.team`,
  `273294casino.team`) — срезаются 1–4 ведущих символа с проверкой по реестру;
- имя бывает обрезано (`qi.lol`, `hk.team`) — восстанавливается по совпадению
  окончания с ещё не найденными именами партии. Если вариантов несколько,
  строка помечается, и надо выбрать по тому, какое имя уже встречалось
  в предыдущих чеках.

## Реестр `USED.txt` — главное

Один файл, имена без TLD, по строке. Это единственный источник уникальности.
**Держи его в git.** История: в облачной сессии он дважды терялся при
перезапуске контейнера вместе со всем scratchpad, восстанавливать приходилось
из истории переписки.

При восстановлении из transcript-а (`.jsonl`) **не используй grep**: переносы
строк хранятся в JSON как литеральный `\n`, и grep склеивает «n» с началом
следующего имени — получается мусор вида `n1991` вместо `1991`, и настоящее
имя при этом теряется. Парси строки через `json.loads` и обходи значения —
как в `history/recover_from_transcript.py`.

Текущий реестр — 895 имён, восстановленных из истории переписки. Это **не
вся** история: партии с августа по начало октября 2026 (в основном `.team` и
`.casino`) в переписке уже не сохранились. Поэтому редкие совпадения с очень
старыми именами возможны; если регистратор отбивает имя как занятое, просто
догенерируй замену. Дальше реестр пополняется автоматически.

`history/all-domains.txt` — то же самое, но с TLD (`имя.tld`), на случай если
понадобится узнать, в какой зоне имя уже бралось.

## Как отвечать

Коротко. Список в блоке кода — и всё. Для чека: «Всего в чеке — N», список,
затем «Не попали в чек — M» с перечислением. Проверяй, что N + M равно размеру
партии, и показывай это. Пользователь пишет по-русски, отвечай по-русски.
