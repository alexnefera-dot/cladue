Что нужно знать до списка

Человек не видит сайт

Любой URL с /ru отдаёт человеку 302 на ref_link; страницу видят только боты и whitelist. Значит контент, палитра, логотипы и popup влияют не на конверсию, а на то, как страницу оценивает Яндекс. Связывать оформление с регистрацией — искать эффект там, где его не может быть.

«Клик» в системе ≠ посетитель

870 тысяч кликов на 226 тысячах сабдоменов при ~500 регистрациях: 0.05%, и клики есть у 74% сабдоменов. Это счётчик срабатываний редиректа. Метрика полезная, но деньги считаются только по трекеру.

Единица — сабдомен

306 тысяч сабдоменов на 1649 баз, в среднем 186 на базу, не 200. Знаменатель берётся из фактических строк.

Ключ соединения — хост

shuffle.3479.team связывает запуск, пайплайн, трафик и деньги. Во всех ответах пишется одинаково: нижний регистр, без схемы и www.

Два расхождения, которые стоит проверить отдельно

Apache режет глубину на 20, PHP разрешает 40, hreflang объявляет 40. Значит уровни 21–40 объявлены, но ведут в 302 на корень — всем, включая ботов. Половина заявленной структуры мертва. Увидим по тому, какие уровни реально приходят в кликах.

После soft-delete базы сабдомены и клики зачищаются. Сейчас удалённых нет, но если появятся — аналитика по ним исчезнет задним числом. Стоит либо не удалять, либо выгружать до удаления.

Правило

Эксперименты судим по кликам. Деньги считаем накопительно и по неделям не сравниваем. Ветка с лучшими кликами может быть убыточной, если она в дорогой зоне — поэтому решение в два шага: клики говорят, какой вариант работает, накопленная экономика говорит, окупается ли.

И: параметры базы (контент, зона, пак) ограничены числом баз — 587 в неделю. Параметры сабдомена (волна, бренд, уровень) различаются внутри базы, там выборка в двести раз больше. Путать эти два случая — завышать мощность в двести раз.

Что вы получаете

Каждую неделю: воронка по шагам с долями и лагами от обеих точек отсчёта · экономика с порогом цены домена · разрезы по каждому рычагу с пометкой «читается / шум / копится» · распределение уровней вложенности · три строки приоритетов.

Раз в месяц: окупаемость зон · измеренный срок жизни сабдомена · износ бренда и переиспользование пака · верификация и квота как источник потерь.

Часть 3 · API

Две системы отдают данные. Система запусков — четыре эндпоинта, трекер — два. Контракт одинаковый.

Общие правила обеих систем

чтокак
метод и форматтолько GET, ответ JSON, charset=utf-8
авторизацияAuthorization: Bearer <token>
времяISO 8601 со смещением: 2026-09-15T13:03:11+03:00. Europe/Kyiv везде, в обеих системах
только дата2026-09-15, границы включительно
нет значенияnull. Не пустая строка, не 0, не "-"
булевоtrue / false
хостнижний регистр, без схемы и www: shuffle.3479.team. Одинаково в обеих системах — это ключ соединения
повторный запростот же диапазон → те же строки, порядок стабильный

Обёртка ответа — одна на все списочные эндпоинты:

{
  "data": [ ... ],
  "meta": {
    "count": 1000,
    "next_cursor": "eyJpZCI6MzA0MTJ9",     // null — это последняя страница
    "generated_at": "2026-09-15T18:20:04+03:00"
  }
}

limit по умолчанию 1000, максимум 5000. cursor — непрозрачная строка из предыдущего ответа. Offset не используем: 306 тысяч строк.

Ошибки:

{ "error": { "code": "invalid_range", "message": "date_to earlier than date_from" } }

unauthorized 401 · invalid_param 400 · invalid_range 400 · rate_limited 429 · internal 500.
