Каталог параметров для аналитики запусков (dorgen-engine)
Снято: 2026-09-15. Код и схема не менялись — только инвентарь того, что уже можно отдавать.
Ключ джойна с трекером: полный хост сабдомена (domains.url), например shuffle.3479.team.
«Запуск» = lifecycle одного content_domain (база xxx.team), не отдельная таблица.

Снимок БД на момент съёмки:
  ~1649 баз (soft-deleted = 0), ~306k сабдоменов, ~206 видимых брендов на запуск,
  пайплайн completed ~1358 баз, Cloudflare-аккаунтов ~898, YA-аккаунтов ~1378.


==============================================================================
ЧТО ВАЖНО ПОНЯТЬ ДО СПИСКА
==============================================================================

Глубина /ru/ru/ НЕ пишется в строку запуска.
  Это глобальный runtime: PHP maxRuDepth=40, Apache RewriteMap режет (/ru){21,}
  (зашито как 20). Историю «какой лимит был в день запуска» из БД не восстановить.
  Для людей любой URL с /ru уже уходит 302 на ref_link; боты видят сайт.
  Hreflang наращивает /ru до лимита.
  Коды hreflang: ru, en, x-default, ru-KZ, en-AU, ru-BY, ru-UZ, ru-SG, ru-ZA,
  ru-PH, ru-RU, ru-HK, ru-PK, ru-US, ru-CA, ru-IE.

Cloudflare Worker сейчас не живой:
  cron add_workers_to_cloudflare выключен, domains.is_worker_added у всех NULL.
  Гео-редирект идёт с origin (PHP + Apache map).
  IndexNow-ключи есть, cron отключён.
  Позиции Яндекс/Google — 0 строк.

После soft-delete базы сайты/домены/клики purge — аналитика по сабдомену пропадает.
Сейчас soft-deleted = 0.

Практичная выгрузка: одна строка = сабдомен, конверсии джойнятся по url;
поля запуска/аккаунта/пака/бренда денормализовать в эту строку.
