# Каждый домен отдельно, сложенные в пулы

`analysis/scripts/po_domenam.py`. Пул — пак плюс день переобхода: всё, что в
этот день ушло на одном контенте. Внутри пула строка = один домен базы.

Данные: 1922 базы, 389 498 сайтов, запуски по 18.09 включительно. Первый
поисковый клик берётся из двух источников — накопленной выгрузки по сабдоменам
и свежей выгрузки кликов за 16–21.09, минимум из двух. Без второй у запусков
после 15.09 окно не закрыто и они выглядят пустыми.

Полная раскладка: `analysis/export/po_domenam_21.09.csv` (1922 строки) и
`analysis/export/po_domenam_21.09.txt` (все 117 пулов поимённо).

Выход в поиск за трое суток по сети — **13.2%**.

## Каждая база несёт ровно один пак

Баз с двумя и более паками: **0**. Пак не смешивается внутри базы, поэтому
«пул» и «пак + день» — одно и то же, и сравнение доменов внутри пула — это
сравнение при полностью одинаковом контенте.

## Разброс — свойство домена, а не случайность выдачи

В блоке гипотез я допускал, что разброс между экземплярами может быть просто
непуассоновской случайностью: один сайт вытягивает кластер запросов, и всё.
Две проверки говорят, что нет.

**Расщепление пополам внутри домена.** Сайты каждой базы случайно делятся
надвое, выход считается в каждой половине.

| | Спирмен между половинами |
|---|---|
| фактические данные, 1921 база | **0.88** |
| смоделированный шум при общей ставке | −0.00 |

**Вторая волна против первой.** Первая волна домена и его же вторая волна —
разные бренды и разный день, то есть настоящая проверка вне выборки.

| | значение |
|---|---|
| баз, где обе волны досмотрены | 1841 |
| Спирмен «первая волна ↔ вторая волна того же домена» | **0.73** |
| верхняя четверть по первой волне → её вторая волна | **14.6%** |
| нижняя четверть по первой волне → её вторая волна | **1.7%** |

Разрыв в 8.6 раза, предсказанный по первому дню и замеренный на втором.

Это значит: качество домена устойчиво и предсказуемо. После первой волны
уже видно, чего ждать от второй, и решение можно принимать в тот же день.

## Что с этим делать

Из этого следует правило, которого сейчас нет: **ранжировать домены по первой
волне и не тратить вторую волну на нижнюю четверть.** Она даёт 1.7% выхода в
поиск — это 25% объёма сети, работающих почти вхолостую.

Чего это не говорит: почему один домен лучше другого. Ни зона, ни час, ни
аккаунт, ни паттерн имени разброса не объясняют (проверено в
`PROSADKA_20.09.md`). Известно только, что свойство есть и что оно измеримо
на второй день.
