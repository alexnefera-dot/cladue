# Тесты на неделю 28.09–04.10

Контент выбирается как обычно, случайными группами — его разбирает отдельная задача.
Тесты проверяют то, что НЕ контент: раскладку по Cloudflare, зону, число страниц, дату в тексте.
Чтобы контент не мешал тестам (и тесты не мешали разбору контента), действует одно правило:

**каждая группа контента в любой день делится между плечами теста поровну.**
Пришло 10 доменов на content-X — 5 в одно плечо, 5 в другое, чередованием (1-й в А, 2-й в Б, 3-й в А…).
Тогда разница между плечами не может быть разницей контента, а у разбора контента в каждой группе
есть все варианты настроек.

## Термометр дня — каждый день

6 доменов `.team` на одном и том же эталонном контенте, раскладка как до 23.09 (2 базы на аккаунт Cloudflare).
Эталон: `content-2026-09-25-пул5-oform` (26.09 дал 14,6% за сутки). Если пул кончится — `content-2026-09-21b-12str`.
Зачем: 23–25.09 выход упал в 2–5 раз, и до сих пор нельзя отделить «плохой день у Яндекса» от «плохого пула».
Термометр отвечает на это каждый день: если он упал вместе со всеми — это день, если нет — это то, что запустили.

## Что записывать

Почти всё видно из API само: зона — из домена, раскладка — из `cf_account_id` / `cf_cd_count_at_launch`,
контент и экземпляр — из `content_label`. Число страниц в API пустое (`pages_count`), поэтому
оно должно быть в имени контента (`7str` / `12str`), как сейчас. Дату в тексте из API не видно:
если тест «дата» идёт — в имени контента нужна метка (`withdate` / `nodate`) или отдельный список доменов.

Термометр: список из 6 доменов каждого дня (или отдельное имя контента, которое больше нигде не используется).

## Как оценивать

- Главная мера — **выход в поиск за 24 и 72 часа** (доля сайтов с кликом из поиска). На 15–25 доменах она
  различает разницу около 30% (например 15% против 11%).
- Сравнение только **внутри одного дня и одной группы контента**, итог — среднее по таким парам,
  значимость — перестановкой плеч внутри пары (как в разборе зон).
- Деньги (рег/ФД) — сложить по всей неделе на плечо; на 100+ доменах в плече различима разница примерно вдвое.
- Термометр — отдельной строкой в каждом отчёте; по нему делится индекс остальных запусков дня.
