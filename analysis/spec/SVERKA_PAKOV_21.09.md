# Сколько баз с паком в интерфейсе, но без метки в API

`analysis/scripts/sverka_pakov.py`. Единица — база (домен). База считается
«есть в API», если `content_label` стоит хотя бы у одного её сабдомена, и
«есть в журнале», если домен упомянут хоть в одном файле `analysis/launch_*.txt` —
это выгрузка из интерфейса, где секция названа паком, а под ней перечислены домены.

Баз всего 1922. В журнале упомянуто 1502.

## Что это значит для прежних выводов

Рейтинг паков и все разборы по контенту держатся на журнале запусков, а не на
API: в API есть метка только у 567 баз из 1922. Это не ошибка анализа — журнал
и есть источник истины, — но это значит, что **любой вывод по контенту
воспроизводится только при наличии `analysis/launch_*.txt`**, а из одного API
его не повторить.

Если в экспорт добавить `content_id` задним числом, 1069 баз закроются
автоматически и проверка перестанет зависеть от txt-файлов.

# Починка нормализатора и пересборка

`analysis/scripts/perenormalizaciya.py`. Панель переписана с исправленной
картой имён, без перевыгрузки данных.

## Что было сломано

**1. Затирание имени.** `content_by_domain()` писал `out[d] = (name, day)` без
условия. Один домен встречается и в недельном файле журнала, и в общем; пустое
имя из одного затирало настоящее имя из другого. Отсюда 94 базы без пака при
живом заголовке.

**2. Дата срезалась вместе с номером экземпляра.** Выражение
`[_\s]*\d+\s*[…\.]{1,3}\s*_?\d*$` задумывалось под `_1…_50`, но съедало и
`_24.08`. В результате `Generator_11page_NOimg_24.08` и `..._25.08` — два
разных запуска — сливались в одно имя, а заодно ломался отбор.

**3. Баннеры секций проходили как имена паков.** `ЗАПУСКИ 24.08.2026 — 42 домена`
нормализовалось в `ЗАПУСКИ 24.` и становилось «паком».

**4. Разные написания одного пака не сходились.** `КОНТРОЛЬ · NEW50_5…` и
`КОНТРОЛЬ NEW50_5…` из разных файлов журнала считались разными паками.

## Что исправлено

Номер экземпляра срезается только в формах `_1…_50` и `_44` / `_372373` —
подчёркивание плюс только цифры до конца. Дата уцелевает: в `_24.08` после
подчёркивания не одни цифры. Разделитель `·` приводится к пробелу. Баннеры
секций отбрасываются. Имя из журнала не затирается пустым из другого файла.
