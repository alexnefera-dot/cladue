01 · Восстановление

Поиск вернулся выше прежнего

Запись входа вернулась сама 4 октября в 01:56 — откатывать прямые реф-ссылки не пришлось. 5 октября поиск дал 70 025 живых кликов за 14 часов: вдвое больше, чем 1 октября до поломки.

Что всё ещё не работает — привязка регистраций к домену. За 04–05.10 в трекер пришло 5 рег против 10–20 в сутки раньше: постбэк без clickid не сшивается. Пока в прямую ссылку не добавлен subid, деньги по доменам и контентам не считаются.

Две трети трафика дают запуски 1–3 октября

Сентябрьские домены дают 17% трафика, хотя их в десятки раз больше. Но главное — сменился режим: прорывается меньше сайтов, зато каждый прорвавшийся даёт в разы больше.

08 · Решения

Что из этого делать

  • Добавить subid в прямую реф-ссылку — значение бренд.база.зона. Без него выводы по деньгам опираются на историю, а режим сети уже поменялся. Разбивка придёт прямо из партнёрки, трекер для этого не нужен.
  • Пересобрать список брендов. 61 из 206 даёт ноль кликов — треть запусков впустую. Слоты отдать тем, кто справа: Lucky Bird, Leon, Martin, Mellstroy, Pinco, Luckybear, Олимп.
  • Не гнаться за Jetton. Он выигрывает поиск и проигрывает кассу. Держать как источник объёма можно, считать успехом — нет.
  • Сдвигать долю в .lol. Вдвое лучше .team по трафику и вдвое дешевле.
  • Сменить меру успеха. Индекс 1,7% при удвоенном трафике — мера больше не описывает происходящее. Считать кликами на запущенный сайт.
  • Разобраться с квотой 150/домен/сутки. Либо поднимать, либо распределять сайты по доменам ровнее — сейчас четверть каждого запуска ждёт следующих суток.
