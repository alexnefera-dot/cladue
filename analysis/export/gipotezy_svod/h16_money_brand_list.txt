Часть (а) — есть ли список брендов по конверсиям и воспроизводим ли он (498 событий = регистрации + ФД на 270 доменах после фильтра).
  1. Список существует: топ-10 брендов держат 34% всех конверсий, тогда как при случайном бренде записи было бы 18%
     (нуль R-K, p = 0.0001); брендов с конверсиями 127 вместо ожидаемых при случайном выборе из 206 — около 176.
  2. Верхушка списка воспроизводится: топ-10 по одной половине запусков собирает 27% другой половины при разбиении
     по чётности дня (при случайности 8%, p = 0.0001), 29% при разбиении август → сентябрь (p = 0.0001),
     24% на доменах с чистой оконной атрибуцией (p = 0.0001) и 24% без «КОНТЕНТ НЕ ЗАПИСАН» (p = 0.0001). Порог постановки 25% выполнен
     в двух главных разбиениях и почти выполнен в двух контрольных. В обеих половинах по чётности в топ-10 входят 6 брендов
     (Cactus, Eva, Leon, Lucky Bird, Martin, Pinco) при 1.7 ожидаемых по случайности (p = 0.0081); авг → сен — 7 брендов при 1.9 (p = 0.0053).
  3. Но порядок внутри списка не воспроизводится. Спирмен по брендам с ≥3 конверсиями = 0.05 (чётность) и 0.14 (авг → сен) —
     это далеко от 0,4–0,7 из постановки. Однако сам критерий здесь неприменим: у бренда с 3–6 конверсиями A + B почти
     постоянна, поэтому под нулём «бренд случаен» Спирмен по таким брендам не 0, а около -0.40; наблюдённое выше нуля с p = 0.0001.
     Честная мера порядка — Спирмен по всем 127 брендам с нулями (нуль около 0.00): 0.15 при чётности (p = 0.0400), 0.08 авг → сен (p = 0.1813).
     То есть: «эти 10–15 брендов конвертируют, остальные почти нет» — устойчиво; «кто из них первый, кто десятый» — шум.
