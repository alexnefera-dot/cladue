# Pipboy — нативное приложение (Swift, macOS → iPhone)

Настоящий .app без Chrome и без npm. Окно = WKWebView (родной движок Apple)
с нашим веб-интерфейсом внутри; сверху — нативный Touch ID и уведомления.
Весь фронт переиспользуется как есть.

## Что нужно (один раз)
1. Xcode из App Store (бесплатно, большой — ставится долго).
2. Node.js (`brew install node`) — сервер крутится локально рядом с приложением.
3. Для iPhone позже: Apple Developer Program ($99/год). Для Mac не обязателен.

## Запуск Mac-версии — проект уже в репозитории
Проект готов и лежит прямо здесь (`native/Pipboy.xcodeproj`), файлы подключены
ссылками — ничего перетаскивать и настраивать не нужно.

1. Клонируй репозиторий **строго в `~/Downloads/cladue`** (этот путь зашит в
   ServerProcess.swift как repoRoot; хочешь другую папку — поправь там одну строку):
   ```
   git clone <repo-url> ~/Downloads/cladue
   ```
2. Открой `~/Downloads/cladue/native/Pipboy.xcodeproj` в Xcode.
3. Нажми ▶ (Run). Подпись стоит «Sign to Run Locally» — Apple-аккаунт не нужен;
   песочница выключена, ATS для http://localhost прописан в Info.plist.
4. Откроется Touch ID → приложение. При первом включении тумблера «🔔 системные
   напоминания» в «Рутины» macOS спросит разрешение на уведомления — разреши.

> Если Xcode попросит выбрать команду подписи — оставь **Sign to Run Locally**
> (или выбери свой личный Apple ID team, тогда подпись будет стабильнее).

## Обновления — больше никакого перетаскивания
Веб-код приложение тянет само: ServerProcess при каждом запуске делает `git pull`
в `~/Downloads/cladue` и перезапускает сервер. Достаточно переоткрыть приложение.

Если менялись и Swift-файлы оболочки — обнови репозиторий и пересобери:
- в Xcode: **Source Control → Pull…**, затем ▶ Run; **или**
- в терминале: `git -C ~/Downloads/cladue pull`, затем ▶ Run в Xcode.

Файлы подключены ссылками на `native/Pipboy/*.swift`, поэтому `pull` обновляет их
на месте — Xcode видит свежий код сразу, копировать ничего не надо.

## Упаковка: работать без Xcode (standalone .app)
Чтобы запускать Pipboy из Launchpad/Dock, не открывая Xcode каждый раз:

1. В Xcode выбери схему **Pipboy** → **Product → Archive** (соберёт Release).
2. В окне Organizer: **Distribute App → Custom → Copy App → Export** → сохрани
   куда угодно. Получишь `Pipboy.app`.
3. Перетащи `Pipboy.app` в **/Applications** (папка «Программы»).
4. Первый запуск: правый клик по иконке → **Open** (один раз — обойти Gatekeeper
   у локально подписанного приложения). Дальше — обычным кликом, можно закрепить в Dock.

### Как прилетают апдейты в упакованную версию
- **Веб-правки (99% изменений)** — сами: при каждом запуске приложение делает
  `git pull` в `~/Downloads/cladue` и грузит фронт из `app/public`. Просто переоткрой.
  *(Клон обязан лежать в `~/Downloads/cladue` — оттуда читается фронт и тянутся апдейты.)*
- **Swift-правки (оболочка, редко)** — пересобрать: `git pull` → повторить шаги 1–3
  (Archive → Copy App → заменить в /Applications).

## Дальше
- Уведомления — готово: рутины/события/задачи/практики со временем шлют системные
  пуши (Notifications.swift), управление в Настройки → 🔔 Уведомления.
- Авто-замок по бездействию — готово (IdleLocker): палец при запуске, через 10 мин
  простоя — снова Touch ID.
- iPhone: тот же WKWebView + нативный слой данных (как на Маке), но локальная SQLite
  на устройстве; синк Mac↔iPhone по Wi-Fi без облака. Отдельный таргет — следующая фаза.

## Почему так
- Swift не использует npm — обходит то, что ломалось с Electron.
- WKWebView = тот же UI, но в родном окне Apple, с настоящим Touch ID.
