Установка при выключенной сети: что успевает встать

Файл сборки %brand_name_en% скачан заранее, интернет пропал, а поставить программу хочется сейчас. Установка при этом проходит, и телефон рапортует об успехе.

Успех неполный: половина работы у %brand_name_en% делается уже после первого запуска с сетью.

Что лежит внутри файла

В пакете лежит оболочка: интерфейс, шрифты, значки и список действующих адресов на день сборки. Ни одного тайтла %brand_name_en%, ни одной строки каталога и ни единого числа по вашему счёту внутри нет — всё это подтягивается с сервера при первом запуске.

Порядок установки без интернета

  1. Разрешить установку из файла — разово, в системных настройках
  2. Поставить пакет поверх старой сборки, не удаляя её
  3. Выдать разрешение на хранилище, остальные можно пропустить
  4. Включить сеть и открыть программу: каталог подтянется за 5 — 20 секунд
Постав можно собрать всухую, без зерна. Работать он начнёт только с засыпкой, и до неё судить о помоле нечем.

Чем опасен старый файл

  • Список адресов протух. Домены живут месяцами, файл — сколько угодно
  • Протокол кассы сменился. Депозит и вывод средств откажут первыми
  • Файл взят не с площадки. Пакет из чужой ссылки проверять нечем

Итог

Без сети встаёт оболочка, и этого достаточно, чтобы не терять время. Смысл появляется после первого запуска с интернетом: тогда обновляется список адресов, подтягивается каталог и открывается касса. Свежий пакет берут только на действующем домене, а не по ссылке из переписки. Состояние счёта видно после входа в кабинет, паспортный RTP тайтлов — в каталоге автоматов, требования к документам — в анкете игрока, действующие адреса — на странице обвода.

Частые вопросы об установке сборки %brand_name_ru%

Каталог пустой после установки — это сбой?

Нет, тайтлов в пакете нет вовсе. Список подтянется с сервера при первом запуске с интернетом.

Можно ли поставить сборку на второй телефон?

Можно, ограничений по числу устройств нет. Играть при этом получится только на одном: игровая сессия одна на счёт.

Сколько весит пакет и сколько занимает потом?

Сам файл от 60 МБ, с накопленным кешем до 400 МБ за месяц. Кеш чистится системными средствами.

Касса не открывается после установки — почему?

Скорее всего файл старый: протокол платежей меняется чаще интерфейса. Скачайте свежий пакет с действующего адреса.

Нужно ли удалять прежнюю сборку перед установкой?

Нет, ставьте поверх. При полном удалении пропадут расписка входа и локальные настройки каталога.

Идёт ли отыгрыш, пока сборка стоит без сети?

Срок идёт всегда, а вот оборот набирается только ставками. Вейджер без спинов не двигается.

Почему список адресов внутри файла устаревает?

Он записан на дату сборки, а домены меняются раз в несколько месяцев. Обновляется список при запуске с сетью.

Влияет ли способ установки на отдачу автоматов?

Нет. RTP и волатильность заданы провайдером и считаются на сервере, оболочка только рисует барабаны.

Что делать, если система не даёт установить файл?

Разрешить установку из файла в настройках безопасности. Разрешение разовое и отзывается сразу после установки.

Обязательна ли сборка или хватит браузера?

Хватает браузера: тот же счёт, тот же каталог, та же касса. Сборка даёт только список адресов и уведомления.
