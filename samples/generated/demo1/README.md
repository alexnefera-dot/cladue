# Тест-генерация demo1 (бренд Казиновия / Casinovia)

Три страницы одной связки, собранные по стохастическому генератору
(`engine/generate.php` → промпт → реализация → `engine/verify.php`).

## Единый стиль генерации (один на все страницы связки)
Голос: без первого лица, обращение на «вы»; именование бренда сбалансировано;
эмодзи в теле — только на главной. Тон/манера совпадают на всех страницах —
это одна «связка от одного автора», варьируется только структура и объём.

## Попадание в коридоры корпуса (движок v2)
| Страница | Метрик в коридоре |
|---|---|
| zerkalo | 20/20 (100%) |
| bonus | 18/20 (90%) |
| slots | 18/20 (90%) |
| **Итого** | **56/60 (93%)** |

Оставшиеся отклонения — маргинальные (в пределах ±20% по плотности цифр/сущностей).
Все структурные (объём, H2, FAQ, списки, таблицы) и голосовые (первое лицо, «вы»,
императивы) метрики — в коридоре. Полный отчёт: `VERIFY.txt`.

## Как воспроизвести
```bash
# промпт по типу (стиль-профиль связки берётся из бренда/домена)
php engine/generate.php --type=zerkalo --brand-ru=Казиновия --brand-en=Casinovia \
    --domain=casinovia.win --seed=demo1 --prompt

# проверить готовую страницу против коридоров корпуса
php engine/verify.php samples/generated/demo1
```
