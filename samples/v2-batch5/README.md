# Пять наборов перед боевым запуском (блочные главные)

Собраны финальным кодом: все 7 фиксов генератора + блочная сборка главной
(`split-page.php --blocks=3` → реалайз блоков → `merge-blocks.php`). Сателлиты
one-shot. Замер: `php engine/check-batch.php samples/v2-batch5 --corpus=dorgen`.

| Набор | Донор | Регистр | Совпадение | Остаточные красные |
|---|---|---|---|---|
| A | set199 | экспертный «я» | **92%** | цифры, императивы |
| D | set229 | безличный | 89% | вода, тошнота |
| B | set235 | личный «я» | 87% | императивы, цифры |

**Средний 87%, лучший 92%** — против 78–86% до блочной сборки.

> Цифры выше — по `check-batch.php`. `compare-vs-donor.php` на тех же наборах
> даёт ±1 п.п. (напр. D 88%, E 83%): инструменты считают немного разные наборы
> полей. Для сравнения прогонов между собой используй один и тот же инструмент.

Выводы для боевого запуска:
- Экспертные/личные регистры («я») дают лучший результат — 87–92%.
- Продающий «вы»+CTA стабильно слабее (83%) — ему нужен verify-loop либо
  отдельная докрутка профиля.
- Остаточные красные везде одни и те же: вода, тошнота, прилагательные,
  плотность цифр — структурные натяжения ниши, не промахи промпта.
