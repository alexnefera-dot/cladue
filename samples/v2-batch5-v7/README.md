# Перегенерация после вычитки референсов (v7)

Собрано после того, как вычитка реальных текстов конкурента вскрыла две дыры,
которых метрики не видят.

## Что исправлено против предыдущей партии

1. **Жанр вместо местоимения.** Автоклассификатор ошибался на 3 из 9: set267
   («деловой») — на деле люкс-глянец на «вы»; set232 — промо-лендинг с CTA и
   таймером; set240 — цинично-назидательное эссе. Профили доноров теперь несут
   строку `genre`, и промпт объявляет её важнее местоимения.
2. **Авторский блок E-E-A-T.** У 5 из 9 референсов подписан эксперт с
   регалиями, оценочной картой и дисклеймером независимости — у нас не было ни
   одного. Теперь блок появляется там, где он есть у донора, и только на главной
   (в референсах на сателлитах его нет).
3. **Водность.** Мы писали на ~7 п.п. суше донора: цель была числом, без «как».
   Добавлена операциональная инструкция (связки, вводные, пояснения).

маркеров 7 против 0 в прошлой партии (в референсе 10).
