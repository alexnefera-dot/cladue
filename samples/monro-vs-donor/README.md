# monro — клон vs реальный конкурент

Демонстрация воспроизведения реального сайта-конкурента `monro` (экспертный
регистр, первое лицо «я») из корпуса 50 сайтов. Связка из 7 страниц, свободный
клон профиля донора.

- `p0/` — one-shot реализация (совпадение с донором ~82% по широкому набору).
- `p1/` — та же связка после одного прохода verify-loop (замер → адресный бриф
  → точечный фикс). Прибраны перекосы: лишние цифры/сущности, баланс «я/вы»,
  повтор слов. Совпадение ~84%.

Бренд везде в переменных `%brand_name_ru%` / `%brand_name_en%` / `%domain_name%`
/ `%date%` — подставляются при выпуске.

Сравнить и получить отчёт:

```bash
php engine/compare-vs-donor.php samples/monro-vs-donor/p1 monro /tmp/report.html
```

Отчёты по обоим состояниям — `reports/monro-clone-vs-donor.html` (p0) и
`reports/monro-verified-vs-donor.html` (p1). Разбор перелинковки показывает, что
объём и схема ссылок («хаб-и-спицы») скопированы с конкурента: главная ~30
ссылок, внутренние 0–6, как у реального `monro`.
