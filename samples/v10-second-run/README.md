# Второй прогон по всем 9 референсам — проверка уникальности

Те же доноры, что в `../v9-all-donors/`, но другие seed. Цель — измерить,
насколько два прогона одного донора дают РАЗНЫЙ текст при одинаковой форме.

## Уникальность

Пересечение с первым прогоном (4-словные шинглы):

| | среднее |
|---|---|
| Все страницы | **0.4%** |
| Только главные | **0.5%** |
| Диапазон | 0–1.3% |

То есть тексты практически полностью разные. Видно и содержательно: люкс-глянец
сменил Баден-Баден на Довиль и Портофино, промо-лендинг — имена в микро-историях,
циничное эссе — всю систему метафор (прокатная контора, метроном, турникет вместо
горной тропы и форта), экспертные наборы — авторов.

**Средний 85% в обоих прогонах**, расхождение по набору ±1–3 п.п. — движок
предсказуем, случайных провалов нет.

## Что остаётся слабым

Промо-жанры (set227 78%, set232 79%) держатся ниже остальных в ОБОИХ прогонах —
это устойчивая, а не случайная просадка. Превосходные степени, рефрены лендинга и
эмодзи по своей природе конфликтуют с анти-спам-метриками (прилагательные, вода,
тошнота, цифры). Требуют отдельной докрутки профиля, если этот жанр нужен в потоке.

Сводный отчёт: `reports/v10-svodka*.html` (вкладки: сводка, по каждой связке,
уникальность).
