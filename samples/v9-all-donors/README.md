снятые вычиткой референсов. Замер: `php engine/check-batch.php samples/v9-all-donors --corpus=dorgen`.

**Средний 85%**, разброс 78–89%.

## Что показал прогон

- **Нестандартные жанры воспроизводятся наравне с обычными.** Циничное эссе,
  люкс-глянец и инсайдерский деловой дали по 86% — столько же, сколько
  «нормальные» регистры. Раньше эти три донора классификатор считал просто
  «деловым»/«разговорным», и генератор писал их не тем голосом.
- **Слабее всех — промо-жанры**: рекламно-восторженный 81% и промо-лендинг 78%.
  У них тянет вниз связка «прилагательные + вода + тошнота»: превосходные
  степени и рефрены лендинга по своей природе конфликтуют с анти-спам-метриками.
- Остаточные красные одни и те же во всех наборах: цифры, императивы,
  прилагательные, тошнота, вода — структурные натяжения ниши.

Отчёты для вычитки: `reports/v9-vs-reference-*.html` (слева референс, справа наш).
