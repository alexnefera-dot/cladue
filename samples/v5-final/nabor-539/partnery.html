❓ Честные ответы на вопросы

Дают ли индивидуальные условия?

Да, при стабильном объёме подключается менеджер, через которого согласуются ставка и нестандартные размещения. Разговор идёт по цифрам личного кабинета, а не по обещаниям. До выхода на объём работают общие условия. Демо для обзора — играть бесплатно.

Когда доход считается подтверждённым?

Доход считается подтверждённым после закрытия расчётного периода и проверки трафика, обычно в первые дни следующего месяца. До этого момента цифра в личном кабинете предварительная и может уменьшиться. При модели с долей дохода выигрыши игроков уменьшают твой доход в периоде, и баланс может уйти в минус.

Условия для партнёров

Комиссии, трафик и выплаты — только по теме партнёрской программы.

Отдельный чат в кабинете партнёра, ответ в рабочие часы. Вопросы по выплатам решаются там, а не в игровой поддержке.

Каждый источник получает свою ссылку с меткой, статистика видна по каждому отдельно. Новый источник добавляется в кабинете.

Вознаграждение выплачивается без удержания налогов, декларирование на стороне партнёра. Выгрузка отчётности для этого доступна.
