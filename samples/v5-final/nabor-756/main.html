Большинство автоматов открываются без депозита на виртуальные кредиты. Выигрыш в демо не выводится — режим нужен для знакомства с механикой.

Аккаунт закрывается через поддержку после вывода остатка без восстановления. Для перерыва есть самоисключение на срок.

Автоматы и касса работают в браузере без установки. Приложение по желанию добавляет биометрию и уведомления, игру не меняет.
