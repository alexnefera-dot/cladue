❓ Честные ответы на вопросы

Можно ли писать в рекламе про гарантированный выигрыш?

Обещать выигрыш в рекламе запрещено правилами программы и лицензией, такие материалы ведут к расторжению. Разрешено описывать условия, бонусы и сроки выплат без обещаний результата. Обещать выигрыш, скрывать риск и убирать пометку 18+. Промо вроде бонусов использовать можно, приписывать им гарантии — нельзя.

Материалы можно переводить?

Перевод согласуется заранее, чтобы не разойтись с правилами. Самостоятельные переделки офферов не допускаются. Готовые локализации обычно уже есть у менеджера. Возрастная разметка обязательна по правилам рекламы и лицензии, без неё материал не проходит проверку. Готовые баннеры уже содержат её, в своих материалах её нужно добавлять самому.

Условия для партнёров

Комиссии, трафик и выплаты — только по теме партнёрской программы.

Статистика по переходам, регистрациям и депозитам обновляется в кабинете. Данные доступны с разбивкой по источникам и датам.

Источники проверяются перед выплатой, при сомнениях запрашивается подтверждение. Проверка не задерживает начисления по чистым источникам.

Запрещён без письменного согласия, поисковая реклама по бренду запрещена всегда. Правила использования бренда лежат в кабинете.

Правила программы — часть договора, изменения публикуются с уведомлением за две недели. Продолжение работы означает согласие.
