❓ Честные ответы на вопросы

Что считается активным игроком?

Активный игрок — тот, кто внёс депозит и сделал ставки в расчётный период. Регистрация без депозита в статистике видна, но вознаграждения не даёт. Число игроков не ограничено, важен порог минимальной выплаты в деньгах, он указан в условиях. Один активный игрок может дать порог за месяц, десять неактивных — не дадут.

Как изменить модель вознаграждения?

Модель вознаграждения меняется по согласованию с менеджером и вступает в силу с начала следующего расчётного периода. Задним числом модель не пересчитывается, текущий период закрывается по прежним условиям.

Условия для партнёров

Комиссии, трафик и выплаты — только по теме партнёрской программы.

Персональный промокод закрепляет игрока за партнёром без перехода по ссылке. Выдаётся менеджером по запросу.

Авансы не выплачиваются, вознаграждение приходит по итогам периода. Индивидуальные условия обсуждаются после нескольких стабильных периодов.

Готовые материалы есть на нескольких языках, свой перевод согласуется с менеджером. Требования к разметке одинаковы для всех языков.
