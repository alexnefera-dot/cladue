# v2 — эталонные наборы по референсу конкурента (dorgen)

Сгенерированы через `--corpus=dorgen`, целятся в метрики конкурента (см.
`docs/v2-dorgen.md`). Замер — `compare-vs-donor.php <папка> <set> --corpus=dorgen`.

| Папка | Донор | Регистр | Опенер | Совпадение |
|---|---|---|---|---|
| `set199-verified/` | set199 | экспертный «я» | есть | **88%** (one-shot 83 → +verify-loop) |
| `set256-verified/` | set256 | нейтральный | нет | **82%** (one-shot 80 → +verify-loop) |
| `set267-oneshot/` | set267 | продающий «вы»+CTA | нет | **78%** (one-shot; петля ухудшила → 76) |

Ключевое: v2 воспроизводит сигнатуры dorgen — тяжёлое «я» (set199: 164 при их 185),
безличность (set256: я/вы≈0), продающие CTA (set267 главная: их 60 команд — берутся).

## Поведение verify-loop (важно)

- **Чистые регистры** (экспертный, нейтральный) — петля надёжно добивает **+2…+5 п.п.**
- **Продающий/деловой** — петля **осциллирует** (крупные правки тянут одеяло):
  set267 78 → 76. Берём такие на one-shot, профиль дорабатываем отдельно.
