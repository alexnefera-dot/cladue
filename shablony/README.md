# Шаблоны для анализа

Сюда складываются наборы шаблонов, которые нужно разобрать: замер по методике,
каталог блоков и вариантов, шинглы, бренд по поверхностям.

---

## ⚠️ Перед загрузкой: репозиторий должен быть приватным

На момент создания этой папки репозиторий **публичный**. Шаблоны конкурентов
в публичном репозитории попадают в открытый доступ: индексируются поиском,
доступны для форка, и **остаются в истории git навсегда** — удаление файла
последующим коммитом историю не чистит.

Переключить: **Settings → General → Danger Zone → Change repository visibility → Make private**.

---

## Куда что класть

### `glavnye/` — только главные страницы

Достаточно для: каталога блоков, всех вариантов `variant-vN`, тем `theme-tN`,
раскладок `layout-structure`, порядка блоков, рецепта рескина.

Проверено: весь CSS шаблона дублируется на каждой странице (12 инлайновых
`<style>` одинаковы везде), поэтому одна главная даёт **112 правил вариантов
из 112** — потерь ноль.

```
glavnye/
  kush/
    main.html
    main_files/          ← обязательно, внутри styles.php
  vavada/
    main.html
    main_files/
```

Вес: ~0.5 МБ на набор в zip. Сто наборов ≈ 16 МБ без картинок, 49 МБ с картинками.

### `polnye/` — все страницы набора

Нужно для: замера по методике (слова, абзацы, h2, плотность ключей, ссылки,
бренд по 13 поверхностям, шинглы) — всё, что считается по корпусу страниц.

```
polnye/
  kush/
    main.html  main_files/
    bonus.html bonus_files/
    slots.html slots_files/
    ...                      ← все 12 страниц
```

Вес: ~2 МБ на набор в zip. 25 наборов ≈ 55 МБ.

## Чего нельзя выбрасывать

**Папки `_files` оставлять обязательно.** Внутри лежит внешний `styles.php`,
и без него теряется **25 правил вариантов из 112** — целиком `action-block`,
целиком `faq-section`, часть `hero-value`. Это 22 % каталога.

**Картинки выбрасывать можно.** В анализе читаются только `img src` и `alt`
из HTML, сами `.jpg` никогда не открываются. Для режима `glavnye/` это экономит
втрое (49 → 16 МБ на сотню наборов). Для полных наборов экономия всего 15 %,
потому что вес — это сам HTML.

## Как загружать

### Через веб-интерфейс GitHub

**Add file → Upload files**, перетащить папки. Ограничения браузерной загрузки:
**25 МБ на файл** и **100 файлов за одно перетаскивание**. Zip-архив до 25 МБ
проходит одним файлом — для режима `glavnye/` этого хватает примерно на 50 наборов.

### Через терминал

Без практических ограничений на размер:

```bash
git clone https://github.com/alexnefera-dot/cladue.git
cd cladue
git checkout claude/blissful-darwin-d8lcoc
cp -r ~/Downloads/OLD50/* shablony/polnye/
git add shablony && git commit -m "data: добавлены наборы OLD50"
git push -u origin claude/blissful-darwin-d8lcoc
```

### Лёгкий архив только из главных

Одна строка, запускать один раз. На столе появится `light.zip`:

```bash
cd ~/Downloads/OLD && for d in */; do mkdir -p ~/Desktop/light/"$d"; \
  cp "$d"main.html ~/Desktop/light/"$d" 2>/dev/null; \
  cp -r "$d"main_files ~/Desktop/light/"$d" 2>/dev/null; done; \
  cd ~/Desktop && zip -qr9 light.zip light
```

## Что дальше

Архивы можно класть как есть — распакую сам. Имя папки набора становится его
именем во всех отчётах, поэтому называйте их по бренду: `kush`, `vavada`, `pin-up`.

Если бренд набора пишется и латиницей, и кириллицей, положите рядом с главной
файл `brand.txt` — по одному написанию на строку. Это снимает известный артефакт
определения бренда для наборов с кириллическим или двусловным названием.
