# Архивы как есть

Сюда кладутся `.rar` / `.zip` / `.7z` с наборами — распаковка на стороне анализа.
Распакованные наборы потом появляются в `../polnye/` и `../glavnye/`.

## Ограничения GitHub на размер файла

| вес файла | что будет |
|---|---|
| до 50 МБ | проходит без замечаний |
| 50–100 МБ | проходит, но GitHub выдаёт предупреждение |
| **больше 100 МБ** | **push отклоняется**, коммит придётся переделывать |

Поэтому любой архив тяжелее ~45 МБ нужно разрезать **до** коммита:

```bash
split -b 45m OLD50.zip OLD50.zip.part-
rm OLD50.zip          # в репозиторий кладутся только части
```

Получится `OLD50.zip.part-aa`, `OLD50.zip.part-ab` и так далее.
Собирается обратно одной командой, порядок частей `cat` берёт сам:

```bash
cat OLD50.zip.part-* > OLD50.zip
```

Части и целый архив вместе в репозиторий класть не надо — только части.

## Важно

Архив — это один непрозрачный бинарный блоб: git не умеет его сжимать по частям
и не умеет хранить разницу между версиями. Каждая новая версия архива — это
**полная копия** в истории, и она остаётся там навсегда. Поэтому: один архив
загружается один раз, перезаливать изменённую версию под тем же именем не стоит.
