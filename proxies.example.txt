# Список прокси, по одному в строке: общий для живой выдачи (source = live)
# и визитов на сайты (visit.proxy = 'list'), используются по кругу.
# Подключается в config.php: 'proxy_file' => __DIR__ . '/proxies.txt', или флагом --proxies=proxies.txt.
# Форматы:
#   http://host:port:user:pass    — HTTP-прокси с логином и паролем (основной формат)
#   host:port                     — HTTP-прокси без авторизации
#   host:port:user:pass           — HTTP-прокси с логином и паролем
#   user:pass@host:port           — то же
#   http://user:pass@host:port    — явно указанный тип: http, https, socks4, socks4a, socks5, socks5h
#   direct                        — прямое подключение без прокси (можно сочетать с прокси)
#
# Примеры (замените на свои):
# http://203.0.113.10:59100:login:password
# 203.0.113.10:8080
# 203.0.113.11:8080:login:password
# socks5://login:password@203.0.113.12:1080
# direct
