# Spheres — второй проект (экспериментальный)

Самостоятельное приложение «Сферы жизни» — отдельно от основного Pipboy (`app/`, `native/`).
Цель: проверить модель, где жизнь ведётся **сферами** (Цели ⊕ Колесо), а не разделами.

## Принцип

Каждая сфера = трасса к 10:
- **10** — как выглядит «достигнуто» (конечная точка);
- **где сейчас** — позиция 0→10 (считается из данных или ставится в ревизии);
- **следующий шаг** — и что для него надо;
- ниже — все инструменты как **живые данные**: задачи (прогресс/даты), рутины (стрики, неделя),
  трекинг (спарклайны), финансы, практики, инфо-связки, идеи.

Сферы двух типов:
- **рост** — есть 10, к которому идёшь (Здоровье, Деньги/FIRE, Развитие, Отношения, Отдых, Дело);
- **опора** — 10 = «всё под контролем» (легализация, налоги, документы, балансы, пассивы).

## Запуск

Чистый веб, без сборки и бэкенда. Открыть `spheres/index.html` в браузере.
Данные хранятся в `localStorage` (кнопка «сбросить» возвращает демо).

```
spheres/
├── index.html
├── style.css
├── app.js          # модель + рендер + редактирование (localStorage)
└── README.md
```
