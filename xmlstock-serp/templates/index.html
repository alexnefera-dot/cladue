XMLStock SERP — выгрузка ТОП и трекер позиций

Локальная работа с живой выдачей Яндекса (и Google) через API xmlstock.com.

Доступ xmlstock
Берётся в кабинете xmlstock.com → раздел API. Сохраняется только в этом браузере.
Параметры поиска
Live — живая выдача (как видит пользователь), но ~10 результатов на запрос: за бо́льшей глубиной листаются страницы (больше запросов/лимитов). XML — официальный Яндекс.XML, до 100 за запрос, дешевле, но выдача может чуть отличаться от живой. Что использовать — зависит от того, какие лимиты пополнены у вас в xmlstock.

Дополнительно (скорость, ретраи)
При ошибках лимита (RPS) уменьшите «Параллельно» или добавьте «Паузу».
Можно вставить 200–300 ключей разом. Дубликаты убираются автоматически.

Каждый блок — отдельный домен со своими ключами (для двух проектов добавьте два блока). Домен можно с www/https:// и путём — приведётся к чистому; поддомены и корень засчитываются. В каждом снятии одинаковые ключи запрашиваются один раз.

«Средняя» считается по снятиям, где сайт найден в выдаче. «Нашли N/M» — в скольких снятиях сайт попал в выбранную глубину.
⚠ Выдача между снятиями не меняется — вероятно кеш xmlstock или стабильный топ. Для реальной динамики увеличьте интервал (часы) — либо позиция просто устойчивая.
Для каждого домена соберём все URL из индекса Яндекса через site:домен. Можно с www/https:// — приведётся к хосту.
Один запрос site: отдаёт максимум ~1000 URL (потолок Яндекса). Глубокий сбор дробит на подразделы (site:домен/раздел) и собирает больше (до «Макс. URL на домен», до 5000) — но тратит кратно больше запросов/лимитов. Движок для site: — Яндекс XML (Live авто-переключается на XML).

Оставим по 1 ссылке на домен, прокликаем каждую и запишем, куда редиректит. Источник — выгрузка «Сбора ТОП» или свой список.
Быстрый (HTTP) — ловит HTTP 3xx, meta-refresh и простой JS (location=…); обфусцированный/таймерный JS не разворачивает. Браузер — открывает страницу в Chromium, ждёт JS/таймер-редирект (как у дорвеев с «/ru/ru/…»), может кликнуть кнопку. Точнее, но медленнее (по одному сайту).
Для браузерного режима нужен Playwright — один раз в папке проекта: pip install playwright && playwright install chromium
