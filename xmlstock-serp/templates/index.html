XMLStock SERP — выгрузка ТОП выдачи

Локальный сбор ТОП-N результатов Яндекса (живая выдача) по списку ключей через API xmlstock.com.

Доступ xmlstock
Берётся в личном кабинете xmlstock.com → раздел API. Сохраняется только в этом браузере (localStorage).
Параметры поиска
Вставьте точный адрес из вашего кабинета, если стандартный не подходит.
Дополнительно (скорость, ретраи)
Если xmlstock возвращает ошибки лимита (RPS) — уменьшите «Параллельно» или добавьте «Паузу».
Можно вставить 200–300 ключей разом. Дубликаты убираются автоматически.
