# XMLStock SERP — выгрузка ТОП выдачи Яндекса

Локальный инструмент с интерфейсом в браузере: вставляете пачку запросов
(200–300 шт.), получаете **ТОП-N результатов по каждому ключу** через API
[xmlstock.com](https://xmlstock.com) и выгружаете в файл (**XLSX** / **CSV**).

По умолчанию используется живая выдача Яндекса (**Yandex Live**). Данные обрабатываются
у вас на компьютере и отправляются только в API xmlstock.

---

## Возможности

- Пачка запросов разом, дубликаты убираются автоматически.
- ТОП-N (1–50) по каждому ключу: позиция, URL, заголовок, домен.
- Параллельные запросы + ретраи с экспоненциальной паузой при ошибках лимита.
- Прогресс в реальном времени, лента обработки, список ошибок.
- Кнопка «Остановить» в любой момент.
- Выгрузка:
  - **XLSX** — два листа: `results` (по строке на результат) и `wide` (ключ + URL-ы в ряд);
  - **CSV** — `query;position;url;title;domain` (UTF-8 + BOM, открывается в Excel двойным кликом).

## Установка

Нужен Python 3.9+.

```bash
cd xmlstock-serp
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откроется браузер на `http://127.0.0.1:5000` (если нет — откройте вручную).

---

## Как пользоваться

1. Введите **User ID** и **API key** из личного кабинета xmlstock (раздел API).
   Они сохранятся в вашем браузере и не отправляются никуда, кроме xmlstock.
2. Выберите **движок**:
   - `Яндекс` — путь `/yandex/xml/`. Живая выдача это будет или XML-лимиты,
     определяется тем, какие лимиты пополнены в вашем тарифе xmlstock;
   - `Google` — путь `/google/xml/`;
   - `Свой URL…` — если в вашем кабинете другой адрес эндпоинта, вставьте его точно.
3. Задайте **регион** (`lr`, например `213` — Москва), при необходимости домен и устройство.
4. Вставьте запросы — по одному в строке.
5. Нажмите **«Запустить сбор»** и дождитесь завершения.
6. Скачайте **XLSX** или **CSV**.

> **Ошибки лимита (RPS).** Если xmlstock начинает отдавать ошибки лимита,
> уменьшите «Параллельно» (например до 2–3) или добавьте «Паузу» (0.2–0.5 сек)
> в блоке «Дополнительно».

## Про эндпоинт

Скрипт использует стандартные адреса xmlstock:

| Движок | URL |
|--------|-----|
| Яндекс (Live / XML) | `https://xmlstock.com/yandex/xml/` |
| Google              | `https://xmlstock.com/google/xml/` |

> У xmlstock единый путь `/yandex/xml/` для Яндекса. Будет это живая выдача
> или официальный Яндекс.XML — зависит от того, какие лимиты пополнены в вашем
> аккаунте, а не от URL.

Запрос формируется так:

```
{endpoint}?user=USER&key=KEY&query=ЗАПРОС
  &groupby=attr=d.mode=deep.groups-on-page=N.docs-in-group=1
  &lr=213&page=0
```

Ответ разбирается как **Яндекс XML** (`response → results → grouping → group → doc →
url / title / domain`); есть запасной разбор JSON. Если у вашего тарифа адрес или
формат отличается — выберите **«Свой URL…»** и вставьте точную ссылку из кабинета.
