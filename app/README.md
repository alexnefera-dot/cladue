# Pipboy — веб-прототип

Локальный прототип платформы. **Без зависимостей** — нужен только Node.js ≥ 22.5 (встроенный SQLite).

## Запуск на Mac

```bash
# один раз: установить Node, если нет
brew install node

# запустить
cd app
node server.js
# → открыть http://localhost:7777
```

База создаётся в `app/data.db` при первом запуске и наполняется тестовыми данными
(разобранные ветки «Авто» и «Здоровье»). Удалишь файл — база пересоздастся.

## Тесты

```bash
cd app && npm test
```

## Что уже есть (этап 1 — категории, импорт, разбор)

- **Категории пользователя** (Финансы → налоги/платежи/балансы/траты/активы/пассивы,
  Легализация → ВНЖ, Работа, Жизнь, История и расчёты, Страхи/Вопросы → Тревоги×8,
  Глобальные цели) + 📥 Инбокс.
- **Импорт**: кнопка «⤓ Импорт» — вставляешь блок заметок как есть, вложенность
  по отступам сохраняется, маркеры (1. / - / •) срезаются. Блок ложится в выбранную категорию.
- **Раскидывание**: в карточке узла «переместить в…» — запись (со всем поддеревом)
  уезжает в категорию/подкатегорию.
- **Ничего не решается за тебя**: тип (задача/решение/вопрос/принцип/идея/тревога),
  приоритет и срок ставишь сам; система подсказывает (★ и «в тексте найден месяц»).
- **Предложения связей** с причиной (совпадение слов, «х5»=«X5») — принять
  (⛓ связать / ⛔ это блокер / → я блокирую) или скрыть. Блокировки — только подтверждённые.
- Поиск по всему (слева внизу).
