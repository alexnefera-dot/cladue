# Pipboy — веб-прототип

Локальный прототип платформы. **Без зависимостей** — нужен только Node.js ≥ 22.5 (встроенный SQLite).

## Запуск на Mac

```bash
# один раз: установить Node, если нет
brew install node

# запустить
cd app
node server.js
# → открыть http://localhost:7777
```

База создаётся в `app/data.db` при первом запуске и наполняется тестовыми данными
(разобранные ветки «Авто» и «Здоровье»). Удалишь файл — база пересоздастся.

## Тесты

```bash
cd app && npm test
```

## Что уже есть (этап 1 — Задачи и Цели)

- Цели-ветки с приоритетами P1–P5, задачи с приоритетами P0–P3, сроками, подзадачами.
- Типы записей: задача / решение / вопрос / принцип / идея.
- Зависимости: «блокирует», «зависит от решения» — с защитой от циклов;
  заблокированные записи приглушены (⛔), принятие решения снимает блокировку.
- **Радар блокеров** в инспекторе: блокирующие, упоминания в других ветках (FTS5,
  кириллица↔латиница «х5»=«X5»), окно времени ±60 дней, открытые решения, принципы ветки.
- Быстрый ввод: `p0–p3` в тексте — приоритет, `2026-08-31` — срок.
- Поиск по всему (слева внизу).
