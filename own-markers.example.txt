# Свои шаблоны — сайты, которые мы сами размещаем и НЕ хотим собирать/скачивать.
# Скопируйте этот файл в own-markers.txt и впишите свои метки (по одной на строку).
# Строки, начинающиеся с #, — комментарии. Регистр не важен.
#
# Метка — устойчивая подстрока, которая есть на страницах вашего шаблона и почти
# наверняка отсутствует у чужих сайтов. НЕ опирайтесь на меняющиеся коды и стили
# (QR-код, оформление) — берите то, что стабильно:
#   • домен размещения шаблона (и его поддомены),
#   • токен проверки (например, содержимое <meta name="yandex-verification">),
#   • характерный путь к ассетам шаблона,
#   • неизменный текст/идентификатор в <head>.
#
# Если метка найдена на странице (или в адресе) — сайт помечается в отчёте
# «исключён как наш» и не скачивается. Метки-домены (без «/», с точкой) отсеиваются
# ещё на этапе сбора — вместе со всеми поддоменами.
#
# Примеры (замените на свои!):
# mytemplate.example        ← домен размещения (и все его поддомены)
# a1b2c3d4e5f6a7b8          ← токен yandex-verification из <head>
# /uploads/brands/          ← характерный путь к ассетам шаблона
