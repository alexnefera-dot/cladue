# Анализатор контента под Яндекс

Инструмент для анализа контента **7-страничного проекта с перелинковкой** под
поисковую систему Яндекс: SEO- и не-SEO-параметры, которые считаются **офлайн**
локальным PHP-движком (без API Яндекса). Контент подаётся в форматах HTML, DOCX
или обычным текстом.

## Три части проекта

| Фаза | Что это | Где |
|------|---------|-----|
| **1. Реестр параметров** | ~110 параметров в 14 категориях с нормами под Яндекс и пометками, что считается офлайн | [`docs/parameters.md`](docs/parameters.md) |
| **2. HTML-шаблон** | Форма загрузки 7 страниц + дашборд: баллы, матрицы 7×7, «светофор» норм, рекомендации | [`template/`](template/) |
| **3. PHP-движок** | Живой локальный скрипт: парсинг → расчёт → сравнение 7 страниц → JSON | [`engine/`](engine/) |

## Запуск

```bash
php -S localhost:8000
# открыть http://localhost:8000/template/index.html
```

Заполните до 7 страниц (файл или вставка текста, ключ + LSI) и нажмите
«Проанализировать». Или нажмите «Показать демо-данные», чтобы увидеть шаблон
сразу. Подробности — в [`engine/README.md`](engine/README.md).

## Что анализируется

- **Объём и текст:** слова, предложения, абзацы, уникальность.
- **Антиспам (Баден-Баден):** классическая/академическая тошнота, плотность
  ключей, доля точных вхождений, переспам выделением.
- **Водность** и речевые штампы.
- **Естественность:** соответствие закону Ципфа.
- **Читабельность:** индексы Флеша, Флеша-Кинкейда, Ганнинга.
- **Ключи и семантика:** вхождения по морфологии (стеммер Портера-Снежка),
  ключ в Title/H1/первом абзаце, покрытие LSI.
- **Структура:** заголовки H1–H6, иерархия, метатеги, микроразметка, изображения.
- **Перелинковка 7×7:** матрица связей, страницы-сироты, тупики, глубина клика,
  разнообразие анкоров.
- **Внутренняя уникальность:** матрица схожести по шинглам, дубли между страницами.
- **Типографика:** двойные пробелы, кавычки, капс.

Полный список с нормами — в [`docs/parameters.md`](docs/parameters.md).

## Требования

PHP ≥ 8.1 с расширениями `dom`, `mbstring`, `zip`.
